# 한글날 수업 앱 릴스 — 기획

`kinetic-type-reel` 스킬의 절차를 따른다. 글자·선·색면만 쓰는 9:16 키네틱 타이포그래피.

| 항목 | 값 |
|---|---|
| 길이 | 16마디 · 120 BPM = 32초, 60fps, 1,920프레임 |
| 화면 | 1080×1920 (릴스·쇼츠) |
| 색 | 먹 `#1F3A30`(앱의 진녹) · 종이 `#FAF8F1` · 주황 `#ED6B36` (앱 팔레트에서) |
