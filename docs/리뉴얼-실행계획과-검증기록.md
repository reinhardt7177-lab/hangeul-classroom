# 국경일 교육 앱 리뉴얼 실행계획과 검증기록

작성일: 2026년 10월 1일

공개자료 기반 리뉴얼 계획을 실제 앱에 적용합니다. 고정 시간 전제 폐지, 선택형 탐구, 출처의 정확성, 학년별 수행 차이를 우선합니다. 이번 작업은 로컬 구현과 검증을 대상으로 하며 공개 배포는 별도 상태로 기록합니다.

## 작업 순서

- [x] 현행 앱의 고정 시간 표시·자동 배정 타이머·합계 검사를 제거했다. 영상의 실제 재생 길이는 유지했다.
- [x] 개천절 키보드 충돌, 연결 원문의 三危太伯 표기, 전승·법 해석을 수정했다.
- [x] 두 주제에 활동 선택·순서 조정·선택 경로 이동·마지막 활동 이어보기를 제공했다.
- [x] 개천절 학생 활동을 학년별 이야기·비교·주장 수정으로 구분했다.
- [x] 한글날 글자 관찰과 근거 읽기·독자 피드백을 보강했다.
- [x] 공통 QR에 주소 선택·localhost 차단·학생 활동 선택을 제공했다.
- [x] 운영 안내·개천절 학습지·오프라인 패키지 구성을 동기화했다.
- [x] 아래 범위의 자동 검증과 브라우저 조작·가독성 검사를 수행했다.

## 추가 시각자료와 모션 제작 계획

| 자료 | 제작 방식과 목적 | 안전 기준 |
|---|---|---|
| 활동 선택 카드 | 기존 삽화와 HTML 타이포그래피 재사용 | 시간·완료 압박 없이 질문·결과물을 표시 |
| 글자 모양·조합 도해 | HTML·CSS 글자 도해, 버튼으로 단계 공개 | 역사적 제자 설명과 현대 발음 관찰을 구분 |
| 문헌·유물·재구성 근거 카드 | 짧은 원문·자체 재서술·공식 원본 연결 | 자료 형태와 주장의 확실성을 별도 판단 |
| 주장·근거·한계 카드 | 큰 타이포그래피와 학생 입력 영역 | AI 그림을 실제 증거로 표시하지 않음 |
| 공개 단계 전환 모션 | 짧은 CSS 전환, 교사 조작 때만 공개 | 동작 줄이기에서 정적 표시, 자동 학습 진행 없음 |
| 실제 유물 사진 | 개별 이용조건 확인 후 채택 | 권한 미확인 사진은 복제하지 않고 공식 원본 보기로 연결 |

새 AI 삽화를 대량 제작하지 않습니다. 사건 연결은 인물·사건 카드로 먼저 해결하며, 글자와 근거 판단은 정확한 텍스트·도해가 더 적합합니다. 실제 사진은 재사용 조건 확인이 필요하므로 출처 확인과 적용 상태를 분리합니다.

## 브라우저 검증 목록

선택 화면은 스크롤을 허용하되 첫 화면에서 활동 선택 목적과 시작 버튼을 찾을 수 있어야 합니다. 발표 화면은 질문·자료·이전·다음·목차가 화면에 들어와야 합니다.

- 시간 전제: 두 주제의 첫 화면·준비·발표·목차에서 고정 분량이 나타나지 않는다.
- 활동 선택: 선택·해제·순서 조정·시작·목차 재방문·이어보기·종료를 검사한다.
- 선택 경로: 선택하지 않은 장면으로 자동 이동하지 않고, 이전으로 돌아갈 수 있다.
- 키보드: 보기의 Space·Enter는 선택을 수행하고 배경 단축키만 발표를 넘긴다. 입력·영상·모달은 고유 조작을 유지한다.
- 학생 활동: 탭 변경 후 입력을 보존하고 학년별 내용이 다르다. 새로고침 안내와 동작이 일치한다.
- QR: 공개 주소, 교실 주소, localhost·파일 주소 오류, 활동 대상 선택을 검사한다.
- 시각자료: 큰 글자·줄바꿈·모션 공개와 동작 줄이기·좁은 화면을 확인한다.
- 예외 탐색: 전체 선택 해제, 오래된 링크 직접 진입, 다른 학년 전환, 영상 없이 진행을 검사한다.

새 시각자료는 한글 ㅁ·ㄴ HTML 타이포그래피, 창제 목적·주장·근거·한계 카드와 교사 조작에 따른 짧은 전환입니다. 국립중앙박물관 송국리 출토 동검 사진은 개별 공공누리 제1유형 조건을 확인해 원본·출처 표시로 사용했습니다. 생성 삽화를 역사적 증거로 바꾸지 않았습니다. [출처 대장](../knowledge/리뉴얼-출처대장.md)에 사용 범위와 조건을 기록했습니다.

이어서 보기는 마지막 **활동의 처음**에서 재개합니다. 세부 공개 단계나 학생 입력을 영구 저장하지 않습니다. 원래 숫자형 직접 링크는 계속 열 수 있습니다. 교사가 고른 경로는 브라우저에만 저장되며 학생과 실시간 동기화하지 않습니다.

기존 오프라인 앱 폴더는 삭제하지 않고 `tmp/hangeul-app-backup-*`, `tmp/gaecheon-app-backup-*`에 보존했습니다. `.claude/` 등 무관한 사용자 파일은 변경하지 않았습니다.

## 다음 단계와 완료 조건

1. **활동 설계 정교화:** 활동별 선행 자료·목표·출처 ID·피드백 기준을 명시적인 공통 데이터로 정리하고, 선택 전에 추천 연결과 필요한 자료를 안내한다. 기존 활동 ID는 유지한다.
2. **출력물 확장:** 선택한 활동에 맞춘 인쇄 묶음, 개천절 중학년 비교표·고학년 주장/근거/한계 수정표, 한글날 독자 피드백 칸을 보강한다. 현행 전체 학습지는 선택 목차에서 열 수 있지만 자동 맞춤 생성은 아직 없다.
3. **근거 자료 확장:** 실제 해례본·고인돌·청동기 생활 자료는 개별 이용조건과 판독 가능성을 확인한 후 채택한다. 확인 전에는 공식 원본 링크를 유지한다.
4. **교실 검증:** 실제 전자칠판 뒤쪽 가독성, 학생 태블릿의 QR 접속, 브라우저 음성 읽기 지원, 저학년 조작 난이도를 확인한다. 기능 통과를 학습 효과의 실증으로 표현하지 않는다.
5. **공개 배포:** 사용자 확인 후 공개 사이트에 배포하고 배포 URL에서 다시 검사한다. 현재 ZIP은 로컬 리뉴얼판이며 공개 사이트는 이전 버전이다. 교실 QR을 쓸 때 공개 주소를 넣으면 이전 버전으로 연결될 수 있으므로 로컬 교실 주소를 먼저 확인한다.

## 2026-10-01 후속 수정

위의 첫 리뉴얼 검증 결과를 보존하며 후속 수정 결과를 추가한다. [학습내용과 시각자료 수정계획](학습내용과-시각자료-수정계획-2026-10-01.md)에 세부 결과와 한계를 기록했다.

네 사건 이야기 카드, 질문 옆의 삼국유사 발췌·풀이, 사진 관찰과 소장품 정보의 구분, 추천 선행 자료, 개천절 비교·근거 수정 학습지와 한글날 독자 피드백 칸을 적용했다. 실제 고창 고인돌 사진과 1946년 해례본 영인본은 생성 삽화·1446년 원본과 구분했다. 개천절 도입 영상도 수정된 자막과 이야기 카드로 다시 만들었다.

자동 검사 5종과 PDF 검사를 통과했다. 현재 한글날 발표 단계는 114개(저학년32·중학년41·고학년41), 학습지는 12종 총 26쪽(개천절14·한글날12)이다. 수정된 PDF 전체 페이지와 영상의 네 프레임을 확인했다. 브라우저에서 이야기 정오답·초기화, 입력 유지, 빈 선택 차단, 추천 자료 미리보기 후 선택 경로 유지 및 1024×768/390×844 화면을 검사했다. [네 사건 이야기 카드 화면](../output/renewal/story-cards-2026-10-01.png)을 저장했다.

선택 활동만 자동으로 묶는 인쇄 기능, 교실 실증, 제정 100주년 특집은 남아 있다. 이번 수정도 공개 사이트 배포를 포함하지 않는다. 실제 학생 QR에는 최신 로컬 교실 주소를 먼저 확인해야 한다.
