# 공개자료 기반 국경일 교육 앱 리뉴얼 계획

작성일: 2026년 10월 1일 · 대상: 한글날·개천절, 초등 1–2·3–4·5–6학년군

## 1 리뉴얼의 결정과 범위

앱을 **교사가 탐구 목적에 맞춰 자료와 활동을 고르는 교육 자료실**로 전환합니다. 고정 수업 시간, 장면별 권장 분량, 시간에 맞춘 내용 압축을 설계 기준에서 삭제합니다. 원문·연표·범금 8조·유물 탐구는 보존하고 필요한 자료와 설명을 보강합니다. 교사는 독립 활동을 고르거나 서로 연결해 사용할 수 있습니다.

이 계획은 [앱 전체 점검과 자료 비교 보고서](앱-전체점검과-계기교육-비교-개선안-2026-10-01.md)를 실행 과제로 구체화한 것입니다. 확인된 문제, 공개자료에서 얻은 구성상의 시사점, 새 설계 제안을 구분합니다. 이후 사용자 요청으로 로컬 앱·PDF·오프라인 패키지에 1차 구현을 적용했습니다. 적용 범위와 남은 과제는 [실행계획과 검증기록](리뉴얼-실행계획과-검증기록.md)을 기준으로 확인합니다. 공개 사이트는 아직 변경하지 않았습니다.

리뉴얼 범위는 현재 운영 중인 두 주제와 여섯 학년군 자료입니다. 나머지 국경일은 준비 중 표시를 유지합니다. 학생 응답의 서버 수집, 학급 계정·실시간 집계, 새 주제 완성, 외부 자료의 무단 재배포는 포함하지 않습니다. 이미 수정한 삽화와 기존 영상은 활용 가능성을 먼저 검토하고 일괄 재제작하지 않습니다.

### 폐지할 것과 유지할 것

| 폐지할 전제·기능 | 대신 적용할 기준 |
|---|---|
| 고정된 수업 총량과 장면별 권장 분량 | 중심 질문, 필요한 자료, 학생 결과물로 활동을 선택 |
| 장면에 자동 배정되는 카운트다운과 종료 안내 | 교사가 관찰·대화·작성을 마친 뒤 직접 진행 |
| 시간 합계와 고정 장면 수를 교육 품질로 보는 검사 | 목표·근거·활동·평가의 연결과 이동 기능 검사 |
| 전체 장면을 모두 끝내야 하는 진행률 | 교사가 선택한 활동 목록 안의 위치와 이어보기 |
| 원문·법·유물을 시간 때문에 생략하는 권고 | 학년의 읽기 수준과 탐구 질문에 따라 선택·연결 |

영상 자체의 재생 길이, 자막 타이밍, 시작·끝 구간은 미디어가 정상 작동하는 데 필요한 정보이므로 유지합니다. 이것을 수업 종료나 학생 활동 마감 기준으로 사용하지 않습니다. 새로운 길이별 코스를 만들어 고정 시간 전제를 대체하지도 않습니다.

공개 구성의 비교에서 도출한 설계 제안은 다음과 같습니다. 학생 대상 효과 비교 실험의 결론은 아닙니다.

- 자료를 많이 나열하는 데서 끝내지 않고 질문·자료·결과물을 연결합니다.
- 같은 활동의 문항 수만 늘리지 않고 학년별 수행 방식을 다르게 만듭니다.
- 정답 확인에 더해 학생이 이유를 설명하고 결과물을 고치는 절차를 둡니다.
- 교사가 문항과 출력 자료를 선택·수정하기 쉽게 만듭니다.
- 외부 영상·링크가 열리지 않아도 목표를 확인할 수 있는 대안을 둡니다.

유료 도안의 공개 미리보기는 기존 보고서의 비교 대상으로만 남깁니다. 이번 리뉴얼의 재사용 자료 목록에는 넣지 않습니다. 공개 열람 가능하다는 사실만으로 사진·PDF·영상의 앱 내 복제나 오프라인 배포가 허용되는 것은 아닙니다.

## 3 앱 구조와 교사 사용 흐름

첫 화면의 국경일 선택은 유지합니다. 주제와 학년군을 고르면 곧바로 전체 발표를 시작하는 대신 활동 선택 화면을 엽니다.

활동 선택 화면에는 다음 정보를 한 카드에 묶습니다.

- 활동 이름과 중심 질문
- 학생이 할 일과 남길 결과물
- 필요한 선행 자료·준비물·인터넷 여부
- 발표 화면, 학생 화면, 인쇄 자료의 연결
- 출처와 교사용 피드백 기준

분류는 ‘이야기 알기 / 자료 탐구 / 글자 실험 / 표현·창작 / 토론·실천 / 배움 확인’으로 구성하고, 주제에 맞는 분류만 보여 줍니다. 교사는 추천 연결을 선택하거나 개별 활동을 담고 순서를 바꿀 수 있습니다. 추천은 의무 과정이 아니며, 선택하지 않은 활동을 미완료로 경고하지 않습니다.

발표 화면은 선택한 목록을 따라 이동합니다. 목차에서 다른 자료를 열었다가 원래 탐구로 돌아올 수 있고, 질문·설명·정답은 현재의 순차 공개 장점을 유지합니다. 학생 QR은 현재 주제·학년군·활동에 연결합니다. 학생에게 교사 노트나 정답이 먼저 노출되지 않도록 교사 경로와 학생 경로를 구분합니다.

동일 브라우저에서 선택한 목록과 교사의 마지막 위치를 저장합니다. 학생 작성 내용의 유지 범위와 새로고침 시 소실 가능성을 명확히 안내합니다. 계정이나 서버 저장을 새로 도입하지 않습니다. 기존 장면 번호 기반 링크·QR은 대응표로 연결해 저장된 교사 링크가 바로 깨지지 않게 합니다.

### 공통 활동 데이터의 최소 구성

각 활동은 안정적인 `id`, 주제·학년군, 중심 질문, 목표, 자료 ID, 선행 활동, 발표 단계, 학생 응답 방식, 피드백 기준, 출력 자료, 외부 연결 대안을 갖습니다. 장면 순서 번호를 활동의 유일한 식별자로 사용하지 않습니다. `minutes`와 기본 카운트다운 값은 새 활동 정의에 넣지 않습니다.

활동마다 독립 사용이 가능한지 표시합니다. 연결이 필요한 활동은 “이 동검 사진을 먼저 살펴보세요”처럼 필요한 자료를 안내하고, 보지 않은 자료에 관한 평가가 갑자기 등장하지 않게 합니다.

## 4 학년군별 학습 리뉴얼

아래 활동 묶음은 자료실의 구성안이며 전부 이수해야 하는 코스가 아닙니다. 추천 연결에는 해당 질문에 필요한 자료와 표현·확인 활동을 함께 배치합니다. 읽기 수준에 따라 말·그림·가리키기로도 응답하게 합니다.

| 주제·학년군 | 탐구 질문과 활동 구성 | 학생 결과물과 확인 기준 |
|---|---|---|
| 한글날 1–2 | ‘글자로 내 마음을 어떻게 전할까?’ 날짜와 기념 의미 → 낱자 조합 → 마음 쪽지·몸짓 표현 | 글자·그림·말로 뜻을 전하고 누구에게 전하는지 설명. 글씨 솜씨는 평가하지 않음 |
| 한글날 3–4 | ‘글자 모양과 쉬운 말은 어떤 도움을 줄까?’ 기본 자음 모양 관찰과 낱자 조합은 별도 활동. 쉬운 안내문은 짝이 읽고 다시 쓰기 | 모양에서 관찰한 점 또는 안내문 수정 전·후와 이유. 뜻과 필요한 정보를 지키며 독자의 반응을 반영 |
| 한글날 5–6 | ‘누구나 뜻을 전하고 정보를 이해하려면?’ 짧은 서문 풀이·쉬운 재서술 비교, 말과 문자의 구별, 안내문 수정, 기념일의 역사·정보 접근 사례 선택 | 창제 목적과 자신의 수정 이유를 근거로 연결. 원문·번역·앱 재서술을 구분하고 핵심 정보를 보존 |
| 개천절 1–2 | ‘어떤 이야기를 기억하고 어떻게 도울까?’ 인물·사건 말을 붙인 이야기 순서, 기념 의미, ‘도와줄까?’ 역할놀이 | ‘옛이야기 속에서는’으로 한 장면 말하기, 상대에게 먼저 묻기. 고조선 자체가 가짜라는 결론으로 연결하지 않음 |
| 개천절 3–4 | ‘이야기와 남아 있는 자료는 무엇이 다를까?’ 이야기·기록 비교, 실제 유물 관찰, 기념일 연표, 우리 반 약속 | 자료가 보여 주는 것과 아직 알 수 없는 것 구별. 이유가 있는 약속 카드와 짝의 질문에 대한 답 |
| 개천절 5–6 | ‘자료로 어디까지 말할 수 있을까?’ 원문 읽기, 문헌·유물 비교, 범금 8조 추론, 주장 수정, 홍익인간 실천의 갈등 상황 | ‘주장 + 근거 + 한계’ 카드와 실행 제안. 상대 의사·실행 가능성·역할을 고려하고 과도한 단정을 고침 |

### 한글날 보강 과제

1. 국립국어원의 [한글의 구성 원리](https://www.korean.go.kr/hangeul/principle/001.html)를 근거로 자음·모음이 음절을 이루는 실험을 구성합니다. ‘오늘날 기본 자모 24자’를 전체 가능한 글자 수처럼 가르치지 않습니다.
2. 중학년 모양 탐구는 ㅁ의 입 모양 관찰, ㄴ의 해례 설명과 그림 비교처럼 교사가 안내할 수 있는 단계로 보여 줍니다. 현대 발음 관찰과 역사적 제자 설명이 완전히 같은 증거인 것처럼 단정하지 않습니다.
3. 고학년은 확인한 서문 구절·현대어 풀이·앱의 쉬운 재서술을 구분해 나란히 제시합니다. 목적을 설명하는 근거 읽기이지 원문 암기 과제가 아닙니다.
4. 말과 문자의 구별에서 반복되는 ‘안녕 / annyeong’ 뒤에는 다른 예시를 사용합니다. 로마자로 한국어를 적었다고 영어가 되는 것은 아니라는 설명은 유지합니다.
5. 2026년 기념 맥락은 [장서각 전시 안내](https://www.aks.ac.kr/webzine/2607/sub_02.jsp)와 [한글날 제정 100주년 전시 안내](https://hangeul.go.kr/exhibition/676?curr_menu_cd=0102020000&page=1&searchCondition=&searchKeyword=)를 참고한 선택 자료로 둡니다. 숫자 암기를 늘리지 않고 문자의 탄생·기념일의 형성·정보 접근을 탐구합니다. 연도 한정 자료는 상시 기본 설명과 분리합니다.

### 개천절 보강 과제

1. [우리역사넷의 단군 기록](https://contents.history.go.kr/front/hm/view.do?levelId=hm_001_0010)과 앱 인용을 대조합니다. 연결한 한문 본문의 `三危太伯`과 번역에 나타나는 `三危太白`을 섞지 않고, 채택한 원문·판본을 표시합니다. 기록 속 약속의 100일과 곰의 변화가 서술된 21일도 구분합니다.
2. 저학년 표현은 “곰이 사람으로 바뀌는 장면은 옛이야기로 전해져요. 고조선의 실제 모습은 남아 있는 유물과 기록으로 알아봐요”로 고칩니다. 전승의 의미를 무시하거나 고조선의 존재를 부정하는 방향으로 설명하지 않습니다.
3. 이야기 순서는 기존 그림에 인물·사건 카드를 덧붙입니다. 단군왕검 등이 그림에서 직접 드러나지 않는 문제는 설명과 과제의 대응을 먼저 고쳐 해결합니다.
4. 유물 탐구에는 이용조건을 확인한 실제 사진과 이름·출토지 또는 유적 위치를 제시합니다. AI 삽화는 분위기·이야기 재구성에 사용하고 실제 유물 관찰의 대체 증거로 쓰지 않습니다. 분포를 물으려면 분포 자료를 먼저 보여 주며, 제공하지 않으면 문항을 사진 관찰에 맞게 바꿉니다. 문화 분포를 확정 국경선으로 표시하지 않습니다.
5. 자료의 형태와 주장의 확실성을 분리합니다. ‘문헌 / 출토 유물 / 현대 재구성’으로 먼저 분류하고, ‘무엇을 뒷받침하는가 / 무엇은 확인하지 못하는가’를 따로 묻습니다. 전승을 기록했다는 사실과 전승의 모든 장면이 실제 사건이라는 판단을 구분합니다.
6. [우리역사넷의 범금 8조 설명](https://contents.history.go.kr/mobile/eh/view.do?code=ganada&levelId=eh_r0005_0010)을 참고하되, 조항에서 직접 읽는 내용과 오늘의 해석을 나눕니다. 엄한 벌·곡식 보상·재산과 노비 신분의 규칙을 읽고 가능한 해석을 말하게 합니다. 사형·노비 제도를 오늘 따라야 할 좋은 규칙으로 칭찬하지 않습니다.
7. 고학년 실천 활동에는 ‘도움을 원하지 않는 친구’, ‘좋은 계획이지만 역할 부담이 고르지 않은 경우’ 등 고려할 점이 충돌하는 상황을 둡니다. 정답 하나를 고르는 대신 상대 의사·역할·가능성을 근거로 제안을 수정합니다.

## 5 출처와 시각자료 운영 기준

자료를 채택할 때는 출처 대장을 만듭니다. 기록할 항목은 자료 ID, 기관·제작자, 제목, 원문 URL, 사용 구절·이미지 식별 정보, 열람 범위, 확인일, 이용조건과 표시 의무, 적용 활동, 대체 자료입니다. 원문 인용·현대어 번역·쉬운 재서술·교사의 해석을 구별합니다.

공공기관 자료도 설명이 서로 다르거나 원문과 해설의 범위가 다르면 대조가 필요합니다. 예를 들어 [국립국어원의 창제 설명](https://www.korean.go.kr/hangeul/origin/001.html)은 기록의 문구와 후대의 반포 설명을 구별하는 관점을 제시합니다. 연도·책의 완성·기념일의 유래를 구분해 검토하고, 정확한 반포일이나 특정 의식을 자료로 확인한 것처럼 재현하지 않습니다. 설명 차이는 교사 노트에서 다루고 학생 화면에 확정되지 않은 세부 사실을 추가하지 않습니다.

자료 채택은 아래 순서로 진행합니다.

1. 원문과 공개 설명을 확인하고 앱의 학습 질문에 필요한 부분을 고릅니다.
2. 사실·번역·해석을 구분하고 다른 공식 자료와 필요한 대조를 합니다.
3. 사진·도안·영상의 개별 이용조건을 확인합니다. 불명확하면 링크로 안내하거나 자체 설명·허용된 대체 자료를 사용합니다.
4. 학생이 직접 관찰할 자료와 교사 해설을 구분해 화면에 배치합니다.
5. 같은 자료를 사용하는 발표·학생 화면·PDF의 문항과 해설을 함께 수정합니다.
6. 출처 링크가 막히거나 영상이 재생되지 않을 때의 대안을 확인합니다.

실제 자료 카드에는 자료 이름·출처·자료 종류를 짧게 표시하고 상세 설명은 교사 노트에서 펼칩니다. 모든 배경 삽화에 긴 출처 설명을 덧붙이지는 않되, 증거를 판단하는 활동에서는 사진·문헌·재구성을 눈에 보이게 구분합니다.

새 시각자료는 실제 동검·유적 사진, 필요한 분포 자료, 글자 관찰 도해부터 선정합니다. 사진의 권한을 확인하기 전 앱에 복제하지 않습니다. 이미 승인·수정된 삽화는 재사용을 우선하고, 사건 연결이나 정보 전달에 부족한 부분만 추가 제작합니다.

## 6 기능과 접근성 개선 과제

- 개천절 전역 단축키가 버튼의 Space를 가로채는 문제를 먼저 수정합니다. 버튼·링크·입력·영상은 고유 키 동작을 유지하고 발표 배경에서만 다음 단계 단축키가 작동하게 합니다.
- 교사 도구의 이름·위치를 통일합니다. 활동 선택, 목차, QR, 교사 노트, 출처, 전체 화면, 다시 보기는 두 주제에서 같은 방식으로 찾을 수 있게 합니다.
- 선택한 활동을 이동·재방문해도 의도치 않게 학생 작성 내용이 지워지거나 정답이 먼저 열리지 않도록 상태를 구분합니다. 다른 학년군에 이전 응답이 잘못 섞이지 않는지도 검사합니다.
- QR에는 공개 주소 또는 검증한 교실 네트워크 주소를 사용합니다. 다른 기기에서 접속할 수 없는 localhost 주소는 학생 배포용으로 만들지 않도록 막고 안내합니다. 실제 학생 기기 접속 검사 없이 오프라인 사용이 검증됐다고 표시하지 않습니다.
- 화면의 한 구역에 질문 하나와 관찰 자료를 크게 제시합니다. 원문 전체·작은 해설은 펼치기나 교사 노트로 분리하되 탐구에 필요한 핵심 구절은 학생이 볼 수 있게 남깁니다.
- 학생 화면의 활동 탭 발견성, 키보드 초점, 모달 닫기, 읽어 주기 대안, 동작 줄이기 설정을 확인합니다. 음성 기능이 없는 환경에는 교사 낭독·말하기 대안을 제공합니다.
- 외부 통신과 학생 응답 미수집을 구별해 안내합니다. 새로고침·화면 종료 시 작성 내용의 처리도 실제 동작과 일치하게 설명합니다.
- 큰 이미지·영상은 저용량 대안을 검토하되 품질과 가독성을 함께 확인합니다. 현재 파일 크기만으로 성능 장애를 단정하지 않습니다.

`site/package.mjs`는 `site/dist`를 휴대용 앱으로 복사합니다. 따라서 문서나 원본만 고치고 배포 데이터·출력물을 그대로 두면 변경이 사용자에게 전달되지 않습니다. 반대로 배포 파일만 고치면 생성 시 되돌아갈 수 있으므로 원본부터 반영하고 산출물을 함께 갱신합니다. 패키징은 기존 출력 폴더를 다시 만드는 작업이므로, 사용자 파일 유무와 정확한 출력 경로를 확인한 뒤 수행합니다.

과거 완료 기록·변경 이력은 지우거나 과거 사실을 바꾸지 않습니다. 현행 운영 안내와 과거 설계 자료를 구분하고, 옛 고정 시간 설계에는 현재 계획으로 대체되었다고 표시합니다. 숫자 문자열을 일괄 삭제하지 않고 수업 전제·타이머 의존성·검사 조건을 각각 확인합니다.

## 8 단계별 실행과 검토 지점

### 단계 A 전제와 출처 정리

R01–R05를 진행합니다. 현행 시간 표시·타이머·검사 조건의 전체 위치를 목록화하고 제거합니다. 원문 인용과 연결 출처를 맞추고 키보드·QR 오류를 수정합니다. 새 출처 대장과 활동 데이터 규칙을 확정합니다.

검토 산출물은 변경 목록, 출처 대장, 정상 동작을 확인한 재현 기록입니다. 이 단계가 끝나도 학습 리뉴얼 전체가 완료됐다고 표시하지 않습니다.

### 단계 B 선택 구조와 개천절 시범 구현

R06–R08을 진행합니다. 공통 활동 선택과 안정적인 ID 경로를 만들고, 개선 필요가 가장 구체적인 개천절 세 학년군에 먼저 적용합니다. 실제 근거 카드·자료 종류와 확인 범위·학년별 결과물을 묶어서 검토합니다.

검토 산출물은 선택 화면, 저학년 이야기·역할놀이, 중학년 비교·약속, 고학년 근거·주장 수정의 작동 예시입니다. 교사가 선택한 질문에 필요한 자료가 빠지지 않는지 확인한 뒤 다음 주제로 확장합니다.

### 단계 C 한글날 학습 보강

R09를 공통 구조에 연결합니다. 기존 마음 쪽지·안내문·역사 구분을 유지하고 글자 관찰, 짧은 근거 읽기, 독자 피드백을 보강합니다. 연도 한정 탐구는 선택 자료로 분리합니다.

검토 산출물은 여섯 학년군의 질문–자료–결과물–피드백 대응표입니다. 같은 활동에 질문만 늘린 차별화가 아닌지 확인합니다.

### 단계 D 출력물과 환경 검증

R10–R11을 진행합니다. 앱 내용이 확정된 뒤 관련 PDF와 교사용 안내를 갱신하고 전체 페이지를 렌더링해 확인합니다. 학교망에서 외부 자료가 막히는 경우, 학생 기기가 없는 경우, 키보드만 사용하는 경우를 시험합니다.

검토 산출물은 PDF 검수 기록, 브라우저·기기 검사 결과, 오프라인 패키지 검사 결과입니다. 실제 교실 뒷자리 가독성·학교망·실물 기기는 별도 확인 여부를 명시합니다.

### 단계 E 사용 의견과 공개 반영
