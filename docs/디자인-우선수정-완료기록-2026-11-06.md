# 국경일 수업 앱 우선 디자인 수정 결과

2026년 11월 6일 디자인 점검의 F01–F05를 수정했다. 기존 삽화·영상·학습지와 초록·크림·주황 계열은 유지했다. 작은 글자와 버튼의 명도만 조정하고, 휴대폰에서는 한글날 발표를 세로로 읽도록 배치했다. 큰 화면의 16:9 발표와 교사가 다음 장면을 넘기는 방식은 유지한다.

## 수정 내용

| 항목 | 결과 |
|---|---|
| F01 글자와 버튼 대비 | 공통 보조 글자·강조 버튼의 색을 역할별로 조정했다. 대표 화면 5개의 Lighthouse 텍스트 대비 검사가 모두 통과했다. |
| F02 작은 화면의 발표 글자 | 폭 700px 이하에서 세로 읽기 배치로 전환한다. 320·390px 대표 본문은 16px, 제목은 28px다. 기존 본문은 각각 약 5.47·6.73px였다. |
| F03 학생 버튼 가림 | ‘다른 국경일’ 링크를 문서 흐름 안으로 옮겼다. 390px 학생 화면에서 입력·글자 버튼과의 겹침은 0건이다. |
| F04 긴 교사 안내 | 좁은 화면에서도 안내 문장을 줄바꿈해 표시한다. 이전·다음은 화면 안에 남고 본문 영역은 세로로 스크롤한다. |
| F05 링크 이름 | 첫 화면 수업 카드의 불필요한 접근성 이름 덮어쓰기를 제거해 보이는 문구와 일치시켰다. |

모바일의 장면 진입은 가로 이동 대신 투명도 전환을 사용해 순간적인 가로 넘침을 방지한다. 기존 글자 모션과 영상은 유지한다. 영상 재생 직후 빠르게 일시정지할 때 오류 화면으로 넘어가던 경합도 수정했다. 의도적인 일시정지는 유지하고 실제 재생 실패에는 기존 대체 화면을 제공한다.

## 검증 결과

한글날 발표 114단계를 390px 브라우저에서 순서대로 넘기며 본문 크기, 가로 넘침, 다음 버튼 위치를 측정했다. 320px 대표 장면, 1024px의 16:9 비율, 학생 글자 조합·자료 창 열기와 닫기도 확인했다. 독립 코드 검토에서 발견한 모바일 조합식과 활동 설명의 대비 저하 두 지점을 수정하고 실제 렌더링 색으로 재검사했다.

| Lighthouse 접근성 표본 | 수정 전 | 수정 후 |
|---|---:|---:|
| 첫 화면 | 94 | 100 |
| 한글날 발표 도입 | 96 | 100 |
| 개천절 기록의 성격 | 100 | 100 |
| 한글날 학생 글자 탐험 | 93 | 98 |
| 개천절 학생 자료 비교 | 95 | 100 |

이미지·학습 내용·개천절·발표·리뉴얼·영상 음원 검사 6종과 브라우저 증거 검사를 통과했다. 영상 검사는 재생 대기 중 일시정지와 실제 실패의 대체 화면을 구별하는 회귀 검사를 포함한다. 기존 이미지 24개의 해시와 원본 대비 무손실 픽셀 검증도 유지한다. `assets`, `videos`, `worksheets`의 파일 변경은 없다.

두 오프라인 ZIP에는 새 스타일과 최신 교사용 안내를 포함한다. 검사 원본과 화면은 로컬 `output/design-priority-2026-11-06/`에 보관한다.

Impeccable 정적 탐지 결과는 13건이다. 기존 크림색·그림자·보조 제목에 관한 취향 경고 6건은 색감 유지 요청에 따라 유지했다. 첫 화면 대비 경고 7건은 정적 배경 조합 추정이며, 실제 브라우저의 해당 첫 화면 Lighthouse 대비와 라벨 검사는 통과했다. 정적 탐지 결과를 전체 무결함 판정으로 사용하지 않는다.

## 배포 상태

로컬 수정과 검증을 완료했다. 공개 사이트와 GitHub의 배포 결과는 업로드 후 이 항목에 기록한다.

## 남은 개선 범위

F06 제목 단계와 탭 선택 상태, F07 첫 화면의 수업 진입점, F08 공통 조작부 규칙, F09 개천절 자료 읽기 흐름은 다음 개선 대상으로 남긴다. 한글날 학생 표본의 98점에는 기존 제목 단계 문제가 반영돼 있다.

이번 결과는 Chromium 브라우저와 자동 검사 범위다. 실물 전자칠판·학생 기기, iOS Safari, 스크린리더, 운영체제 고대비와 모션 감소 설정은 별도 확인이 필요하다. 전체 접근성 인증이나 모든 환경의 무결함을 뜻하지 않는다. 증거 검사 CLI는 선택 입력을 생략할 수 있지만 이번 검증에는 114단계와 Lighthouse 보고서 5개를 모두 전달했다.
