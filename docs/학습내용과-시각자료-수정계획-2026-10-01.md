# 국경일 교육 앱 학습내용과 시각자료 수정계획

작성일: 2026년 10월 1일

학습내용 검토 보고서를 바탕으로 그림과 사건의 대응, 자료가 함께 있는 질문, 디지털 활동과 인쇄 학습지의 연결을 보완한다. 기존 선택형 수업과 활동 ID를 유지하고, 고정 수업 시간은 다시 도입하지 않는다. 이번 범위는 로컬 앱과 오프라인 패키지이며 공개 사이트 배포는 포함하지 않는다.

## 이미지와 모션 제작

사건을 알아보기 어려운 풍경 그림을 대신할 이야기 카드 네 장을 기본 이미지 생성 도구로 제작한다. 그림은 어린이용 전승 삽화이며 실제 인물과 복식 또는 특정 발굴터의 복원이라고 설명하지 않는다. 카드에는 글자를 생성하지 않고 앱과 학습지의 실제 텍스트로 제목과 설명을 제공한다. 기존 풍경과 마을 이미지는 분위기 및 재구성의 한계 설명에 재사용한다.

글자 조합과 자료 강조는 기존 HTML과 CSS를 보완한다. 교사나 학생의 버튼 조작으로만 공개하며 동작 줄이기 설정에서는 움직임 없이 표시한다. 새 장식 영상은 제작하지 않는다.

실제 해례본 지면과 고인돌 사진은 개별 자료의 이용 조건과 판독 가능성을 확인한 경우에만 앱에 저장한다. 확인되지 않은 자료는 공식 원본 링크로 제공하고, 채택하지 못한 이유를 결과에 기록한다.

## 조사 근거와 적용 한계

- [국사편찬위원회 삼국유사 원문과 번역](https://contents.history.go.kr/front/hm/view.do?levelId=hm_001_0010): 100일의 약속과 21일의 변화 서술을 비교하는 근거다. 수업용 풀이는 인용문과 구분한다.
- [국립중앙박물관 송국리 동검](https://www.museum.go.kr/MUSEUM/contents/M0502000000.do?relicId=2040&schM=view&searchId=search): 실제 사진과 소장품 정보를 구별하여 읽는다. 출토지를 곧바로 고조선의 국경으로 해석하지 않는다.
- [국립국어원 한글의 탄생](https://www.korean.go.kr/hangeul/origin/001.html): 창제와 책의 완성, 정확한 반포 행사의 확인 범위를 교사용 설명에서 구별한다.
- [국립국어원 한글의 구성](https://www.korean.go.kr/hangeul/principle/001.html): 글자 조합 관찰의 근거다.
- [참쌤스쿨 계기교육 자료](https://chamssaem.com/482), [몽당분필 한글날 자료](https://mdbftv.tistory.com/242): 공개 소개에 나타난 이야기 표현과 손으로 만드는 활동 구성을 참고했다. 제작자의 도안을 복제하지 않으며 첨부자료 전체나 수업 효과를 검증했다고 표현하지 않는다.

## 별도 후속 과제

선택 활동만 자동으로 묶어 인쇄하는 기능, 실제 전자칠판 및 학생 기기의 교실 검증, 한글날 제정 100주년 특집, 공개 배포는 별도 과제다. 이번 수정은 학습 효과의 실증을 뜻하지 않는다.

## 실행 결과

로컬 앱·학습지 수정 완료. 공개 사이트에는 배포하지 않았다.

- 생성 이미지 스킬로 이야기 카드 네 장을 제작하고, 환웅 그림의 불필요한 동행 인물과 날개 표현을 고쳤다. 네 사건과 같은 그림을 교사·학생·인쇄물에 적용했다. [정확한 프롬프트와 파일 기록](../knowledge/이야기카드-이미지-제작기록.md)을 남겼다.
- 삼국유사 발췌와 수업용 풀이를 질문 옆에 제공하고 100일의 약속과 21일의 변화 서술을 비교한다. 동검은 사진 관찰·소장품 설명·확인 불가능한 점으로 나누었다.
- 활동 선택 카드에 목표·결과물·피드백 기준을 표시하고, 추천 선행 자료를 강제 선택 없이 열 수 있게 했다. 기존 활동 ID와 저장된 선택 경로를 유지한다.
- 중학년 개천절 자료 비교와 고학년 근거·한계·수정 칸, 한글날 독자 질문·최종 수정 칸을 추가했다. PDF 스킬의 렌더 검수 절차로 12종 총 26쪽을 확인했다. 개천절 고학년은 쓰기 공간을 위해 3쪽으로 늘렸다.
- 고창 고인돌 실제 사진은 CC BY-SA 3.0 저자·출처·조건을 표시했다. 해례본 지면은 1446년 실물 사진이 아닌 1946년 조선어학회 석판 영인본으로 명시했다. [이용 조건과 서지 정보](../knowledge/리뉴얼-출처대장.md)를 기록했다.
- 개천절 도입 영상의 환웅·단군 그림과 청동기 설명·자료 비교 자막을 수정해 재생성했다. 7·17·27·52초 프레임을 확인했다. 영상은 1920×1080, 60초이며 음성 내레이션 없이 기존 배경음악을 사용한다.
- 자동 검사 다섯 가지와 PDF 검사를 통과했다. 한글날 발표 단계 114개, 기존 선택·순서 변경·이어서 보기·QR 주소 방어·키보드 가드를 검사했다.
- 브라우저에서 1024×768 교사 화면과 390×844 학생 화면을 확인했다. 이야기 오답·정답·다시 고르기, 입력의 탭 이동 후 유지, 빈 선택의 시작 차단, 추천 자료를 열고 돌아와도 선택 목록 유지, 실제 사진과 영인본 표시를 확인했다. 검증 브라우저 오류 로그는 비어 있었다. Playwright 검증 세션 모듈 오류로 제공된 브라우저 제어 기능을 사용했다.
- [최종 이야기 카드 화면](../output/renewal/story-cards-2026-10-01.png)을 저장했다. 오프라인 패키지는 수정 파일을 포함하도록 빌드 목록과 출처 문서 복사를 보강했다.
- 추가 모바일 검수에서 긴 활동 탭의 오른쪽 글자가 가려지는 문제를 고쳤다. 480px 이하에서 세 탭을 같은 폭으로 배치한다. 두 ZIP은 무결성과 현재 앱·이미지·PDF·영상·기록 문서의 해시 일치 검사를 수행한다.

실제 교실의 학습 효과, 전자칠판 뒤쪽 가독성, 다른 학생 기기의 QR 접속은 미검증이다. 입력은 현재 화면의 메모리에만 남으며 새로고침하면 사라진다. 선택 활동별 자동 인쇄 묶음·제정 100주년 특집·공개 배포는 이번 범위에 넣지 않았다.

## 브라우저와 PDF 검사 목록

- 네 이야기 카드의 오답 순서와 다시 고르기 및 정답 순서를 확인한다. 키보드 선택이 발표 넘김과 충돌하지 않아야 한다.
- 선택 화면의 목표와 결과물 및 확인 기준을 읽고, 먼저 보면 좋은 자료를 열어도 저장된 선택 목록을 바꾸지 않아야 한다.
- 학생 자료 비교의 발췌문과 사진 및 설명이 외부 접속 없이 보이며 입력 후 탭을 바꾸었다 돌아와도 남아 있어야 한다.
- 해례본 지면은 영인본 표기와 풀이가 함께 보이고, 고인돌은 실제 사진과 재구성의 출처가 구별되어야 한다.
- 교사 발표 화면은 1024 곱하기 768, 학생 활동은 390 곱하기 844에서 중요한 조작과 제목 및 자료의 잘림을 검사한다. 학생 활동의 세로 스크롤은 허용한다.
- PDF 12종 총 26쪽의 이미지와 한글 및 한자, 작성 칸과 페이지 번호 및 하단 잘림을 확인한다.
- 예외 검사로 이야기의 잘못된 순서와 빈 활동 선택 및 단일 선행 자료 열기 후 목차 복귀를 검사한다.
- 수정된 영상의 환웅과 단군 장면 및 청동기 자료 설명과 마지막 비교 장면을 추출해 확인한다.

## 2026-10-01 공개 배포 확인

사용자의 공개 배포 요청에 따라 위의 로컬 수정본을 [주 공개 사이트](https://holiday.mumuworld.com/)와 [GitHub Pages 미러](https://reinhardt7177-lab.github.io/hangeul-classroom/)에 배포했다. 앞의 미배포 안내는 이 배포 전의 기록이다.

Cloudflare 배포 버전은 `ed61fed4-1fef-4630-90fa-9d650b4b9d63`이며, 사이트 소스 커밋은 `cfd11583a8a0a80c063cd8094a6eb68f5ccb0081`이다. [GitHub 검증·배포 실행](https://github.com/reinhardt7177-lab/hangeul-classroom/actions/runs/36814383540)이 성공했다. 영상 주소에 버전 질의문을 붙여 브라우저에 이전 영상이 남는 문제를 예방했다.

두 공개 주소에서 각각 배포 파일 83개를 대조했다. 이미지·영상·학습지 등 바이너리 파일은 SHA-256 해시가 일치하며, GitHub의 일부 텍스트 파일은 Windows와 Linux의 줄바꿈 차이만 있다. 두 주소 모두 영상 부분 요청에 206 응답과 정확한 1,024바이트를 반환했다. 공개 브라우저에서는 새 이야기 카드 네 장과 순서 설명, 학생 QR의 공개 주소, 60초 도입 영상의 실제 재생을 확인했다. 상세 결과는 `output/deployment/public-verification-cloudflare-2026-10-01.json`과 `output/deployment/public-verification-github-2026-10-01.json`에 저장했다.

실제 교실의 다른 학생 기기에서 QR을 여는 검사와 교실 실증은 여전히 남아 있다. 공개 앱 배포와 별개로 GitHub Releases의 ZIP 첨부 파일은 이번 배포에서 갱신하지 않았다.
