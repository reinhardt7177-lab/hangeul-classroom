# 한국문화 시각 고증 — 필수 제작 기준

> 사용자 확정 조건: **대한민국의 역사·문화 교육 자료. 중국풍 표현을 철저히 배제한다.**  
> 적용 범위: 첫 화면, 모든 삽화·배경·인물·도구·영상 선정·모션·평가 그림·인쇄물.

## 1. 제작 방향

한국사의 구체적인 시대·장소·자료를 출발점으로 삼습니다. ‘동양풍’, ‘아시아 전통’, ‘오리엔탈’, ‘판타지 궁궐’ 같은 모호한 지시로 역사 장면을 생성하지 않습니다.

중국 궁궐·정원·복식·관모·무협·선협의 시각 관습을 한국 배경의 장식으로 끌어오지 않습니다. 중국식 기와·복식·장식 요소를 피했다고 해서 곧 한국 고증을 통과한 것으로 보지 않고, **한국 자료와의 일치 여부를 별도로 확인**합니다.

## 2. 한글날에 적용할 기준

- 시대가 필요한 장면은 조선 전기, 세종 재위기 안에서 구체적인 시점을 설정합니다.
- 궁궐은 한국 공식 자료를 바탕으로 구성하며, 현재 경복궁의 후대 건물을 1443년의 사실적 배경으로 단정하지 않습니다.
- 세종의 복식·관모·신분 표식은 장면 시점에 맞는 자료로 확인합니다. 후대 의복 실물을 그대로 세종 개인의 의복으로 옮기지 않습니다.
- 중국 황제의 복식, 청대 관모·변발, 중국 관료의 모자, 자금성·만리장성·중국 사찰풍 배경 등을 넣지 않습니다.
- 서책·제본·붓·벼루·책상은 조선 관련 근거를 확인합니다. 서양식 중앙 제본 책을 조선의 실물 서책처럼 사용하지 않습니다.
- 실제 훈민정음 사료에 있는 글자는 원자료 그대로 다룹니다. **한국 역사 사료에 포함된 한문 원문**과 **근거 없이 덧붙인 중국풍 장식**은 구분합니다. 원문을 고치거나 임의의 한자로 꾸미지 않습니다.
- 생성한 세종 얼굴은 상상 표현임을 밝히고 실제 얼굴을 정확히 복원했다고 설명하지 않습니다.

## 3. 개천절에 적용할 기준

- 단군 건국 이야기의 인물·관계·순서를 한국의 공식 역사 해설과 대조합니다.
- 환웅·웅녀·단군을 모호한 도사·신선 캐릭터 하나로 합치지 않습니다.
- 중국 선협·무협 의상, 도사 모자, 중국식 황궁, 날아다니는 검, 중국 사찰·무술 상징 등 무관한 요소를 넣지 않습니다.
- 화려한 왕관·지팡이·문양을 역사적 근거 없이 창작한 뒤 실존 복식으로 설명하지 않습니다.
- 산·숲·생활 공간도 한국 문화 맥락을 벗어난 이국적 장식으로 채우지 않습니다.
- 신화 장면은 **‘단군 건국 신화를 상상하여 표현한 그림’**으로 표시합니다. 특정 연도의 실제 사진·유적 복원도처럼 제시하지 않습니다.
- 생생한 화풍은 가능하지만, 근거 없는 고조선 궁궐·복식 세부를 확정된 사실처럼 표현하지 않습니다. 필요하면 인물 클로즈업보다 상징적·서사적 구도로 불확실성을 줄입니다.

## 4. 생성 프롬프트의 고정 구조

```text
교육 주제: 대한민국의 [한글날 / 개천절]
이미지 종류: [자료 참고 재현 / 신화 상상 장면 / 현대 한국 교실 / 상징 삽화]
구체적인 시대·장소: [확인된 범위]
인물과 역할: [한국 자료에 근거한 관계·행동]
복식·관모·건축·도구: [공식 참고 자료에 맞춘 구체적 특징]
학생이 관찰할 단서: [이 그림으로 배우는 내용]
참고 자료: [기관·자료명·시대]
불확실한 부분: [생략하거나 상상 표현임을 표시할 요소]
문자 처리: 원문·날짜·자모는 확인한 자료 또는 화면 텍스트로 따로 배치
금지 요소: 중국 궁궐·복식·관모·중국식 무협/선협 표현, 일본·기타 문화의 혼입,
           시대가 다른 소품, 불명확한 동양풍 장식, 가짜 역사 문서·가짜 글자
검수: 생성 결과를 한국 공식 자료와 대조한 뒤 채택
```

부정어 목록만 길게 넣는 방식에 의존하지 않습니다. 만들고자 하는 **한국의 구체적인 모습**을 먼저 설명하고, 필요한 경우 확인된 참고 이미지를 사용합니다.

## 5. 채택 전 검수표

| 항목 | 통과 조건 |
|---|---|
| 문화 식별 | 한국의 시대·장소·대상을 명확히 설명할 수 있다 |
| 건축 | 지붕·처마·장식·공간 구성의 근거가 있고 다른 문화 건축이 섞이지 않는다 |
| 인물 | 역할과 인물 관계가 수업의 이야기와 맞는다 |
| 복식·관모 | 시대와 신분에 맞는 근거를 기록했다 |
| 서책·문자 | 잘못된 제본·가짜 원문·자모 오류가 없다 |
| 생활 도구 | 용도·재료·시대가 어긋나지 않는다 |
| 신화 표시 | 상상 장면임을 학생도 알 수 있다 |
| 선택지 공정성 | 특정 문화의 외양에 대한 편견이나 국적 추측으로 정답을 유도하지 않는다 |
| 교사 설명 | 검증된 사실과 재현·추정을 구분한다 |
| 최종 판단 | 근거가 부족하거나 혼입이 의심되면 보류하고 수정·교체한다 |

## 6. 현재 이미지의 상태
