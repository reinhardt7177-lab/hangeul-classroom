# 한글날 제정 100주년 특집 계획

작성일과 공개 자료 확인일은 2026년 10월 1일이다. 대상은 현재 공개된 국경일 교육 앱의 초등 1–2학년, 3–4학년, 5–6학년 수업이다. 이 문서는 특집의 학습내용, 시각자료, 기능, 제작 순서와 검수 기준을 제안하는 계획서다. 특집 화면이나 새 이미지·영상·PDF를 제작했다는 완료 기록은 아니다.

권장 방향은 **기념일이 만들어지고 이어진 과정을 자료로 살피고, 오늘의 우리가 한글로 무엇을 나눌지 표현하는 특집**이다. 기존 창제 목적·글자 원리·독자 피드백 수업을 유지하면서 별도 특집으로 연결한다. 후속 요청에 따라 활동 선택 화면 없이 학년별 모든 장면을 기본 순서로 제공하며, 고정 수업 시간·배정 타이머·모든 결과물의 의무 제출은 두지 않는다. 공통 화면 운영은 [전체 장면 진행과 학습지 해설 버튼 수정 계획](전체장면-진행과-학습지-해설-버튼-수정계획-2026-10-01.md)을 따른다.

## 1 특집의 핵심 개념과 역사 기준

2026년의 100주년은 **1926년 가갸날로 한글날을 기념하기 시작한 역사**를 기준으로 한다. 한글을 1926년에 만들었다거나 현재의 국경일 지위가 100년 되었다는 뜻이 아니다. 국립한글박물관은 같은 해를 훈민정음 반포 580돌로도 안내한다. 두 숫자는 출발 사건이 다르므로 하나의 생일처럼 묶지 않는다. [2026년 공식 전시 안내](https://hangeul.go.kr/exhibition/676?curr_menu_cd=0102020000&page=1&searchCondition=&searchKeyword=), [2026년 한글의 해 안내](https://www.hangeul.go.kr/webzine/202602/sub1_2.html).

| 구분 | 학생에게 제공할 사실 | 설명에서 지킬 경계 |
|---|---|---|
| 1443년 | 세종이 새 문자를 창제했다 | 현재 한글날을 정확한 창제일로 설명하지 않는다 |
| 1446년 | 훈민정음을 설명하는 책이 완성되었다. 수업에서는 반포를 기념하는 해로 구별한다 | 특정 날짜의 반포식이나 군중 행사를 확인한 것처럼 재현하지 않는다 |
| 1926년 | 11월 4일에 가갸날 기념식이 열렸다 | 당시 양력 날짜를 지금의 10월 9일로 바꾸어 표시하지 않는다 |
| 1928년 | 가갸날의 이름이 한글날로 바뀌었다 | 명칭 변경과 한글 창제를 같은 사건으로 다루지 않는다 |
| 1945년 | 해방 후 10월 9일에 공개 기념식을 열었다 | 그해에 문자가 생겼다거나 새로운 기록에 정확한 반포식 날짜가 적혀 있었다고 설명하지 않는다 |
| 2026년 | 한글날 제정 100주년을 기념한다 | 창제·책의 완성·기념일 제정을 구별한다 |

창제와 책의 완성 및 정확한 날짜의 한계는 [국립국어원 설명](https://www.korean.go.kr/hangeul/origin/001.html)을 따른다. 1926년 첫 기념은 [국립한글박물관 2026년 기사](https://www.hangeul.go.kr/webzine/202603/sub1_1.html), 1928년 명칭 변경은 [박물관의 기념일 역사 설명](https://www.hangeul.go.kr/webzine/201810/sub1_1.html), 1945년 공개 기념은 [국립국어원 한글날 유래](https://www.korean.go.kr/nkview/news/10/102.htm)로 확인했다. 1928년의 세부 변경 일자는 기관 자료 간 차이가 있어 학생 자료에는 연도만 쓴다.

학생용 공통 질문은 “한글은 오래전에 만들었는데, 왜 기념일의 100주년이라고 할까요?”로 제안한다. 저학년은 숫자 계산 대신 ‘글자를 만든 일’과 ‘기념하는 날을 정한 일’의 그림 카드를 나눈다. 중·고학년은 사건과 출처를 함께 연결한다.

## 2 공개 자료와 비교한 특집의 역할

공식 특별전은 기념일의 변화, 한글을 배우고 쓰는 문화, 앞으로의 한글을 함께 다룬다. 우리 앱은 이를 초등학생의 **관찰·자료 비교·다른 사람에게 설명·수정**으로 바꾸어 적용한다. 박물관 전시를 복제하거나 공식 전시와 제휴한 서비스처럼 표시하지 않는다. 아래의 활동은 자체 설계 제안이다. [공식 특별전의 구성](https://hangeul.go.kr/exhibition/676?curr_menu_cd=0102020000&page=1&searchCondition=&searchKeyword=).

현재 앱은 창제 목적과 글자 원리, 해례본 지면, 읽기 쉬운 안내문에 강점이 있다. 새 특집은 여기에 ‘왜 기념했는가’, ‘날짜와 이름은 왜 달라졌는가’, ‘우리는 어떻게 이어 갈 것인가’를 추가한다. 같은 창제 설명을 긴 영상으로 반복하는 것이 목표는 아니다.

첫 구현에서는 연표와 자체 도해, 출처가 있는 짧은 설명만으로 핵심 활동이 가능해야 한다. 옛 신문이나 기념식 사진의 재배포 조건이 해결되지 않아도 활동을 중단하지 않도록, 해당 이미지는 보강 자료로 둔다.

## 3 학년별 활동

공통 도입은 ‘두 출발점 구별하기 → 가갸날 알아보기 → 기념일 변화 살피기 → 오늘의 참여 생각하기’의 네 장면으로 제안한다. 실제 화면 수는 가독성 검수 후 확정한다. 아래 활동은 학년별로 두 개씩 준비하고 공통 도입부터 기본 순서로 모두 제공한다. 활동 선택 창은 두지 않는다.

| 학년과 활동 | 중심 질문과 자료 | 학생 결과물 | 피드백 기준 |
|---|---|---|---|
| 1–2학년 가갸날 이름 놀이 | 왜 ‘가갸’라고 불렀을까? 자체 제작한 가·갸·거·겨 낱자 카드와 짧은 역사 설명 | 낱자를 조합하고 기념일의 옛 이름을 말·그림으로 설명 | 소리·글자 놀이와 역사적 이름을 연결하되 날짜 암기는 요구하지 않음 |
| 1–2학년 마음을 나누는 기념 카드 | 한글로 누구에게 어떤 마음을 전할까? 기존 쪽지 활동과 연결 | 그림과 한두 낱말로 만든 카드, 받는 사람의 반응 | 상대가 뜻을 알아들었는지 확인하고 낱말 또는 그림 한 부분을 고침 |
| 3–4학년 기념일 변화 카드 | 만든 해와 기념하기 시작한 해는 왜 다를까? 사건 카드와 자체 연표 | 창제·책의 완성·첫 기념·이름 변화 카드 분류와 이유 | 연도만 맞히지 않고 각 사건이 무엇을 뜻하는지 설명 |
| 3–4학년 작은 기록 전시 | 옛 기념 자료와 오늘의 기념 방식은 어떻게 다를까? 출처를 표시한 역사 설명과 학생용 가상 행사 사례 | ‘자료에서 알게 된 점 / 오늘의 제안’이 나뉜 전시 카드 | 과거 사실과 학생의 제안을 구별하고 짝의 질문 후 설명을 수정 |
| 5–6학년 날짜를 정한 근거 읽기 | 기록에 적힌 시기와 기념일 날짜는 같을까? 실록·해례본 시기 설명과 기념일 해설 | 주장·자료 근거·확인할 수 없는 점·수정한 설명 | ‘9월 상순’이 정확한 반포식 날짜를 입증한다는 오개념을 고침 |
| 5–6학년 다음 기념일 안내 설계 | 누구나 이해하고 참여할 수 있는 안내는 무엇일까? 자체 만든 가상 행사 안내문 | 핵심 정보를 유지한 안내문, 독자 질문, 수정 이유 | 시간·장소·참여 방법의 정확성과 독자의 이해를 함께 확인 |

기념 카드·전시 카드·안내문에는 실제 학생 이름, 얼굴, 연락처를 요구하지 않는다. 말하기·종이·그림 응답도 같은 학습목표로 인정한다. 안내문은 수업용 가상 사례임을 명시하고 박물관의 실제 행사 정보처럼 보이게 하지 않는다.

기본 수업 연결은 저학년 ‘마음 쪽지’, 중학년 ‘글자 조합과 창제·반포 구분’, 고학년 ‘해례본 근거 읽기와 독자 피드백’으로 제안한다. 필요한 근거 자료는 해당 장면에서 제공하며 별도 활동 선택 목록을 만들지 않는다.

## 4 필요한 시각자료와 제작 방식

| 자료 | 제작 제안 | 쓰임과 우선순위 |
|---|---|---|
| 두 출발점 비교 도해 | ‘문자를 만든 역사’와 ‘기념일의 역사’를 자체 SVG와 실제 텍스트로 구분 | 100주년 오개념 방지에 필수 |
| 기념일 연표 | 창제·책·첫 기념·명칭 변화·공개 기념·100주년을 사건 카드로 구성. 간격은 시간 비례가 아닌 사건별 배열임을 표시 | 중·고학년 비교와 교사용 설명에 필수 |
| 가갸 낱자 조합 도해 | 가·갸·거·겨를 실제 글자와 조작 버튼으로 구성. 기존 로컬 한글 글꼴 사용 | 저학년 이름 놀이에 필수 |
| 기록과 풀이 비교 카드 | 자료명·작성 시기·확인 범위·수업용 풀이를 함께 표시 | 고학년 근거 탐구에 필수 |
| 기념 카드와 작은 전시 틀 | 자체 제작한 여백 중심의 카드. 사실과 나의 제안에 별도 칸 제공 | 학년별 결과물 제작에 필수 |
| 특집 대표 삽화 | 현대 교실에서 글로 마음을 나누는 장면 한 장을 새로 제작하거나 기존 교실 삽화 재사용 | 분위기를 위한 선택 자료. 역사 증거로 사용하지 않음 |
| 실제 옛 신문과 기념 자료 | 소장기관의 개별 자료와 권리·판독 상태를 확인한 뒤 채택 | 조건 확인 후 보강. AI로 가짜 신문·기념식 사진을 만들지 않음 |

실제 신문 이미지를 쓸 경우 기사 날짜, 지면, 소장처, 원본 주소, 이용 조건을 출처대장에 남긴다. 원문 이미지와 현대어 풀이를 나란히 두되 풀이를 원문처럼 표시하지 않는다. 자료가 공개되어 있다는 이유만으로 이미지의 자유로운 복제·크롭·색 변경을 허용된 것으로 간주하지 않는다.

기존 해례본 이미지는 **1946년 석판 영인본**임을 유지한다. 현재 파일이 정인지 후서의 날짜 구절까지 보여 주는지 별도로 확인하고, 해당 구절이 보이지 않으면 이 지면으로 날짜를 확인한 것처럼 연결하지 않는다. 후서 지면을 추가할 때도 서지와 이용 조건을 새로 검수한다. [기존 출처대장](../knowledge/리뉴얼-출처대장.md).

## 5 타이포그래픽과 모션 계획

권장 모션은 정답을 대신 알려 주는 장식이 아니라 사건의 구별과 자료 비교를 돕는 짧은 변화다. 아래 길이는 수업 시간이 아니라 화면 효과의 제작 제안이다.

- 특집 제목은 ‘1926 → 2026’과 ‘한글날 제정 100주년’을 실제 텍스트로 배치한다. 연도 확대·제목 나타남은 교사 재생 버튼으로 시작하며 자동 반복하지 않는다.
- ‘가갸날’ 카드에서 ‘한글날’ 카드로 전환할 때 두 이름과 1928년 표기를 함께 남긴다. 글자를 지워 과거 이름이 사라진 듯 보이게 하지 않는다. 전환은 약 1–2초로 제안한다.
- 연표는 교사가 다음 사건을 눌렀을 때 한 카드씩 강조한다. 일정 속도로 100년을 자동 통과하는 영상이나 빠른 숫자 카운터는 쓰지 않는다.
- 낱자 조합은 선택한 자음·모음이 합쳐지는 과정만 짧게 보여 준다. 실제 글자 조합 규칙을 검증하며 음성 안내를 필수로 삼지 않는다.
- 모션 끄기와 `prefers-reduced-motion`에서는 동일 정보를 정지 화면으로 제공한다. 키보드·터치로 같은 결과에 도달하고 색만으로 사건 종류를 구분하지 않는다.

첫 구현은 SVG·CSS·텍스트 기반으로 제안한다. 영상 파일이나 Skia 렌더는 필수 의존성으로 추가하지 않는다. 후속 선택 과제로 1926년 기념의 시작과 오늘의 참여를 연결하는 짧은 도입 영상을 제작할 수 있다. 영상에는 자막·대본·정지 이미지 대체본을 제공하고, 내레이션·배경음악은 권리와 제작 범위를 정한 뒤 별도로 진행한다.

## 6 앱 연결과 기능 계획

기본 수업의 활동 ID·번호형 링크를 보존하고 특집의 상태가 기본 수업에 섞이지 않도록 별도 페이지와 별도 데이터로 분리하는 방식을 우선 제안한다. 다음 이름과 주소는 구현 시 검토할 제안이며 현재 존재하는 특집 주소가 아니다.

- 진입점: 국경일 첫 화면의 한글날 카드 옆에 특집 링크, 한글날 첫 화면에 ‘제정 100주년 특집’ 버튼을 추가한다. 기존 기본 수업을 대체하거나 특집으로 자동 이동시키지 않는다.
- 제안 페이지: `site/dist/hangeul-centenary.html`. 공개 경로 후보는 `/hangeul-centenary.html`, 미러는 저장소 하위 경로를 유지한다.
- 제안 원본: `content/hangeul-centenary-data.js`. 배포 데이터와 학습지 생성기가 같은 사실·문항·출처를 읽도록 설계한다.
- 공통 기능: 학년별 전체 장면 이동과 학습지·해설 창, `activity-qr.js`의 공개 주소 방어 기능을 적용한다. 독립 활동 ID를 사용하고 활동 선택 목록은 만들지 않는다. 기존 공통 코드의 두 주제 전용 분기를 검토해 기본 수업에 영향을 주지 않도록 한다.
- 학생 기능: 활동별 탭 이동 중 입력 유지, 정답·예시의 단계적 공개, 다시 고르기, 말·그림·종이 대체 안내를 제공한다. 새로고침 시 입력이 사라지는 범위를 분명히 알린다.
- 자료 기능: 각 활동에 목표·결과물·피드백·연결 출처를 표시한다. 핵심 학습은 외부 동영상·사이트 접속 없이 가능하도록 만든다.
- 개인정보: 학생 응답을 서버나 분석 서비스에 자동 전송하지 않는다. 자동 공개 갤러리·이름별 순위·외부 로그인은 추가하지 않는다.
- 배포: `site/package.mjs`의 명시적 복사 목록에 새 페이지·데이터·코드·자료를 반영한다. 한글날 및 통합 ZIP 생성기, 새 PDF 생성기와 검증도 함께 맞춘다. 배포 폴더만 직접 고치지 않는다.

2026년 안내와 상시 역사 자료를 구분한다. 행사 배너에는 확인일을 표시하고 종료 뒤에는 ‘2026년 기념 기록’으로 바꾸는 운영 절차를 둔다. 기기 날짜만으로 특집 링크를 숨기거나 수업 도중 화면을 전환하지 않는다.

## 7 학습지와 교사용 안내

새 특집 학습지는 세 학년군의 학생용과 교사용으로 **6종**을 제안한다. 기존 12종 학습지의 파일과 링크는 유지한다. 페이지 수는 쓰기 공간과 렌더 검수 후 확정하며, 기존 26쪽을 유지해야 한다는 이유로 새 활동을 좁은 칸에 넣지 않는다.

학생용은 저학년 기념 카드, 중학년 사건 분류·자료와 제안 비교, 고학년 주장·근거·한계·독자 질문·수정 칸을 중심으로 구성한다. 교사용에는 사실 기준, 오개념 대응, 열린 답의 허용 범위, 자료 이용 조건과 기기 없는 대체 활동을 넣는다. 화면과 PDF의 정답·출처·영인본 표기를 같은 원본에서 생성한다.

## 8 제작 순서와 완료 조건

단계의 선후관계는 유지하되 수업 분량이나 특정 배포일을 확약하지 않는다. 10월 9일 전 제공이 필요하다면 핵심 기능을 먼저 완성하고 영상·추가 사진·심화 활동은 후속으로 분리한다.

| 단계 | 작업과 산출물 | 다음 단계로 넘어갈 조건 |
|---|---|---|
| 1 내용 확정 | 역사 사실표, 세 학년군 6활동, 문항·자료·교사 풀이의 대응표 | 100주년의 기준과 날짜 해석의 한계가 모든 화면에서 일치 |
| 2 핵심 구현 | 특집 진입, 전체 장면 이동·학습지 해설 창, 두 출발점 도해·연표·낱자 조합, 학생 응답 | 기존 수업 회귀 검사 통과, 외부 접속 없이 핵심 활동 가능 |
| 3 시각 표현 보강 | 대표 삽화 선택, 비교 카드·전시 틀, 교사 재생 모션 | 자료 성격과 출처 표기, 정지 화면·키보드·모바일 동등성 확인 |
| 4 인쇄와 안내 | 6종 학습지, 교사용 특집 안내, 출처대장 | 모든 PDF 페이지 렌더 확인, 앱과 문항·정답·출처 일치 |
| 5 환경 검증 | 브라우저·QR·기존 수업·오프라인 패키지 검사 기록 | 아래 검수 항목 통과. 실제 교실 미검증 사항은 별도로 표시 |
| 6 공개 반영 | 주 사이트·미러·오프라인 파일 버전 대조, 변경 안내 | 사용자 배포 요청 확인 후 실제 공개 주소에서 재검사 |

첫 제공의 필수 범위는 역사 기준, 공통 도입, 학년별 6활동, 필수 자체 도해, 전체 장면 이동·학습지 해설·QR·정지 모션 대체, 6종 PDF와 출처다. 실제 옛 신문 사진, 새 영상·내레이션, 맞춤 인쇄 묶음은 이 첫 제공의 완료를 막지 않는 후속 과제로 제안한다.

## 9 검수 기준

- [ ] 제목·본문·정답·교사 노트·PDF에서 창제, 책의 완성, 기념일 제정을 혼동하지 않는다.
- [ ] ‘100주년’이 어떤 사건부터 센 것인지 학생이 말·그림·글 중 한 방식으로 설명할 수 있다.
- [ ] 1926년의 11월 4일과 현재의 10월 9일을 같은 당시 날짜로 설명하지 않는다.
- [ ] 사료의 작성일·기사 수록일·기념일 날짜와 정확한 행사 날짜를 구별한다.
- [ ] 자료에서 읽은 내용과 학생의 해석·느낌·미래 제안을 구별한다.
- [ ] 실제 역사 사진·영인본·자체 도해·생성 삽화의 성격과 권리가 표시되어 있다.
- [ ] 틀린 카드 분류의 피드백, 첫 장면부터 마지막 장면까지 전체 이동, 입력 유지와 초기화를 검사했다.
- [ ] 입력란·조합 버튼·영상의 Space 조작이 발표 넘김과 충돌하지 않는다.
- [ ] 1024×768 교사 화면과 390×844 학생 화면에서 제목·자료·탭·핵심 조작이 가려지지 않는다.
- [ ] 모션 끄기·키보드·종이 참여와 온라인 참여가 같은 목표를 확인한다.
- [ ] 특집 QR이 올바른 학년과 학생 활동에 연결되고 localhost·파일 주소를 공개 주소처럼 안내하지 않는다.
- [ ] 기존 개천절·한글날 활동 ID, 전체 장면 경로, 발표 단계와 PDF 링크가 유지된다. 기존 자동 검사 5종에 새 특집 검사를 추가한다.
- [ ] 모든 새 PDF 페이지를 렌더링했고, 화면·인쇄·오프라인 패키지의 내용이 일치한다.
- [ ] 공개 반영 시 주 사이트와 미러의 새 자산·영상 부분 응답·QR을 확인하고, 별도 학생 기기의 접속 여부를 기록한다.

기능 검사 통과를 학습 효과의 실증으로 표현하지 않는다. 교실 검토에서는 연도 암기 점수보다 사건을 구별하는 설명, 자료를 가리키는 근거, 짝의 질문 뒤 수정한 표현을 살핀다.

## 10 후속 선택 확장

훈맹정음도 2026년에 100주년을 맞는다. 관련 역사는 공식 박물관 자료에서 확인할 수 있지만, 한글날 제정과는 별개 사건이므로 추가 심화 카드로 제안한다. [국립한글박물관의 2026년 설명](https://www.hangeul.go.kr/webzine/202603/sub1_1.html).

이를 확장한다면 ‘같은 정보를 서로 다른 방식으로 읽기’에 초점을 둔다. 화면의 점 그림을 만지는 실제 점자와 같은 체험으로 표현하지 않고, 눈을 가리는 장애 체험을 필수 활동으로 만들지 않는다. 실제 한글 점자 배열·약자·표기 규칙은 전문 자료와 검토를 거친 뒤 제공한다. 첫 구현에서는 큰 글자·명확한 설명·읽기 순서와 같은 정보 접근의 개선부터 다룬다.

기관 전시와의 연결은 선택 링크로 둔다. 확인일 현재 공식 특별전은 2026년 10월 2일부터 2027년 2월 9일까지 대한민국역사박물관에서 열릴 예정으로 안내되어 있다. 이는 교실 특집 앱과 별개 일정이며 방문 가능·예약·운영 변경은 교사가 최신 공식 안내에서 다시 확인한다. [전시 상세](https://hangeul.go.kr/exhibition/676?curr_menu_cd=0102020000&page=1&searchCondition=&searchKeyword=).

이번 문서 작성으로 완료된 것은 근거 확인과 특집 계획이다. 앱 구현, 이미지·모션 제작, 새 PDF 생성 및 공개 재배포는 아직 진행하지 않았다.
