# 한글날 수업 도입 다큐: 60초 구성과 크레딧 견적

작성: 2026-09-27. 아래 표는 **제작 전 기획·견적 기록**이다. 이후 사용자의 클링 선택에 따라 Kling v3.0 Pro 7컷을 생성하고 60초 다큐를 앱에 탑재했다. 실제 영상 생성 사용량은 **52.5크레딧**(2702.43 → 2649.93)이며 유료 재생성 없이 완료했다. 완성본의 대본은 `도입-다큐-교사대본.md`를 따른다.

## 교실용 60초 구성

7개의 실사풍 생성 영상(각 5초, 합계 35초)과 5개의 출처·연도·질문 카드(각 5초, 합계 25초)를 편집한다. 교사가 한 번 재생한 뒤 바로 첫 탐구 질문으로 넘어갈 수 있는 길이다. 카드는 Skia/앱에서 정확한 한글로 제작한다.

| 시간 | 방식 | 화면·교사 내레이션 핵심 | 고증 경계 |
|---|---|---|---|
| 0–5초 | 타이포그래픽 | ‘우리말을 글로 전하기 어려웠다면?’ | 시대를 특정한 현장 촬영물처럼 보이지 않게 한다. |
| 5–10초 | 생성 영상 ① | 백성이 자신의 뜻을 글로 전하기 어려운 상황 | 백성을 모두 문맹으로 묘사하거나 읽을 수 없는 가짜 문서를 클로즈업하지 않는다. |
| 10–15초 | 생성 영상 ② | 세종이 보고를 듣고 백성의 어려움을 생각하는 상징 장면 | 실제 기록되지 않은 특정 만남·대사를 역사적 사건처럼 재연하지 않는다. |
| 15–20초 | 생성 영상 ③ | 왕의 책상에서 우리말 소리와 새 글자를 고민하는 상징 장면 | 글자 모양은 생성 영상 안에 만들지 않는다. 집현전 공동 창제 장면으로 소개하지 않는다. |
| 20–25초 | 연도 카드 | **1443년, 세종의 훈민정음 창제** | 문자 창제와 책 간행을 구분한다. |
| 25–30초 | 생성 영상 ④ | 새 글자로 쓸 노래를 준비하는 학자들의 상징 장면 | **1445년 『용비어천가』 노래 작성**, 1447년 간행과 구분. 종이는 빈 면 또는 실제 출처 자료의 편집 삽입. |
| 30–35초 | 생성 영상 ⑤ | 집현전 학자들이 새 글자의 원리와 쓰임을 설명하는 책을 준비 | 학자들의 **해례 작성**을 보여 주며 글자 자체의 공동 창제라고 단정하지 않는다. |
| 35–40초 | 출처 카드 | **1446년, 『훈민정음』 해례본 간행·반포** | 유물 사진을 쓸 때 소장처·판본·재사용 조건을 먼저 확인. 가짜 옛 한글 금지. |
| 40–45초 | 연도 카드 | **1447년, 『용비어천가』 간행** | 1445년 노래 작성과 1447년 책 간행을 따로 표시. |
| 45–50초 | 생성 영상 ⑥ | 시간이 흐른 뒤 한글을 배우고 쓰는 사람들 | 1446년 직후 모두가 읽게 된 듯한 즉시 보급 장면으로 편집하지 않는다. |
| 50–55초 | 생성 영상 ⑦ | 오늘날 우리 교실에서 읽고 쓰는 모습 | 시대 전환을 화면에 명시한다. |
| 55–60초 | 질문 카드 | ‘세종은 왜 새 글자를 만들었을까?’ 다음 PPT 슬라이드로 연결 | 교사 ‘다음’ 버튼만으로 수업 이어가기. |

## 현 계정의 실제 견적

2026-09-27 힉스필드 연결에서 조회한 **5초·16:9·무음·한 편** 값이다. Seedance는 720p, Kling은 `sound: off`로 계산했다. 아래 단가는 생성 전 조회 기록이며, 실제 결과는 위 완료 기록을 따른다.

| 모델 | 5초 한 컷 | 영상 7컷을 모두 새로 만들 때 | 2–3회 생성·재시도 예산 |
|---|---:|---:|---:|
| Kling v3.0 Standard | 6.25 크레딧 | 43.75 | 약 87.5–131.25 |
| Kling v3.0 Pro | 7.5 크레딧 | 52.5 | 약 105–157.5 |
| Seedance 2.5, 720p | 35 크레딧 | 245 | 약 490–735 |
| **권장 혼합**: 인물 4컷 Kling Pro + 분위기 3컷 Seedance | 모델별 단가 적용 | **135** | **약 270–405** |

2–3회 예산은 모든 컷을 평균 2–3번 생성한다는 단순 가정이다. 실제 비용은 선택한 옵션과 고증 검수에서 탈락한 컷 수에 따라 달라지므로 매 생성 직전에 다시 견적을 확인한다. 위 값은 **영상 생성만** 포함한다. 인물·복식 일관성을 위한 기준 이미지 생성, AI 내레이션·음악·업스케일·편집 서비스 비용은 포함하지 않았다. Skia 카드와 앱 내 재생 연결은 로컬 제작으로 힉스필드 영상 크레딧을 쓰지 않는다. 기존 채택 영상을 재사용하면 새로 생성하는 컷 수만큼 줄일 수 있지만 다큐 전체의 화풍·인물 일관성을 먼저 비교한다.

## 반드시 지킬 제작 원칙

- 중국 왕조풍 관모·용포·궁궐·장식·서체를 섞지 않는다. 조선 전기 복식·공간의 실물 근거와 생성 프레임을 대조한다.
- 인물과 공간은 **교육용 상징 재연**으로 표시한다. 특정 창제 순간의 실제 현장·세종의 실제 얼굴·모든 백성의 즉각적 문자 습득을 사실처럼 말하지 않는다.
- 읽혀야 하는 모든 한글·연도·원문은 생성 영상이 아니라 정확한 글꼴·출처가 확인된 자료로 후편집한다.
- 교사 화면 진입 시 자동 재생, 상단 ‘영상 다시 보기’, 끝난 뒤 정지 화면 유지. 학생 태블릿에는 필수 시청을 요구하지 않는다.
