> 목표: 전자칠판에서 교사가 ‘다음’만 누르면 필요한 짧은 영상이 자동 재생되고, 화면 위 ‘다시 보기’로 즉시 반복한다. 학생 태블릿에는 영상 시청을 필수로 요구하지 않는다. 정확한 글자와 날짜는 앱의 HTML 또는 실제 한글 폰트를 사용한 Skia 영상으로 보여 준다.

낱자 `ㅎ+ㅏ+ㄴ→한`의 결합과 퀴즈 정답은 앱이 **정확한 글자를 직접 그리는 모션**으로 표현한다. `1443→1446` 비교는 실제 Skia와 한글 폰트로 렌더링한 MP4를 사용한다. 생성형 영상에는 한글을 쓰게 하지 않는다. 세종의 실제 얼굴이나 특정 시대의 왕복식을 재현했다고 주장하지 않으며, 클링 영상에서도 인물은 얼굴이 보이지 않는 상징적 뒷모습에 한정한다.

## 제작 사양과 실행 순서

1. 힉스필드에서 16:9, 5초, 무음 영상을 각 1개 생성한다. 편집 효과보다 피사체의 안정성과 자연스러운 움직임을 우선한다.
2. 결과의 **처음·중간·마지막 프레임**을 확인한다. 가짜 글자, 중국식 건축·복식·장식, 손·책·도구의 변형, 시대 혼합이 보이면 앱에 채택하지 않는다. 원본은 보존하고 불합격 이유를 적는다.
3. 채택한 영상은 로컬 MP4로 `site/dist/videos/`에 저장한다. 시작 그림은 기존 검수된 PNG를 사용해 재생이 막혀도 수업이 진행되게 한다.
4. 교사 발표 화면의 해당 장면에만 `muted playsinline` 자동 재생을 연결한다. 한 장을 다시 열거나 위쪽 ‘영상 다시 보기’를 누르면 처음부터 재생한다. 페이지를 자동으로 넘기지 않는다.
5. 1–2·3–4·5–6학년 전체 이동 검증, QR 학생 활동 분리, 압축본의 MP4 포함 및 브라우저 재생을 확인한다.
