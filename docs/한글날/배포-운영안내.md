# GitHub와 공개 수업 사이트 운영

배포 방식: GitHub Pages. `main` 브랜치에 수정본을 올리면 GitHub Actions가 검증한 뒤 공개 사이트를 갱신한다.

- 저장소: `reinhardt7177-lab/hangeul-classroom`
- 사이트 주소: `https://reinhardt7177-lab.github.io/hangeul-classroom/`
- 실행 파일: `site/dist/`
- 배포 파일: `node site/package.mjs`가 구성한 `output/hangeul/수업앱/`
- 배포 작업: `.github/workflows/pages.yml`

## 수정 후 확인

```powershell
node site/verify-presenter.mjs
node site/verify-documentary-audio.mjs
Push-Location site
node verify.mjs
Pop-Location
```

검증이 통과한 수정본을 커밋하고 `main`에 푸시한다. GitHub 저장소의 Actions에서 `Verify and deploy classroom` 성공 여부를 확인한다. 영상 변경 시 브라우저 캐시 구분을 위해 영상 URL의 버전 쿼리도 갱신한다.

## 교실에서 사용

교사는 공개 사이트에서 학년을 선택하고 발표 수업을 시작한다. ‘태블릿 QR’에서 학생 활동을 고르면 공개 사이트의 학생 전용 주소로 QR이 만들어진다. 교사와 학생 모두 인터넷에 연결되어 있으면 되며 동일한 와이파이는 필수 조건이 아니다. 로컬 교실 서버를 사용할 때에만 같은 네트워크가 필요하다.

학생 응답의 서버 수집·실시간 집계는 없다. 영상의 소리 자동 재생이 막히면 ‘배경음악 켜기’를 누른다. 최초 영상 로딩은 네트워크 속도에 따라 달라진다.

## 보존과 배포 범위

로컬의 생성 원본·검수용 프레임·임시 업로드 설정·런타임 라이브러리는 보존하되 저장소에는 올리지 않는다. 현재 수업에서 사용하지 않는 초기 마을 그림도 공개 앱에서 제외한다. 수업 앱의 영상·이미지·로컬 글꼴·학습지 PDF와 교사 문서는 저장소에 포함한다. 글꼴과 QR 라이브러리의 기존 라이선스 파일은 유지한다.

오프라인 ZIP은 GitHub Release 첨부 파일로 제공한다. 새 버전 배포 후 ZIP을 다시 만들었다면 릴리스도 새 버전으로 발행한다. 공개 저장소의 생성 자료가 실제 유물 사진이나 실물 복원 기록이라는 뜻은 아니다.
