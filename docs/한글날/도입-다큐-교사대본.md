# 60초 도입 다큐 · 교사 해설

완성: 2026-09-27. **1920×1080·24fps·60초·잔잔한 배경음악**. 영상 속 큰 한글 문장을 교사가 읽어 주거나, 먼저 감상하고 마지막 질문에서 대화합니다. 1–2 / 3–4 / 5–6학년 모두 수업 첫 화면에서 자동 재생됩니다.

## 전자칠판 조작

- 아래 **배경음악 켜기/끄기**로 소리를 조절합니다. 소리 자동 재생이 차단되면 영상을 보면서 이 버튼을 한 번 누르세요. 음악은 교사의 해설을 돕는 현대 창작 연주곡이며 조선 음악의 복원은 아닙니다.

- 위쪽 **영상 잠시 멈춤 → 이어서 보기**, **영상 다시 보기**를 사용합니다.
- 아래 **영상 해설**을 열면 영상이 멈춥니다. 해설을 닫고 위쪽 **이어서 보기**를 누릅니다.
- 마지막 질문 화면에 머무릅니다. **다음**을 누르면 원래 수업의 관찰 화면으로 넘어갑니다.
- 도입 3분 안에서 영상 1분, 짝 대화 30초, 학생 답 듣기와 다음 화면 연결 1분 30초로 운영합니다.

## 시간별 읽어 줄 말

| 시간 | 화면 | 교사가 읽어 줄 말 |
|---|---|---|
| 0–5초 | 제목 | 누구나 마음을 전할 수 있도록. 세종이 꿈꾼 글자 이야기예요. |
| 5–10초 | 도움을 구하는 사람 | 우리말은 있었지만, 글로 뜻을 전하기 어려운 이들이 있었어요. |
| 10–15초 | 세종의 생각 | 세종은 그 어려움을 안타깝게 여겼어요. |
| 15–20초 | 새 글자를 고민하는 모습 | 누구나 쉽게 배우고 쓸 새 글자를 만들고자 했어요. |
| 20–25초 | 1443 | 1443년, 세종이 새로운 글자 스물여덟 자를 만들었어요. |
| 25–30초 | 노래를 준비하는 학자들 | 새 글자로 지은 노래, 용비어천가가 만들어졌어요. |
| 30–35초 | 원리를 설명하는 학자들 | 정인지 등 학자들이 세종의 명을 받아 새 글자의 원리와 쓰임을 설명하는 해례를 지었어요. |
| 35–40초 | 1446 | 1446년에는 훈민정음 해례본을 펴냈어요. |
| 40–45초 | 1447 | 용비어천가는 1445년에 짓고, 1447년에 책으로 펴냈어요. |
| 45–50초 | 배우며 미소 짓는 사람 | 시간이 흐르며 한글을 배우고 쓰는 사람들이 늘어났어요. |
| 50–55초 | 오늘의 학교 도서관 | 그 글자는 오늘도 우리의 마음과 생각을 이어 줘요. |
| 55–60초 | 생각할 질문 | 세종은 왜 새 글자를 만들었을까요? |

5초 안에 말하기가 빠르게 느껴지면 잠시 멈춥니다. 모든 문장을 덧붙여 설명하기보다 화면 문장을 그대로 읽어도 충분합니다.

- **30–35초 화면 문구:** ‘학자들은 세종의 명을 받아 새 글자의 원리와 쓰임을 설명했어요.’로 고쳤습니다. 해례를 지은 학자 8명 가운데 대부분은 집현전 소속이지만 강희안은 돈녕부 주부였으므로 모든 참여자를 집현전 학자로 묶지 않습니다.
- **50–55초 장면:** 현대 학교 **도서관** 장면이며, 라벨도 ‘현대 한국 도서관 · 상상 영상’으로 맞췄습니다.

## 학년군별 짧은 활동

| 학년군 | 질문·활동 | 확인할 답 |
|---|---|---|
| 1–2학년 | 영상의 연도는 설명하지 않고 ‘세종은 누구를 위해 글자를 만들었을까?’만 묻기. 표정이나 한마디로 답해도 좋다. | 글로 뜻을 전하기 어려운 사람들(백성)이 쉽게 배우고 쓰도록 새 글자를 만들었다. 연도 암기는 요구하지 않는다. |
| 3–4학년 | ‘글자를 만든 일’과 ‘원리를 설명한 책을 펴낸 일’ 순서 말하기 | 1443년 창제 → 1446년 해례본 간행. 만든 까닭까지 연결하면 충분하다. |
| 5–6학년 | ‘영상에서 상상한 장면’과 ‘자료로 확인한 사실’ 하나씩 구분하기 | 인물의 대화·표정·공간은 상상, 창제 목적과 연도는 사료에 근거한 설명이다. |

영상 다음에는 기존 관찰·탐구 활동을 이어 갑니다. 학생 태블릿 QR은 글자 탐험·만들기·골든벨 개인 활동에 사용합니다.

## 역사 설명의 경계

- 세종의 문자 창제와 정인지 등 학자들의 해례 작성을 구분합니다. ‘학자들이 모두 함께 한글을 발명했다’고 단정하지 않습니다.
- 『용비어천가』는 1445년 노래 작성, 1447년 책 간행을 구분합니다. 책을 펴내는 일은 **간행**, 글자를 처음 만드는 일은 **창제**라고 부릅니다.
- 한글이 생기자 즉시 모든 백성이 읽었다고 설명하지 않습니다.
- 인물·공간·동작은 교육용 상상 재연입니다. 세종의 실제 초상이나 집현전 실내 복원도가 아닙니다. 왕의 복식은 1444년 이후 자료를 참고한 상징 장면으로 표시했습니다.
- 생성 영상의 종이는 의도적으로 비워 두었습니다. 화면의 정확한 한글 설명은 Skia로 별도 제작했습니다.

### 최종 검증 후 덧붙일 설명

『용비어천가』는 조선 왕조의 건국과 선왕의 업적을 기리는 노래입니다. 백성에게 글자를 가르치는 교본과는 구분합니다. 1445년에 본문을 짓고, 설명을 보완하여 1447년에 책으로 펴냈습니다. 훈민정음 해례는 정인지를 비롯한 학자 8명(대부분 집현전 소속)이 세종의 명을 받아 지었습니다. 30–35초 화면 문구가 ‘집현전 학자들은…’으로 남아 있는 이전 배포본을 쓸 때도 이 문장으로 설명합니다.

한글날은 10월 9일에 기념하지만, 이를 확인된 창제일이나 반포식 날짜라고 설명하지 않습니다. 기존 수업의 ‘1446년 반포’는 통상적인 교육 표현이며, 영상은 그해 해례본 간행을 구체적으로 보여 줍니다. 해례본은 한문으로 설명한 문헌입니다.

왕의 복식은 1444년 이후 자료를 참고했습니다. 박물관에 전시된 곤룡포·익선관은 20세기 초 영친왕의 것이므로 세종의 실제 옷이나 1443년 현장을 그대로 복원한 자료로 소개하지 않습니다. 인물의 표정·동작, 건물과 가구도 상상 재연입니다. 한글 사용의 확대는 긴 과정이며, 영상 속 한 사람이 곧바로 글을 읽게 되었다는 실제 기록은 없습니다.
