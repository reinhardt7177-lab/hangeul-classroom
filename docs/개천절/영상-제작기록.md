# 개천절 영상·모션 제작 기록

2026-09-27 현재, [초등교육자료 엄선 기록](../../knowledge/개천절-초등교육자료-엄선.md)에 맞춰 두 개의 8초 클립을 완성했다.

| 장면 | 결과 파일 | 역할 | 고증·안전성 |
|---|---|---|---|
| 한국 산의 새벽 | `site/dist/videos/gaecheon-dawn-kling-8s.mp4` | 모든 학년 도입. 페이지를 열면 자동 재생 | 한국의 화강암 산세와 소나무·안개만 사용. 역사적 특정 장소의 실사라고 말하지 않음 |
| 곰과 범 | `site/dist/videos/gaecheon-bear-tiger-kling-8s.mp4` | 모든 학년 전승 장면. 페이지를 열면 자동 재생 | 『삼국유사』의 전해지는 이야기를 상상한 자연 장면. 사람으로 변하는 모습을 사실처럼 만들지 않음 |

두 클립은 Kling 3.0 Pro 16:9, 각 8초로 생성했다. 생성 비용 확인값은 **각 12, 합계 24 Higgsfield 크레딧**이었다. 시작·중간·끝 프레임을 확인하고 중국풍 궁궐·의상·장식·문자·판타지 요소가 없는 컷만 채택했다. 영상의 배경음악은 `site/motion/compose_gaecheon_bgm.py`로 만든 현대적 악기 합성곡이며 외부 음원 샘플을 쓰지 않았다. 영상마다 H.264/AAC로 합쳐 웹과 오프라인 ZIP에 넣었다.

교사 발표 화면에서는 영상이 **소리 없이 자동 재생**된다. 브라우저의 자동재생 제한 때문에 음악은 교사가 위쪽 **♫ 소리 켜기**를 누르면 들린다. **↺ 다시 보기**는 영상과 글자 모션을 함께 처음부터 재생한다. 영상이 로드되지 않아도 아래의 이미지가 수업 장면을 유지한다.

## 아직 영상화하지 않은 장면

- ‘10월 3일은 기념하는 날’은 현재 Skia 정지 타이포그래픽과 웹 글자 모션으로 제공한다. 5–6학년 자료 판단에 초점을 맞춰 영상 자체보다 교사의 발문과 답 공개를 우선했다.
- ‘오늘의 홍익인간’은 새 현대 교실 이미지와 학생 선택 활동으로 제공한다. 짧은 영상으로 만드는 것은 추후 수업 관찰 결과를 보고 결정한다.

기존 [승인 전 계획](영상-승인전-제작계획.md)은 제작 전의 기록으로 남겨 둔다. 사용자께서 이후 영상 제작을 직접 요청해 도입과 전승 두 장면을 제작했다.
