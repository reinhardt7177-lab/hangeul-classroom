# 개천절 영상·모션 제작 기록

## 2026-10-01 수정

환웅과 단군 장면에 새로 만든 전승 이야기 카드를 적용했다. 25초 설명은 청동기 문화와 출토지·시기 확인으로, 50초 설명은 문헌과 실제 유적 자료에서 확인할 수 있는 범위로 고쳤다. 수정된 화면으로 60초 영상을 다시 만들었다. 소리는 배경음악이며 음성 내레이션은 없다. 아래의 9월 제작 기록은 당시 버전의 기록이다. 생성 프롬프트와 이미지 파일은 `knowledge/이야기카드-이미지-제작기록.md`에 기록했다.

2026-09-27 현재, [초등교육자료 엄선 기록](../../knowledge/개천절-초등교육자료-엄선.md)에 맞춰 두 개의 8초 클립을 완성했다.

두 클립은 Kling 3.0 Pro 16:9, 각 8초로 생성했다. 생성 비용 확인값은 **각 12, 합계 24 Higgsfield 크레딧**이었다. 시작·중간·끝 프레임을 확인하고 중국풍 궁궐·의상·장식·문자·판타지 요소가 없는 컷만 채택했다. 영상의 배경음악은 `site/motion/compose_gaecheon_bgm.py`로 만든 현대적 악기 합성곡이며 외부 음원 샘플을 쓰지 않았다. 영상마다 H.264/AAC로 합쳐 웹과 오프라인 ZIP에 넣었다.

교사 발표 화면에서 곰·범 영상은 **소리 없이 자동 재생**된다. 브라우저의 자동재생 제한 때문에 음악은 교사가 위쪽 **♫ 소리 켜기**를 누르면 들린다. **↺ 다시 보기**는 영상과 글자 모션을 함께 처음부터 재생한다. 영상이 로드되지 않아도 아래의 이미지가 수업 장면을 유지한다.

| 장면 | 결과 파일 | 역할 | 고증·안전성 |
|---|---|---|---|

`site/motion/gaecheon-documentary/make_documentary.py`로 12장면 × 5초를 만든다. 그림 장면은 천천히 움직이는 켄번스 효과, 글자는 Skia(맑은 고딕·바탕), 음악은 스크립트 안에서 합성한 D장조 피아노·패드 곡이다. ‘동양풍’ 5음 선율과 외부 음원을 쓰지 않았다. 1920×1080·24fps·60초, H.264/AAC, 약 17MB. Higgsfield 크레딧은 쓰지 않았다(0).

검수에서 고친 것:

- 새벽 산 그림·영상은 황산식 산수로 읽혀 넣지 않았다. 도입 그림은 활엽수와 완만한 능선의 `gaecheon-tree.png`를 쓴다.
- `gaecheon-community.png`에 닭 두 마리와 옥수수처럼 보이는 걸이가 있었다. 청동기 시대 한반도의 닭 사육 근거가 약하고 옥수수는 아메리카 원산으로 조선 시대에 들어왔다. 닭 자리는 주변 흙·풀로 덮고 오른쪽 걸이 부분은 잘라 낸 수정본으로 바꿨다(원본은 `drafts/replaced/2026-09-28/gaecheon-community-before-chicken-corn-fix.png`). 수업 화면·학습지·영상이 모두 수정본을 쓴다.
- 도서관 그림 라벨을 ‘현대 교실’에서 ‘현대 도서관 교육용 삽화’로 바로잡았다.
- 태극기 장면의 깃봉이 설명 글자와 겹치지 않게 줄이고, ‘붙여 달아요’ 화살표가 깃봉과 깃면이 만나는 곳을 가리키게 했다.

시간별 대본과 수업 운영은 [1분 도입 영상 교사 대본](도입-영상-교사대본.md)에 있다.
