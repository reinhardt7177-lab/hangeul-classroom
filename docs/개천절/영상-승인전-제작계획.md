# 개천절 영상·모션그래픽 제작 계획 — 당시 승인 전 기록

이 문서는 제작 전 계획을 보존한 기록이다. 이후 사용자가 개천절 영상 제작을 직접 요청해 A와 B를 완성했다. 현재 결과와 비용, 남은 장면의 상태는 [영상 제작 기록](영상-제작기록.md)을 본다.

| 후보 | 위치·길이 | 제작 방식 | 학습 목적·고증 |
|---|---|---|---|
| A. 하늘이 열리는 자연의 도입 | 수업 첫 장면, 8–12초 | 한국 산세 이미지 기반 Kling/Higgsfield 카메라 모션 + 잔잔한 창작 음악 | 장소·사건을 실사로 단정하지 않고 상징적 자연 장면으로 제작. 사람이 등장하지 않음. |
| B. 전승의 세 장면 | 신단수·곰과 범·고조선 이야기 사이, 각 5–7초 | 승인된 정지 이미지의 제한적 패럴랙스. 필요한 경우 Blender로 2.5D 깊이 합성 | 모든 컷 화면에 ‘『삼국유사』 전승을 상상한 장면’ 고정 표기. 환웅·단군의 미확인 복식·궁궐을 만들지 않음. |
| C. 날짜와 근거의 차이 | 5–6학년 주장·근거 장면, 7–10초 | Skia로 **정확한 한글 글자** 렌더링 후 모션 타이포그래픽 | “10월 3일 = 기념하는 날”, “정확한 건국일 = 확인 불가”를 순차 표시. 현재 앱의 `gaecheon-fact-skia.png`를 시안으로 사용. |
| D. 홍익인간의 오늘 | 마무리, 8–10초 | 현대 한국 교실의 도움·존중 장면 생성 또는 교사 제공 소스, Blender/편집 합성 | 특정 학생의 도움이 미담으로만 소비되지 않도록 상호 존중·의견 듣기를 보여 줌. |

## 승인 뒤 제작 게이트

1. 교사가 컷 A–D 중 필요한 컷, 총 길이, 음악·내레이션 여부와 예상 크레딧을 검토한다.
2. 한 장면씩 이미지·복식·배경 고증을 확인한다. 중국풍 궁궐·복식·용·한자 장식·무협·도교 연출은 즉시 폐기한다.
3. 생성 영상은 ‘자료 기록’처럼 보이지 않도록 상상 재현 표기를 고정한다. 역사 문장과 한글 글자는 이미지 생성 모델에 맡기지 않고 Skia에서 합성한다.
4. 완성 후 전자칠판에서 페이지 진입 시 자동 재생, 위쪽 다시 보기, 멈춤·소리 조절, 영상 없는 대안을 연결한다.

Blender 합성은 이 초기 계획의 후보였고, 완료된 두 컷은 Kling 영상과 자체 제작 음악으로 만들었다. 후속 장면의 실제 제작 여부는 [영상 제작 기록](영상-제작기록.md)에 남긴다.
