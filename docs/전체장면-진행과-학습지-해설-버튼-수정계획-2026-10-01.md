# 전체 장면 진행과 학습지 해설 버튼 수정 계획

작성일은 2026년 10월 1일이다. 사용자가 첨부한 개천절 ‘기록의 성격’ 화면과 활동 선택 창을 기준으로, 개천절·한글날의 세 학년군에 공통 적용할 변경을 정리한다. 사용자 승인 후 로컬 앱과 운영 안내를 수정했다. 공개 사이트 재배포는 아직 하지 않았다.

결정할 기본 흐름은 **국경일 선택 → 학년 선택 → 첫 장면 → 모든 장면을 기본 순서로 진행**이다. 활동 선택 창, 체크박스, 선택 목록과 순서 변경 기능은 없앤다. 그 자리는 **학습지·해설** 버튼으로 바꾸고, 누르면 현재 학년의 학생 학습지와 교사 해설 링크만 보여 준다.

‘모두 나오게’는 해당 학년의 모든 장면이 누락 없이 이전·다음으로 이어진다는 뜻으로 적용한다. 모든 장면을 한 화면에 붙이거나 모든 퀴즈 정답을 처음부터 공개하는 방식은 아니다. 고정 수업 시간과 자동 배정 타이머는 다시 넣지 않는다.

## 1 수정 전 첨부 화면과 코드에서 확인한 문제

첫 이미지의 ‘후대에 편찬된 문헌 / 고조선 당시의 기록’은 `site/dist/gaecheon.js`의 `microActivity()`가 만든 보기다. 클릭 처리에서는 `microSelected`와 선택 강조만 바꾸며, 설명은 `state.beat`가 바뀌어야 생성된다. 따라서 보기만 눌렀을 때 설명이 나오지 않는 구조다.

해당 렌더 함수만 독립 실행한 검사에서도 선택 강조는 켜졌지만 `beat=0`이면 설명이 생성되지 않았고, `beat=1`에서만 설명이 생성됐다. 이는 선택과 설명 공개가 따로 작동한다는 코드 근거다. 아직 공개 브라우저에서 같은 화면을 재현하지 않았으므로, 실행 예외나 화면 잘림까지 모두 확인했다고 표현하지 않는다.

두 번째 이미지의 활동 선택 창은 `lesson-library.js`가 제공한다. 개천절의 학년 카드와 한글날의 `setupGrade()`가 이 창을 열고, 이전·다음 이동도 선택 목록에 의존한다. 버튼을 숨기기만 하면 선택 경로 때문에 일부 장면이 계속 빠질 수 있어 진입·이동·저장 상태를 함께 바꿔야 한다.

## 2 기록의 성격 보기와 피드백 수정

보기 클릭 직후 선택 결과와 이유를 같은 화면에 표시하는 방식을 권장한다. 첫 번째 보기는 ‘『삼국유사』는 사건보다 훨씬 뒤인 고려 시대에 편찬된 문헌이에요’, 두 번째 보기는 ‘고조선 당시 사람이 바로 남긴 기록은 아니에요. 고려 시대에 편찬된 문헌인지 다시 살펴봐요’처럼 학생이 판단한 까닭을 확인할 수 있게 한다. 문장은 구현 시 기존 교사 해설과 대조한다.

- 보기 선택은 선택 상태·피드백·접근성 상태를 함께 갱신한다. 정답 표시를 색만으로 구분하지 않는다.
- 선택 피드백은 발표 전체의 `beat`와 별도 상태로 관리한다. 보기 클릭만으로 다음 장면으로 이동하거나 전체 정리 답을 한꺼번에 공개하지 않는다.
- ‘설명 보기’는 교사가 전체 정리를 보여 주는 버튼으로 유지한다. 보기 클릭의 반응과 전체 정리를 명확히 구별한다.
- 다시 고르기와 장면 재방문 시의 상태를 정의한다. 다른 장면이나 다른 학년의 선택이 섞이지 않도록 장면 단위로 관리한다.
- 보기 부분만 갱신할 수 있다면 영상·입력·스크롤 위치를 유지한다. 버튼을 눌렀다는 이유로 영상이 처음부터 다시 재생되지 않아야 한다.
- 같은 방식의 관찰·그림 성격·기념일 의미·실천 보기들도 함께 점검한다. 학생 활동의 입력과 퀴즈 공개 규칙은 별도로 보존한다.

긴 제목과 버튼 및 새 피드백은 1024×768, 1280×720, 390×844에서 확인한다. 제목이 잘리거나 설명이 화면 밖에 고정되는 경우 해당 장면의 레이아웃·글자 크기·스크롤 영역을 조정한다. 전체 화면을 읽기 어려운 크기로 일괄 축소하지 않는다.

## 3 활동 선택 없이 전체 장면 진행

| 현재 기능 | 변경할 동작 |
|---|---|
| 학년 클릭 후 활동 선택 창 | 해당 학년 첫 장면으로 바로 진입 |
| 활동 선택과 한글날 목차 버튼 | 학습지·해설 버튼으로 교체 |
| 체크박스·분류 필터·선택 비우기·순서 변경 | 화면과 이벤트에서 제거 |
| 선택한 활동만 이전·다음으로 이동 | 원본 데이터의 모든 장면을 기본 순서로 이동 |
| ‘선택한 자료’ 진행 표기 | ‘전체 장면’ 또는 ‘수업 진행’으로 변경 |
| 선택 목록 기반 이어서 보기 | 선택 창 기능은 제거. 학년 시작은 첫 장면으로 통일 |
| 예전 `#choose/학년` 링크 | 해당 학년의 전체 수업 첫 장면으로 호환 연결 |

원본 학습내용·이미지·자료 비교·학생 활동·퀴즈는 삭제하지 않는다. 한글날은 각 장면 안의 세부 발표 단계까지 모두 유지한다. 진행 수는 실제 전체 데이터에서 계산하며, 마지막 장면의 종료 안내도 전체 순서를 기준으로 한다.

이전에 저장한 `holiday-library:v1` 선택 목록이 새 수업 경로를 제한하지 않도록 읽기 의존성을 제거한다. 브라우저 저장소 전체 삭제는 하지 않으며 QR 주소·음성·모션 설정 등 다른 데이터에 영향을 주지 않는다. 기존 장면 직접 링크는 가능한 한 유지한다.

`lesson-library.js`가 제공하던 목표·결과물·피드백·출처 데이터는 필요하면 교사 해설에 재사용한다. 활동 선택 UI를 없애는 것이 학습 근거까지 없애는 작업은 아니다. 선택·저장·이동 API를 쓰는 모든 호출을 확인한 뒤 공통 파일의 유지 또는 정리를 결정한다.

## 4 학습지 해설 버튼 구성

권장 버튼명은 **학습지·해설**이다. 수업 상단의 기존 활동 선택 또는 목차 자리에 배치한다. 클릭하면 제목 ‘개천절 · 3–4학년 학습자료’처럼 현재 국경일과 학년이 보이는 작은 창을 연다.

창 안에는 ‘학생 학습지 PDF 열기’, ‘교사 해설 PDF 열기’ 두 링크와 닫기 버튼만 둔다. 선택 카드, 추천 활동 목록, 수업 시작 버튼은 넣지 않는다. 별도 정답이 없는 학생용과 교사 해설을 명확히 구별하고, 두 PDF는 새 탭에서 열어 수업 위치가 유지되게 한다.

개천절은 `worksheets/gaecheon-학년-student.pdf`와 `-teacher.pdf`, 한글날은 기존 파일명 그대로 `worksheets/hangul-학년-student.pdf`와 `-teacher.pdf`를 연결한다. 화면명 ‘한글날’과 파일 접두사 `hangul`이 다르므로 링크 생성 시 임의로 `hangeul`로 바꾸지 않는다.

현재 장면의 교사 노트, 자료 출처, 학생 QR, 전체 화면, 모션 다시 보기 기능은 보존한다. 이 요청은 기존 활동 선택 창을 자료 창으로 바꾸는 것이며 다른 수업 도구 전체를 삭제하는 것으로 확대하지 않는다. 첫 화면의 전체 학년 학습지 모음이 남더라도 수업 안 버튼은 현재 학년 두 자료만 표시한다.

PDF를 열고 돌아와도 현재 장면·보기 선택·학생 입력이 바뀌지 않아야 한다. 자료 창의 Escape 닫기, 키보드 이동과 닫은 뒤 원래 버튼으로 초점 복귀를 확인한다.

## 5 변경 파일과 작업 순서

1. `gaecheon.js`의 보기 선택·피드백 상태를 수정하고 기록의 성격 장면을 먼저 재현 검사한다. 관련 CSS는 실제 잘림이 확인된 범위에서 고친다.
2. `gaecheon.js`, `hangeul.js`, `hangeul-presenter.js`의 학년 진입·이전·다음·진행 수·목차 호출을 전체 경로로 바꾼다. 학생 모드와 기존 직접 링크를 함께 검사한다.
3. 공통 학습지·해설 창을 만들고 선택 UI의 이벤트·CSS·HTML 의존성을 정리한다. `lesson-library.js`의 교육 메타데이터는 필요한 부분만 분리해 유지할 수 있다.
4. `verify-renewal.mjs`, `verify-gaecheon.mjs`, `verify-presenter.mjs` 등에서 선택 기능을 전제로 한 검사를 새 요구사항으로 교체한다. 무관한 콘텐츠·음원 검사는 유지한다.
5. 교사용 운영 안내와 제작계획의 현재 안내를 고친다. 과거 검증 기록은 보존하되 이번 구조로 대체된 것을 표시한다. 학습지 문항 자체는 이번 구조 변경만을 이유로 삭제하지 않는다.
6. 앱 패키징·ZIP 복사 목록과 검사 대상을 맞춘다. 로컬 검증 후 별도 배포 요청에 따라 공개 사이트와 미러를 갱신하고 공개 주소에서 다시 확인한다.

기존 사용자 파일과 작업 내용을 보존했다. 앱의 진입·이동·자료 창·보기 피드백을 수정하며, 학습지 문항과 영상 파일은 그대로 유지한다. 공개 사이트는 별도 배포 요청 후 갱신한다.

## 6 한글날 제정 100주년 특집에 적용할 규칙

[100주년 특집 계획](한글날-제정-100주년-특집-계획-2026-10-01.md)의 역사 기준과 학년별 활동·시각자료는 유지하되, 활동 선택 창을 재사용한다는 제안은 이번 요구로 바꾼다. 특집도 학년을 고르면 공통 도입과 해당 학년의 모든 활동이 기본 순서로 이어지도록 설계한다. 학습지·해설 버튼과 QR·접근성 규칙을 공통 적용한다.

모든 장면을 제공하더라도 학생에게 모든 결과물 제출을 강제하거나 시간 제한을 두지는 않는다. 학년별 난이도와 교사의 실제 수업 운영은 별도로 존중한다.

## 7 완료 판단 기준

- [x] 개천절·한글날의 세 학년군을 누르면 활동 선택 창 없이 첫 장면이 열린다. 실제 브라우저에서 여섯 진입 버튼을 클릭했다.
- [x] 예전 일부·재정렬 선택 목록을 읽거나 지우지 않고 전체 경로를 사용한다. 저장소 접근을 감시하는 자동 검사로 확인했다.
- [x] 개천절 49개 장면과 설명 단계, 한글날 114개 발표 단계의 순방향·역방향·종료를 실제 렌더 함수와 이동 함수로 자동 검사했다. 모든 장면의 실제 브라우저 화면을 개별 검수한 것은 아니다.
- [x] 기록의 성격 보기의 두 선택 모두 클릭 직후 설명이 나오고 다시 고를 수 있다. 브라우저 클릭과 Space 선택으로 확인했다.
- [x] 해당 장면의 제목·보기·피드백과 자료 창을 1280×720, 1024×768, 390×844에서 확인했다. 실제 터치 기기 검수는 별도다.
- [x] 학습지·해설 창에는 현재 학년의 학생용·교사용 두 PDF 링크만 있다. 12개 PDF의 HTTP 200 응답·PDF 형식을 검사했다. 브라우저의 새 탭 링크는 유지하며 외부 PDF 뷰어의 화면 검수는 별도다.
- [x] 자료 창을 닫아도 장면·보기 선택이 유지된다. 재생 중인 개천절 영상도 41.69초에서 42.31초로 이어졌으며 처음으로 되돌아가지 않았다. 학생 실천 입력과 선택은 다른 활동 탭을 다녀와도 유지됐다.
- [x] 학생 QR의 학년·활동 링크, localhost 차단, 직접 장면 링크와 한글날 모션 끄기·켜기 및 정지 상태를 브라우저에서 확인했다. 교사용 운영 안내와 제작계획의 이전 목차 안내도 새 버튼에 맞췄다.
- [ ] 외부 PDF 뷰어에서 돌아오는 실제 기기 검수와 별도 학생 기기의 QR 접속을 확인한다.
- [ ] 실제 교실 브라우저에서 전체 화면 진입·복귀를 확인한다. 현재 내장 브라우저에서는 버튼을 눌러도 전체 화면 상태가 되지 않아 정상 작동 확인으로 표시하지 않았다.
- [x] 기존 자동 검사와 새로운 전체 경로·클릭 피드백 검사가 통과한다.
- [ ] 공개 배포가 요청되면 두 공개 주소에서 핵심 화면과 실제 PDF 파일을 재검사한다.

로컬 구현과 자동 검사는 완료했다. 실제 브라우저에서는 학년 직접 진입, 기록의 성격 정답·오답·다시 선택, Space 선택, 자료 창 닫기와 초점 복귀를 확인했다. 자료 창을 열고 닫아도 현재 장면과 보기 선택이 유지됐다. PDF 링크는 현재 학년에 맞게 연결되며 12개 파일 응답을 확인했다. 공개 재배포와 실제 교실 기기·외부 PDF 뷰어 검수는 아직 수행하지 않았다.

브라우저 검수 화면은 `output/full-lessons/기록의-성격-즉시피드백.png`, `output/full-lessons/학습자료-창.png`에 보관한다. 문서와 앱 파일은 오프라인 ZIP에 함께 반영하며, 공개 사이트에 적용됐다는 의미는 아니다.

후속 검수에서 ‘기록의 성격’ 정답에는 후대 문헌임을, 오답에는 고조선 당시의 직접 기록이 아님을 각각 설명하도록 다듬었다. 관찰·기록의 성격·그림의 성격·기념일 의미·실천 보기 다섯 종류에 정답·오답·다시 선택·교사 정리 후 선택 잠금 검사를 추가했다. 설명 글자는 기존 14px에서 화면 크기에 따라 16–24px로 키우고 어두운 배경을 넣었다. 긴 오답 설명도 세 검수 화면 크기에서 확인했다.
