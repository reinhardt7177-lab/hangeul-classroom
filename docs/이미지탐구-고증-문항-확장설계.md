# 이미지로 탐구하는 국경일 수업 — 고증·문항·활동 확장 설계

> 최신 요청 반영: **이미지가 풍성하고, 시대 표현은 근거가 있으며, 학생은 이미지를 통해 생각하고 답하는 수업.**  
> 2026-09-26 · 제작 구상안. 아래 수량은 계획이며, 이미지·문항 전체의 제작 완료 수량이 아닙니다.

> **사용자 의도:** 이미지 4지선다는 가능한 방법의 예시입니다. 특정 문제 형식을 기본값으로 고정하지 않고, 수업 내용과 학년 수준에 맞는 다양한 관찰·조작·표현·탐구 방법을 설계합니다.

> **필수 조건:** [한국문화 시각 고증 기준](한국문화-시각고증-필수기준.md)을 모든 자산에 적용하며 중국풍 표현을 배제합니다. 한글날과 개천절은 **별개의 교육 패키지**입니다. 아래는 두 패키지가 참고할 제작 방법이며 혼합 수업을 뜻하지 않습니다.

## 1. 핵심 제안

**‘한 장 보고 설명 듣기’에서 ‘보고 → 찾아내고 → 고르고 → 이유 말하기’로 전환합니다.**

공통으로 유지할 것은 문제 형식이 아니라 **풍성하고 정확한 시각 자료, 학생이 생각하는 과정, 교사의 쉬운 진행**입니다. 관찰이 필요한 내용은 탐색으로, 관계를 이해할 내용은 조작으로, 생각을 확장할 내용은 창작·토론으로 구성합니다. 이미지 4지선다는 그중 선택형 활동이 알맞을 때 사용할 수 있는 하나의 예시입니다.

예를 들어 세종을 보여 준 뒤 이름을 묻는 것으로 끝내지 않습니다. 당시 소통의 어려움을 보여 주고, 새 문자가 필요한 까닭을 찾게 하며, 오늘날 누구나 이해할 수 있는 안내문을 고르게 합니다.

## 2. 이미지를 세 층으로 나누기

| 층 | 무엇을 보여 주나 | 화면에 붙이는 표지 | 사용 원칙 |
|---|---|---|---|
| **실물 자료** | 실제 유물·문헌·공식 소장품 이미지 | ‘실물 자료 · 소장기관 · 자료명’ | 원자료·시대·권리 확인. AI로 글자나 결손을 고친 뒤 원본처럼 쓰지 않음 |
| **고증 참고 재현** | 자료를 참고해 구성한 역사 속 생활 장면 | ‘자료를 참고한 재현 이미지’ | 시대·복식·건물·소품 근거를 기록. 미확인 부분은 추정으로 표시 |
| **신화·상징 표현** | 단군 이야기, 설명용 은유, 첫 화면 장식 | ‘건국 신화의 상상 장면’ 또는 ‘상징 삽화’ | 사실적인 화풍이어도 실증된 사건으로 설명하지 않음 |

**사진처럼 보이는 것과 역사적으로 정확한 것은 다릅니다.** 생생함은 표현 품질이고, 고증은 근거·시대 일치·검수의 문제입니다. 두 가지를 따로 확인합니다.

### 기존 5개 시안의 위치

이번에 만든 클레이 스타일 5종은 **최종 사용을 보류한 첫 화면 시안**으로 보존합니다. 특히 세종 주변 건물·책 제본, 개천절 인물의 배치와 복식은 고증 검증을 마친 복원도가 아닙니다. 한국문화 시각 기준을 통과하기 전에는 최종 화면이나 본문 설명에 채택하지 않습니다.

## 3. 풍성함을 만드는 이미지 구성

### 원화 제작 구상: 약 47종

| 묶음 | 계획 수량 | 예시 |
|---|---:|---|
| 국경일 첫 화면 | 5 | 현재 생성한 5종, 고증 검증 전 장식 시안 |
| 한글날 이야기·재현 | 10 | 문자 생활의 어려움, 사람의 뜻 전달, 글자 연구를 상징하는 장면, 글을 읽고 쓰는 생활 |
| 개천절 신화 장면 | 8 | 산과 구름, 환웅, 곰과 호랑이, 웅녀, 단군과 공동체 등 이야기 흐름 |
| 오늘의 교실·생활 상황 | 12 | 안내문 읽기, 친구 돕기, 차례 지키기, 공용 공간, 쉬운 말 안내 |
| 도구·단서·확대 관찰 | 8 | 확인된 자료의 책·종이·붓·글자 확대, 활동에 필요한 현대 소품 |
| 활동·평가 공통 | 4 | 골든벨, 미션 지도, 관찰 노트, 완료 장면 |
| **계획 합계** | **47** | 원화 수량. 외부 실물 사료는 출처·권리 확인 후 별도 선정 |

원화 47장은 확정 예산이나 제작 완료 약속이 아닙니다. 장면별 학습 필요를 확인해 확정할 목표량입니다. 같은 질문을 반복하는 장식 그림은 줄이고, 새 정보·관찰 근거가 있는 그림을 늘립니다.

### 원화를 수업 자산으로 확장

- 한 원화에서 전체 장면·관찰용 확대·단서 공개·정답 설명을 만듭니다.
- 똑같은 원화를 서로 다른 정답 상황처럼 재사용하지 않습니다.
- 저학년에는 관찰할 부분을 좁히고, 고학년에는 맥락과 출처를 함께 제공합니다.
- 한글의 정확한 자모, 날짜, 문헌 원문은 생성 이미지에 맡기지 않고 확인된 원자료 또는 실제 텍스트로 표시합니다.
- 배경·인물·소품의 움직임이 필요하면 별도 레이어로 제작하고, 한 장의 그림에 모든 모션을 기대하지 않습니다.

### 다양한 형태를 함께 쓰는 활동·평가 묶음

| 묶음 | 활용 방식 | 확인할 학습 |
|---|---|---|
| 관찰형 | 확대·가림막 공개·단서 표시·장면 비교 | 이미지에서 필요한 정보를 찾는가 |
| 조작형 | 글자 조합·순서 배열·분류·관계 연결 | 원리·순서·기준을 이해하는가 |
| 판단형 | OX·이미지 선택·근거 선택·설명 수정 | 조건과 자료에 맞게 판단하는가 |
| 표현형 | 말풍선·설명 녹음 대신 현장 말하기·그림·포스터 | 자기 말과 장면으로 의미를 전하는가 |
| 협력형 | 짝 설명·다른 관점 토론·공동체 제안 | 근거를 주고받고 생각을 발전시키는가 |

모든 활동에 네 보기를 만들 필요는 없습니다. 완성 수량은 각 수업의 목표와 시간에 맞춰 정하며, 동일한 형식으로 채울 문항 수나 선택지 칸 수를 목표로 두지 않습니다.

## 4. 학생이 경험하는 흐름

**몰입 → 발견 → 시도 → 설명 → 다시 생각하기**를 기본 흐름으로 삼고, 답하는 방법은 활동에 따라 바꿉니다.

| 순간 | 화면에서 일어나는 일 | 교사가 돕는 방법 |
|---|---|---|
| 몰입 | 이야기에 필요한 큰 장면과 질문 하나 등장 | “무엇이 보이나요?” |
| 발견 | 확대하거나 가림막을 열어 단서를 관찰 | 관찰과 추측을 구분해 묻기 |
| 시도 | 조합·배열·비교·그림·말·선택 중 적절한 방식으로 답하기 | 처음 조작만 시범, 학생 시도 기다리기 |
| 설명 | 바뀐 장면·만든 결과·선택한 근거를 공유 | “어디를 보고, 왜 그렇게 했나요?” |
| 다시 생각 | 해설·다른 관점·친구의 결과를 보고 수정 | 정답형은 이유, 창작형은 기준으로 피드백 |

### 학년별로 도움을 달리하기

| 학년군 | 관찰 범위와 지원 | 학생 표현 |
|---|---|---|
| 1–2 | 장면의 일부부터 보기, 교사가 읽어 주기, 간단한 조작 | 가리키기·이어 말하기·그림으로 답하기 |
| 3–4 | 장면끼리 비교, 조작 과정 확인, 짧은 힌트 | 만든 결과와 이유 설명하기 |
| 5–6 | 출처·맥락·상반된 설명 함께 살피기 | 주장과 근거, 개선안 제시하기 |

읽기 부담이 학습 이해보다 크게 작용하지 않도록 합니다. 정해진 정답이 없는 창작·토론은 정답 공개 대신 **좋은 예·다른 관점·고쳐 볼 점**을 제시합니다.

## 5. 내용에 맞춰 고르는 12가지 이미지 활동

| 방식 | 실제 학생 행동 | 수업 예 | 권장 |
|---|---|---|---|
| **이미지 4지선다** | 네 장면 중 조건에 맞는 한 장 선택 | 한글 창제 취지에 맞는 상황 | 전 학년 |
| **확대 단서 찾기** | 큰 그림에서 중요한 부분 누르기 | 실제 자료의 글자·제본 관찰 | 전 학년, 단서 수 조절 |
| **장면 비교** | 두 그림의 의미 있는 변화 설명 | 이해하기 어려운 안내와 고친 안내 | 전 학년 |
| **이야기 순서** | 그림을 시간 흐름에 따라 놓기 | 단군 신화의 흐름 | 저·중학년 |
| **그림–설명 연결** | 그림에 맞는 설명을 연결 | 창제/반포·한글/한국어 | 중·고학년 |
| **조건 분류** | 정해진 기준에 따라 묶기 | 오늘의 실천/전승 내용/확인할 주장 | 중·고학년 |
| **다음 장면 예상** | 다음에 일어날 일을 고르고 설명 | 말이 전달되지 않은 뒤 해결 방법 | 저·중학년 |
| **말풍선 완성** | 인물 관점에서 한 문장 만들기 | 글로 마음을 전하는 사람의 말 | 전 학년 |
| **근거 스티커** | 판단의 근거가 된 곳을 표시 | 어떤 단서로 그렇게 생각했는지 | 중·고학년 |
| **그림에 붙은 설명 고치기** | 과장·혼동된 설명을 수정 | ‘한글 이전에는 우리말도 없었다’ | 중·고학년 |
| **우리 반 장면 만들기** | 상황·행동·도움받는 사람을 구성 | 홍익인간을 교실에서 실천 | 전 학년 |
| **나만의 문제 만들기** | 그림에 질문과 선택지를 붙여 친구에게 출제 | 수업에서 배운 내용을 새 문제로 | 고학년 확장 |

**한 수업에서 주 활동은 2–3가지로 제한합니다.** 모든 방법을 한 차시에 넣어 화면 조작만 늘리지 않습니다. 진행 버튼·힌트·해설의 위치는 일관되게 유지하되, 학생의 답변 방식과 평가 형태는 목표에 맞춰 바꿉니다.

### 추천 조합

| 수업 | 도입 → 핵심 활동 → 평가 |
|---|---|
| 한글날 1–2 | 글자 가리기 → 글자 조합·마음말 카드 → 그림 연결·한 문장 말하기 |
| 한글날 3–4 | 생활 장면 비교 → 글자 실험·쉬운 말 안내 → 순서/선택 문제와 만든 안내 설명 |
| 한글날 5–6 | 말/문자 비교 → 자료 해석·안내문 개선 → 틀린 설명 수정·개선 근거 제시 |
| 개천절 1–2 | 구름 속 이야기 → 그림 순서·인물 말풍선 → 이야기 이어 말하기·그림 OX |
| 개천절 3–4 | 이야기 단서 → 실천 상황 구성·짝 설명 → 분류·실천 이유 말하기 |
| 개천절 5–6 | 주장 관찰 → 자료 탐정·서로 다른 해석 토론 → 근거 표시·공동체 제안 검토 |

## 6. 고증 제작 절차

### 이미지 한 장의 이력

`학습목표 → 보여 줄 사실 → 공식 근거 확인 → 장면 설계 → 이미지 생성 → 근거와 대조 → 수정·보류 → 화면 출처 표기`

각 그림에 다음 기록을 붙입니다.

| 필드 | 기록 내용 |
|---|---|
| 이미지 ID | 예: H-STORY-03 |
| 수업 목적 | 이 그림에서 학생이 무엇을 발견해야 하는지 |
| 시대·장소 | 확인된 범위와 추정 범위 |
| 인물·복식 | 관련 자료, 세부 표현을 단정할 수 있는지 |
| 건물·도구·서책 | 근거가 되는 자료·시대, 피할 후대 요소 |
| 출처 | 기관·자료명·페이지 URL·확인일 |
| 권리 | 열람 가능과 재사용 허용을 구분, 별도 확인 여부 |
| 생성 정보 | 실행 프롬프트·모델/도구·원본 경로 |
| 불확실성 | 복원 근거가 없는 얼굴·색상·배치 등 |
| 화면 표지 | 실물 자료 / 재현 이미지 / 신화 상상 장면 |
| 검수 상태 | 초안 / 사실 대조 중 / 수정 필요 / 수업 사용 가능 |

### 고증에서 특히 주의할 부분

- 오늘날 볼 수 있는 궁궐 건물 사진을 그대로 15세기 당시 모습이라고 사용하지 않습니다.
- 후대의 표준 영정이나 상상 초상을 실제 세종의 모습을 촬영한 것처럼 설명하지 않습니다.
- 『훈민정음』 해례본과 언해본, 그 밖의 후대 책을 구분합니다.
- 생성 모델이 만든 한자·옛한글을 사료의 실제 글자로 제시하지 않습니다.
- 조선 후기 복식·도구·건축 표현을 세종 시대로 무심코 옮겨오지 않습니다.
- 단군 신화의 초자연적 장면은 장엄하게 표현하더라도 역사적 복원 장면이라고 부르지 않습니다.
- 역사적 오류를 찾는 문제를 만들 때는 **오류가 든 학습용 보기**임을 교사 자료에 기록하고, 정답 공개 뒤 올바른 설명을 충분히 제시합니다.

공식 자료에 근거한 구체적인 시각 참고표는 [고증 참고 자료](../knowledge/historical-visual-references.md)에 정리합니다.

## 7. 좋은 이미지 활동과 문항의 기준

공통으로 학생이 이미지를 실제로 관찰해야 하고, 활동의 결과가 학습목표를 보여 주어야 합니다. 창작·토론형은 정답 하나로 닫지 않고 **근거의 적절성·설명의 명료함·실천 가능성** 같은 기준으로 피드백합니다.

아래 기준은 그중 단일 정답 선택형 문제를 쓸 때 적용합니다.

- **정답은 질문의 조건 아래 하나:** 다른 그림도 충분히 옳게 해석된다면 질문이나 보기를 고칩니다.
- **그림을 보아야 풀 수 있음:** 그림을 가려도 텍스트만 읽고 풀 수 있다면 시각 자료의 역할을 재검토합니다.
- **색·표정·크기가 답을 주지 않음:** 정답만 밝고 크게, 오답만 우스꽝스럽게 만들지 않습니다.
- **오답도 배운 내용과 연결:** 엉뚱한 보기로 정답을 돋보이게 하지 않고, 실제 오개념을 확인합니다.
- **읽기와 학습 이해를 구분:** 질문 읽어 주기·확대·대체 설명을 제공합니다.
- **A만 자주 답이 되지 않음:** 문제은행 전체의 정답 위치를 점검합니다.
- **접근성 설명은 중립적:** 대체 텍스트에 ‘정답 그림’이라고 쓰지 않고 필요한 장면 정보를 동등하게 전달합니다.
- **재현을 증거로 채점하지 않음:** 생성 이미지 속 모습을 관찰해 실제 역사를 확정하도록 묻지 않습니다.

각 주제·학년군별 실제 문항 예시와 오답 해설은 [이미지 문항 설계·검토](../knowledge/image-question-quality.md)에 수록합니다.

## 8. 교사 편의: 풍성하지만 복잡하지 않게

수업 중 반복해서 쓰는 조작은 **다음 / 힌트 / 정답 / 해설**로 통일합니다. 그림 확대, 자료 출처, 추가 이야기는 필요할 때만 펼칩니다.

- 수업 시작 전 ‘이 수업에서 사용할 이미지·영상·활동·평가’를 한 장에서 확인합니다.
- 이미지는 학생 화면에 크게, 출처와 교사 주의점은 별도 도움말에 둡니다. 재현·신화 표지는 학생 화면에도 유지합니다.
- 인터넷 상태가 불안하면 외부 영상을 빼고 준비된 이미지 이야기로 진행합니다.
- QR 학생 활동에는 본문보다 가벼운 이미지를 제공합니다. 원본 고해상도는 확대할 때 불러옵니다.
- 기본 수업은 학생 답변을 서버에 모으지 않습니다. 실시간 집계가 필요할 때만 수업 코드·응답 저장 기능을 별도 구현합니다.
- 학습지에서도 같은 그림을 쓰되 흑백 판독성과 인쇄 크기를 검수합니다.

## 9. 실제 제작의 우선순위

1. **대표 이미지 수업 1종:** 3–4학년 한글날의 재현 3장, 실물 자료 1개, 장면 비교·글자 조합·자기 설명 활동을 먼저 만듭니다.
2. **내용·시각 검수:** 시대 표현, 질문의 단일 정답, 교실에서의 가독성을 함께 확인합니다.
3. **한글날 3단계 확장:** 원화 공유와 수준별 질문·활동 분리를 적용합니다.
4. **개천절 3단계 확장:** 신화 장면과 근거 판단 자료의 표지를 일관되게 적용합니다.
5. **활동·평가·인쇄물 완성:** 목표에 맞게 선택한 다양한 활동과 6종 학습지·교사용 해설을 검수합니다. 선택형 문항 수를 고정하지 않습니다.
6. **수업 리허설:** 주제·학년별로 처음부터 끝까지 진행하고 이미지 로딩·QR·영상 대안·정답 공개를 확인합니다.

이 확장 설계는 [기본 제작 계획](국경일-수준별-수업앱-제작계획.md)의 이미지 수량과 평가 방식을 보강합니다. 이미지 수량은 이 문서의 계획을 우선하며, 실제 제작 완료 여부는 각 자산의 검수 상태로 관리합니다.
