# 오늘의 국경일 — 수준별 수업 앱 제작 계획

> **한글날·개천절 × 1–2 / 3–4 / 5–6학년 = 6개 수업**  
> 선생님은 화면을 넘기며 이야기하고, 학생은 보고·말하고·만들며 참여하는 수업.  
> 작성일: 2026-09-26 · 상태: **제작 설계안**. 기능 구현·영상 재생 검증·배포 완료를 뜻하지 않습니다.

> **구성 확정:** 한글날과 개천절은 각각 독립된 교육 패키지로 제작합니다. 공통 첫 화면에서 선택한 뒤에는 이야기·이미지·활동·영상·평가·학습지·교사용 해설이 주제별로 분리됩니다. [한글날 계획](한글날/제작계획.md) · [개천절 계획](개천절/제작계획.md)

> **문화 표현:** 대한민국의 역사·문화에 맞게 고증하며 중국풍 표현을 배제합니다. [한국문화 시각 고증 필수 기준](한국문화-시각고증-필수기준.md)을 적용합니다. 현재 생성한 5개 시안은 재검수 전까지 최종 사용 보류입니다.

> **시각·활동 설계:** 풍성한 고증 참고 이미지와 다양한 관찰·조작·창작·토론 활동을 [이미지탐구·고증·문항 확장 설계](이미지탐구-고증-문항-확장설계.md)에 구체화했습니다. **4지선다는 예시이며 필수·중심 형식이 아닙니다.** 원화 약 47종을 검토하는 계획이며, 활동과 문항 수는 내용에 맞춰 정합니다. 생성한 5개 시안은 첫 화면용 상징 삽화이며 고증을 마친 본문 자료가 아닙니다.

## 1. 만들고 싶은 수업의 모습

첫 화면에서 우리나라 5대 국경일을 아름다운 벤토 그리드로 만납니다. 선생님이 **한글날 또는 개천절 → 학년군 → 수업 시작**을 선택하면 바로 수업이 시작됩니다.

화면은 설명 자료와 활동 도구가 한 몸처럼 연결됩니다. 글자를 설명하다가 그 자리에서 조합하고, 단군 이야기를 보다가 바로 순서를 맞추고, 마지막에는 같은 수업 내용으로 골든벨이나 학습지를 진행합니다.

**화려함의 기준은 ‘배움이 보이는 움직임’입니다.** 등장 효과만 늘리기보다 한글이 결합되는 원리, 이야기의 순서, 근거와 생각의 차이가 눈에 보이게 만듭니다. 이미지와 모션은 풍성하게, 선생님의 조작은 단순하게 설계합니다.

### 이번 제작 범위

| 구분 | 완성할 내용 |
|---|---|
| 첫 화면 | 3·1절·제헌절·광복절·개천절·한글날, 총 5개 카드 |
| 본 수업 | 한글날 3종 + 개천절 3종, 총 6종 |
| 다른 국경일 | 날짜·의미를 담은 간단한 소개. 전체 수업과 혼동하지 않도록 표시 |
| 진행 방식 | 교사용 발표 화면, 키보드·터치 이동, 목차, 해설, 정답 공개 |
| 학생 참여 | 학년별 조작 활동, 짝 대화, QR 개인 활동, 기기 없는 대체 활동 |
| 영상 | 검토한 YouTube 영상, 시청 전 질문, 시청 후 활동, 재생 실패 시 대체 화면 |
| 평가 | 전원 참여 골든벨 또는 인쇄 학습지 선택, 교사용 정답·해설 |
| 제작 이미지 | 원화 약 47종을 검토하는 계획. 현재 생성한 시안은 5종. 구체적인 묶음은 시각·활동 설계 참조 |

## 2. 첫 화면과 수업 진입

### 벤토 그리드 구성

```text
오늘의 국경일                         국경일 수업   수업 안내

특별한 날, 함께 배우는 우리의 이야기

┌────────────────────────┬────────────────────────┐
│ 한글날 · 10.09          │ 개천절 · 10.03          │
│ 세종·책·글자 삽화       │ 산·곰·호랑이 삽화       │
│ [수업 선택]             │ [수업 선택]             │
├────────────────┬───────┴────────┬───────────────┤
│ 3·1절 · 03.01  │ 제헌절 · 07.17 │ 광복절 · 08.15 │
│ 날짜와 의미    │ 날짜와 의미    │ 날짜와 의미    │
└────────────────┴────────────────┴───────────────┘
```

- 이번에 완성하는 한글날·개천절을 크게 배치합니다.
- 나머지 세 카드도 눌러 볼 수 있지만 ‘소개 보기’로 표시합니다.
- 수업 선택창에서 `1–2학년 / 3–4학년 / 5–6학년`, `골든벨 / 학습지`를 고릅니다.
- 기본 수업은 40분입니다. 준비물과 QR 사용 여부를 한 장에서 확인한 뒤 시작합니다.
- 수업 선택 화면에 **미리 보기, 학습지 인쇄, 처음부터 시작**을 제공합니다.

## 3. 학년별로 실제로 달라지는 것

| 설계 요소 | 1–2학년: 발견하고 말하기 | 3–4학년: 비교하고 만들기 | 5–6학년: 근거로 설명하기 |
|---|---|---|---|
| 설명 방식 | 친근한 이야기, 그림과 짧은 말 | 원인·과정·결과, 두 개념 비교 | 자료 해석, 의미 확장, 주장과 근거 |
| 한 화면 글 | 핵심 문장 1–2개 | 핵심 문장 2–3개 | 핵심 주장과 짧은 자료 1개 |
| 교사 역할 | 문항을 읽고 말하기 지원 | 비교 질문과 제작 활동 안내 | 증거 질문과 토의 진행 |
| 학생 조작 | 큰 그림 고르기, 눌러 보기 | 순서 맞추기, 조합·분류하기 | 판단 후 근거 고르기·적기 |
| 참여 조직 | 함께 답하기 → 짝에게 말하기 | 개인 조작 → 짝 설명 | 개인 판단 → 짝 토론 → 공유 |
| 평가 | 그림 선택·OX·구두 설명 | 객관식·순서·짧은 적용 | 개념 구분·자료 판단·이유 설명 |
| 학습지 | 그림 중심, 쓰기 칸 최소 | 조합·연결·짧은 문장 | 근거 칸, 비교·실천 제안 |
| 피해야 할 것 | 연도 외우기, 긴 읽기, 속도 경쟁 | 사실만 외우는 반복 문제 | 어려운 낱말만 늘린 저학년 활동 |

**공통 원칙:** 저학년의 발달 수준을 읽기 능력 하나로 단정하지 않습니다. 모든 학년에서 교사가 읽어 주기, 말로 답하기, 짝의 도움을 받기가 가능합니다. 심화 설명은 필요할 때만 펼칩니다.

## 4. 40분 수업의 공통 흐름

| 장면 | 시간 | 학생이 하는 일 | 선생님의 핵심 조작 |
|---|---:|---|---|
| 01. 호기심 열기 | 3분 | 그림을 보고 예상하기 | 시작·한 번 재생 |
| 02. 오늘의 미션 | 1분 | 무엇을 배울지 확인하기 | 다음 |
| 03. 이야기 속으로 | 6분 | 장면을 보고 질문에 답하기 | 장면별 공개 |
| 04. 원리를 눈으로 | 6분 | 조작하며 관계 발견하기 | 시범·학생 지명 |
| 05. 영상으로 확인 | 4분 | 관찰 질문을 갖고 보기 | 영상 시작·멈춤 |
| 06. 내가 해 보는 활동 | 8분 | 만들기·분류·짝 토의 | 활동 시작·타이머 |
| 07. 잠깐 확인 | 3분 | 1–2문제에 답하고 수정하기 | 정답·해설 공개 |
| 08. 핵심 정리 | 2분 | 오늘 배운 두 가지 말하기 | 핵심 순서대로 공개 |
| 09. 마무리 평가 | 6분 | 골든벨 **또는** 학습지 | 평가 시작·정답 공개 |
| 10. 한 문장 가져가기 | 1분 | 생활 속 실천 한 가지 말하기 | 마무리 |
| **합계** | **40분** | | |

- 영상 4분에는 시청 전·후 질문도 포함합니다. 원본 전체가 길면 교사가 사전에 확인한 짧은 구간을 사용합니다.
- 골든벨과 학습지를 모두 수업 중에 강제하지 않습니다. 둘 다 쓰려면 학습지를 확장 활동 또는 다음 차시로 돌립니다.
- 조작이 오래 걸리면 다음으로 넘길 수 있으며, 화면에 남은 활동이 수업 진행을 막지 않게 합니다.

## 5. 한글날: 세 개의 수준별 수업

### A. 1–2학년 — 「마음을 전하는 글자」

**학습목표**
1. 한글날이 한글을 기리는 날임을 말할 수 있습니다.
2. 한글로 마음을 전하는 말을 만들고 소개할 수 있습니다.

| 장면 | 화면·이야기 | 참여와 연출 |
|---|---|---|
| 01 | 글자가 없는 가게와 편지: “어떤 것이 불편할까요?” | 간판의 글을 가렸다가 공개. 생활 속 필요 발견 |
| 02 | 오늘의 미션: “우리 글자로 마음을 전해요.” | 목표 2개를 그림과 함께 공개 |
| 03 | 백성이 뜻을 쉽게 펴도록 새 글자를 만든 세종 이야기 | 세종·사람들·책 삽화를 순서대로 보여 줌 |
| 04 | ㄱ과 ㅏ가 만나 ‘가’가 되는 순간 | 글자 카드를 누르면 합쳐짐. 교사와 함께 2번 시도 |
| 05 | 한글 관련 짧은 영상 | 보기 전 “한글로 무엇을 할 수 있나요?” |
| 06 | 고마워·사랑해·괜찮아 중 마음에 드는 말 고르기 | 화면 또는 종이 카드로 말 만들기, 짝에게 말하기 |
| 07 | 한글날과 관련 있는 그림 찾기 | 그림 2–3개 중 선택, 교사 읽어 주기 |
| 08 | “한글로 내 생각과 마음을 전할 수 있어요.” | 학생 작품을 말로 소개하고 핵심 정리 |
| 09 | 그림 골든벨 4문항 또는 그림 학습지 | OX·선택·구두 문항, 탈락 없음 |
| 10 | 내가 오늘 전하고 싶은 말 | 한 학생씩 또는 짝끼리 한 문장 |

**평가 예:** “한글날은 한글을 기리는 날이에요. O일까요, X일까요?” → O. 교사는 그림과 함께 읽어 줍니다. 날짜·연도 암기를 핵심 성취로 삼지 않습니다.

### B. 3–4학년 — 「글자 발명 연구소」

**학습목표**
1. 한글을 만든 때와 널리 알린 때를 구분하고 만든 까닭을 설명할 수 있습니다.
2. 자음과 모음을 조합해 낱말을 만들고 상대가 이해하기 쉬운 말을 고를 수 있습니다.

| 장면 | 화면·이야기 | 참여와 연출 |
|---|---|---|
| 01 | 읽기 어려운 안내문을 만났어요 | 이해하지 못했을 때의 불편함 말하기. 한자를 열등한 문자로 묘사하지 않음 |
| 02 | “누구나 마음을 전할 수 있도록!” | 오늘 해결할 질문 2개 |
| 03 | 1443년 창제 → 1446년 반포 | ‘만듦’과 ‘널리 알림’ 카드를 타임라인에 놓기 |
| 04 | 자음·모음 조합 실험실 | 초성·중성·종성을 눌러 글자 조합. 잘못된 조합은 설명과 함께 안내 |
| 05 | 한글 관련 영상에서 목적과 쓰임 찾기 | 보기 전 질문 하나, 보기 후 짝 설명 |
| 06 | 우리 반 쉬운 말 안내문 만들기 | 어려운 표현을 쉬운 표현으로 바꾸기, 2인 활동 |
| 07 | 창제/반포 구분, 자음/모음 확인 | 문항 2개, 오답 이유까지 공개 |
| 08 | 만들어진 목적·글자 조합·배려하는 표현 | 학생이 먼저 말한 뒤 교사가 정리 |
| 09 | 골든벨 5문항 또는 조합·적용 학습지 | 개념 확인 3개 + 적용 2개 |
| 10 | 내일부터 바꿔 볼 우리 반 표현 | 쉬운 안내말 하나 제안 |

**평가 예:** “1446년은 훈민정음을 처음 만든 해일까요, 널리 알린 해일까요?” → 널리 알린 해. 정답 뒤에 1443/1446 타임라인을 다시 보여 줍니다.

### C. 5–6학년 — 「모두를 위한 문자, 한글」

**학습목표**
1. 한국어와 한글, 창제와 반포를 구분해 설명할 수 있습니다.
2. 한글 창제 취지를 바탕으로 정보에 접근하기 쉬운 안내문을 제안할 수 있습니다.

| 장면 | 화면·이야기 | 참여와 연출 |
|---|---|---|
| 01 | 말로는 이해하지만 글로는 읽지 못한다면? | 음성으로 전달되는 말과 문자 표기를 비교 |
| 02 | “누구나 읽고 이해할 수 있는 안내문은?” | 자료에 근거해 설명하는 미션 |
| 03 | 창제 목적과 창제·반포의 구분 | 출처가 있는 짧은 자료, 당시 상황과 현대적 적용을 구분 |
| 04 | 한글은 문자, 한국어는 언어 | ‘말/표기’ 사례를 분류. 한글 창제 이전에도 한국어가 있었음을 확인 |
| 05 | 영상 속 사실·설명·감상 구분 | 보며 근거 한 가지 찾기 |
| 06 | 누구나 이해할 수 있는 학교 안내문 설계 | 독자 정하기 → 표현 고치기 → 짝 피드백 |
| 07 | “한글이 생길 때 한국어도 생겼다” 판단 | X와 이유, 개념 혼동 바로잡기 |
| 08 | 문자의 목적과 오늘의 정보 접근 | 과거 취지와 현대 적용의 연결을 설명 |
| 09 | 골든벨 6문항 또는 근거형 학습지 | 사실 2 + 구분 2 + 적용 2. 서술형은 교사용 기준 제시 |
| 10 | 나의 안내문을 바꾼 이유 한 문장 | “누가 이해하도록 무엇을 바꾸었다.” |

**평가 예:** “‘한글’과 ‘한국어’는 같은 뜻이다”에 동의하나요? → 한글은 한국어 등을 적는 문자이며, 한국어는 언어이므로 같은 개념이 아닙니다. 학생 수준에 맞는 쉬운 설명을 인정합니다.

## 6. 개천절: 세 개의 수준별 수업

### D. 1–2학년 — 「하늘이 열린 날의 이야기」

**학습목표**
1. 개천절이 우리나라의 시작을 기리는 날임을 말할 수 있습니다.
2. 옛이야기를 듣고 주변 사람을 돕는 행동 한 가지를 고를 수 있습니다.

| 장면 | 화면·이야기 | 참여와 연출 |
|---|---|---|
| 01 | 구름 뒤에 어떤 이야기가 있을까요? | 누르면 구름이 열리고 산과 이야기책 등장 |
| 02 | “옛이야기를 듣고 함께 사는 마음을 찾아요.” | 목표를 짧게 소개 |
| 03 | 환웅·곰과 호랑이·웅녀·단군 | 장면마다 ‘옛날부터 전해 오는 이야기’ 표시, 실제 영상처럼 단정하지 않음 |
| 04 | 이야기 세 장면 순서 맞추기 | 큰 그림 카드를 누르는 방식. 끌기만 요구하지 않음 |
| 05 | 개천절 관련 짧은 영상 | 기억에 남는 장면 하나 찾기 |
| 06 | 모두에게 도움이 되는 행동 고르기 | 친구 돕기·차례 지키기 등 교실 상황카드, 짝과 역할놀이 |
| 07 | 개천절은 무엇을 기리는 날인가요? | 그림 선택, 문항을 교사가 읽어 줌 |
| 08 | 나라의 시작을 기억하고, 함께 사는 마음 배우기 | 한 문장 두 번 나누어 공개 |
| 09 | 그림 골든벨 4문항 또는 연결 학습지 | 이야기 이해·날의 의미·생활 실천 |
| 10 | 오늘 내가 할 작은 도움 | 구체적인 행동 한 가지 말하기 |

**평가 예:** “혼자 하기 어려워하는 친구를 돕는 행동”을 그림에서 찾고 왜 골랐는지 말합니다. 이야기를 잘 외우는 능력만으로 평가하지 않습니다.

### E. 3–4학년 — 「단군 이야기 탐험대」

**학습목표**
1. 개천절의 의미와 단군 이야기의 주요 흐름을 설명할 수 있습니다.
2. 홍익인간의 뜻을 이해하고 우리 반에서 실천할 일을 제안할 수 있습니다.

| 장면 | 화면·이야기 | 참여와 연출 |
|---|---|---|
| 01 | 달력의 10월 3일, 무엇을 기억할까요? | 날짜와 국경일 이름 연결 |
| 02 | “나라의 시작에 담긴 마음을 찾아요.” | 이야기 이해 + 실천 미션 |
| 03 | 단군 건국 이야기 | 환웅의 내려옴 → 곰 이야기 → 단군과 고조선. 전승임을 반복 확인 |
| 04 | 이야기와 확인된 사실을 다루는 방법 | ‘전해지는 이야기’와 ‘자료로 알아보는 역사’ 표지로 구분 |
| 05 | 개천절 영상 | 홍익인간이 어떤 뜻으로 설명되는지 듣기 |
| 06 | 우리 반 홍익인간 실천 카드 만들기 | 누구를 어떻게 도울지 상황별 제안 |
| 07 | 홍익인간의 뜻, 이야기의 순서 | 순서 맞추기·짧은 선택형 |
| 08 | 개천절의 의미·전승 이야기·오늘의 실천 | 학생 예시를 중심으로 정리 |
| 09 | 골든벨 5문항 또는 적용 학습지 | 의미 2 + 구분 1 + 적용 2 |
| 10 | 이번 주 실천 한 가지 | 교실에서 바로 할 수 있는 행동 선택 |

**평가 예:** “홍익인간을 우리 반에서 실천하는 방법을 하나 제안하세요.” → 특정 친구나 구성원에게 어떤 도움이 되는지 설명하면 인정합니다. ‘착하게 살기’만 쓰면 구체화 질문을 줍니다.

### F. 5–6학년 — 「신화와 역사 사이, 우리의 시작」

**학습목표**
1. 건국 신화가 전하는 의미와 자료로 확인해야 할 역사적 주장을 구분할 수 있습니다.
2. 홍익인간의 의미를 바탕으로 공동체의 문제를 해결하는 제안을 근거와 함께 제시할 수 있습니다.

| 장면 | 화면·이야기 | 참여와 연출 |
|---|---|---|
| 01 | “옛 기록에 나온 말은 모두 그대로 일어난 일일까요?” | 먼저 각자 판단, 정답은 보류 |
| 02 | “이야기의 의미와 확인할 근거를 함께 찾아요.” | 학습 질문 2개 |
| 03 | 단군 이야기와 개천절의 기념 의미 | 이야기 내용·기념일·역사적 검증의 질문을 분리 |
| 04 | 자료 탐정: 이 자료로 어디까지 알 수 있을까? | 전승 내용/자료 확인/추가 근거 필요 카드를 분류 |
| 05 | 영상 속 표현 관찰 | “전해진다”와 “확인된다”에 주목 |
| 06 | 우리 학교의 함께 해결할 문제 | 문제 → 도움받는 사람 → 실행 → 이유, 짝 제안 |
| 07 | 근거에 비해 결론이 너무 큰 문장 찾기 | 실제 연대와 사건을 신화만으로 확정하지 않음 |
| 08 | 신화의 문화적 의미와 역사 탐구의 방법 | 신화를 거짓말로 단순 치부하지 않도록 정리 |
| 09 | 골든벨 6문항 또는 자료·근거 학습지 | 개념 2 + 자료 판단 2 + 실천 2 |
| 10 | “이 자료로 알 수 있는 것 / 더 알아볼 것” | 한 문장으로 학습 마무리 |

**평가 예:** “단군 이야기가 기록되어 있다는 사실만으로 이야기 속 모든 사건을 실제 사건으로 확정할 수 있나요?” → 어렵습니다. 어떤 주장을 확인하려면 어떤 자료가 더 필요한지 설명하도록 돕습니다.

## 7. 이미지와 모션: 기억에 남는 장면 만들기

### 시각 방향

- **장면에 맞는 시각 표현:** 첫 화면은 친근한 입체 상징 삽화, 역사 본문은 실물 자료와 고증 참고 재현, 단군 이야기는 장엄한 신화 그림으로 구성합니다. 장면 속 학습 단서가 한눈에 들어오게 만듭니다.
- 한글날은 책·글자·따뜻한 금빛, 개천절은 산·하늘·깊은 초록을 중심으로 구분합니다.
- 첫 화면은 정돈된 카드형, 수업 화면은 한 장면이 크게 차지하는 발표형으로 구성합니다.
- 그림에 긴 한글 문장을 생성하지 않습니다. 제목·설명·정확한 자모는 화면 위에 실제 글자로 얹습니다.
- 저학년에는 표정과 상황을, 고학년에는 자료와 판단 단서를 강조합니다. 공통 삽화를 재사용하되 화면 구성과 질문은 달라집니다.
- 역사 인물·단군 이야기는 **교육용 상상 삽화**로 표시합니다. 실제 유물·원문·사료가 필요한 장면은 출처와 이용 조건을 확인한 실물 자료를 사용합니다.

### 모션그래픽 구성

| 모션 | 학생이 이해할 내용 | 조작·제어 |
|---|---|---|
| 카드의 짧은 들림·그림의 미세한 이동 | 선택 가능한 수업 | 가리키거나 선택할 때만 반응 |
| 글자 없는 장면 → 글자 등장 | 문자가 생활에서 하는 역할 | 교사 클릭으로 전환 |

| 창제 → 반포 타임라인 | 만드는 것과 널리 알리는 것의 차이 | 두 사건을 한 번씩 공개 |
| 구름 열림 → 이야기책 장면 전환 | 개천절 이야기 진입 | 한 번 재생, 건너뛰기·다시 보기 |
| 그림 순서 정렬 | 사건의 흐름 | 카드 선택·앞뒤 이동 가능 |
| 정답 공개·해설 확대 | 답보다 이유 확인 | 정답과 해설을 차례로 공개 |
| 마지막 종과 짧은 축하 효과 | 참여의 성취감 | 소리 기본 꺼짐, 한 번 재생 |

**제작 주의:** 이미지 속 요소를 움직여야 하는 장면은 배경·인물·전경을 분리한 자산이 필요합니다. 한 장짜리 삽화만 만든 뒤 개별 인물 움직임까지 가능하다고 가정하지 않습니다. 발표 중 계속 움직이는 배경, 과도한 줌, 번쩍임은 사용하지 않습니다.

## 8. 교사가 편해지는 발표 기능

| 기능 | 교실에서의 동작 | 완료 기준 |
|---|---|---|
| 큰 발표 화면 | 설명은 크게, 조작 도구는 아래쪽 | 교실 뒤에서 읽을 수 있는 글 크기로 실제 투사 확인 |
| 이전·다음 | 화살표 키·큰 버튼·터치 | 입력창 사용 중에는 이동 단축키가 작동하지 않음 |
| 전체 화면 | 한 번 눌러 발표, Esc로 복귀 | 지원하지 않는 환경에서도 수업 가능 |
| 목차 | 모든 장면을 한눈에 보고 이동 | 영상·활동·평가 장면으로 바로 이동 |
| 교사용 도움말 | 발문·예상 답·오개념·준비물 | 학생 화면에서는 접힌 상태가 기본 |
| 단계별 공개 | 설명·정답·해설이 순서대로 등장 | 이전 화면으로 갔다 와도 의도치 않게 답이 노출되지 않음 |
| 활동 타이머 | 시작·일시정지·초기화·시간 조절 | 다음 화면으로 가면 알림이 뒤늦게 울리지 않음 |
| 소리·모션 | 소리 기본 꺼짐, 모션 줄이기 | 브라우저 자동재생 제한과 시스템 동작 줄이기 대응 |
| 진행 기억 | 이 기기에서 마지막 장면 이어가기 | 수업·학년별 구분, 처음부터 시작 제공 |
| 대체 진행 | 인터넷·학생 기기 없이 교사 화면으로 활동 | QR를 건너뛰어도 핵심 목표 달성 가능 |

교사용 설명에는 **① 읽어 줄 말 ② 물어볼 질문 ③ 예상 답 ④ 틀리기 쉬운 점 ⑤ 막혔을 때 도움말**을 같은 순서로 둡니다. 저학년 설명을 준비하다 고학년 자료와 섞이는 일이 없도록 학년 표시를 유지합니다.

교사 도움말을 학생에게 전혀 보이지 않게 하려면 별도 발표자 창과 확장 화면 설정이 필요합니다. 기본안은 접을 수 있는 도움말이며, 별도 발표자 창은 기본 수업 검증 뒤 확장합니다.

## 9. 인터랙티브 활동과 QR

### 수업에 꼭 필요한 네 가지 활동 도구

| 도구 | 1–2학년 | 3–4학년 | 5–6학년 |
|---|---|---|---|
| 한글 조합 | 제시된 자음·모음 고르기 | 받침 포함 낱말 조합 | 문자·언어 구분과 쉬운 안내문에 적용 |
| 이야기 순서 | 그림 3장 | 그림·문장 4–5장 | 흐름 확인 후 전승·자료 판단으로 확장 |
| 상황 카드 | 도움이 되는 행동 고르기 | 누구를 어떻게 도울지 제안 | 실행 가능성과 근거 비교 |
| 생각 한 줄 | 말로 답하기·교사 기록 | 짧은 문장 | 주장 + 이유 |

- 드래그뿐 아니라 **눌러 선택 → 위치 선택**, 앞·뒤 버튼, 키보드로도 활동할 수 있게 합니다.
- 틀렸을 때는 실패 효과 대신 다시 생각할 단서를 줍니다.
- 학생 글은 안전하게 일반 텍스트로 표시하며, 마크업이나 스크립트로 실행하지 않습니다.

### QR의 역할을 명확히 구분

1. **개인 활동 QR:** 선택한 주제·학년·활동으로 바로 들어갑니다. 학생은 자기 기기에서 활동하고 피드백을 받습니다.
2. **영상·참고 자료 QR:** 확인된 원본 자료로 이동합니다. 수업 중 꼭 필요한 경우에만 사용합니다.
3. **교사 지정 링크 QR:** 학교에서 사용하는 설문·학급 게시판 링크를 입력해 연결할 수 있습니다.

**기본안에는 실시간 응답 수집이 없습니다.** 학생은 기기 안에서 답을 확인하고, 교사는 손들기·짝 설명·대표 발표로 확인합니다. 전체 학생의 답을 자동으로 모으고 교사 화면에 집계하려면 수업 코드·서버 저장·접속 권한을 갖춘 별도 기능이 필요합니다. 개인 활동 QR를 실시간 수집 기능처럼 안내하지 않습니다.

**학생 접속 조건:** QR은 학생 기기에서 열리는 주소여야 합니다. 교사 컴퓨터의 `localhost` 주소나 교사 전용 비공개 주소는 학생용으로 사용할 수 없습니다. 본 제작 후 학생이 접근 가능한 배포 주소와 접근 범위를 확정하고 실제 스마트폰으로 스캔 검증합니다. 첫 화면에 개인정보를 입력하게 하지 않습니다.

## 10. YouTube를 수업에 자연스럽게 넣기

- 자동재생하지 않습니다. **보기 전 질문 → 재생 → 멈추고 생각하기 → 수업 복귀**의 구조를 고정합니다.
- 영상 카드에는 제목, 제작자, 선정 이유, 확인한 재생 길이·시청 구간, 원본 열기를 표시합니다.
- 세 학년군에 같은 영상을 무조건 쓰지 않습니다. 같은 영상이라도 발문·구간을 바꾸고, 저학년에 어려운 경우 다른 자료를 선정합니다.
- 외부 영상의 광고·관련 영상·임베드 허용 여부를 앱이 완전히 제어할 수 있다고 약속하지 않습니다.
- 재생이 막히면 원본 링크를 열거나 동일 학습목표의 **3장 요약 + 교사 설명**으로 진행합니다.
- 영상 파일 자체를 무단 복제하지 않고 원본 링크·임베드를 사용합니다.

현재 확보한 후보와 출처는 [자료 조사 기록](../knowledge/sources.md) 및 [학년별 교육과정 상세](../knowledge/grade-level-curriculum.md)에 정리합니다. 링크 발견과 실제 재생 검증은 구분합니다. 수업 구간은 교사가 실제 내용을 검토한 후 확정합니다.

## 11. 골든벨과 학습지

### 골든벨 운영

`문제 읽기 → 개인 생각 → 모두 답 들기 → 정답 공개 → 이유 설명 → 다음 문제`

- 탈락 없이 마지막 문제까지 모두 참여합니다.
- 점수·속도보다 “왜 그렇게 생각했는지”를 우선합니다.
- 저학년 4문항, 중학년 5문항, 고학년 6문항을 기본으로 합니다.
- 정답을 누르자마자 표시하지 않고 교사가 공개합니다. 학생 개인 모드는 제출 뒤 피드백을 줍니다.
- 서술형에는 예시 답과 인정 기준을 제공하며, 정확히 같은 문장을 써야만 정답으로 처리하지 않습니다.
- 기본 골든벨은 학급 공통 발표형입니다. 개인 순위표·학생별 성적 자동 저장은 포함하지 않습니다.

### 학습지 산출물

**6종의 학생용 학습지 + 각 학습지의 교사용 정답·해설**을 만듭니다. A4 1쪽을 기본으로 하고 글씨 크기와 답칸이 부족하면 2쪽으로 나눕니다.

| 학년군 | 구성 | 형식 |
|---|---|---|
| 1–2 | 그림 선택 2개 + 연결 1개 + 말·그림 표현 1개 | 읽어 주기 가능, 흑백에서도 구분 |
| 3–4 | 개념 확인 2개 + 조합·순서 1개 + 적용 1개 | 짧은 쓰기, 힌트 포함 |
| 5–6 | 개념 구분 2개 + 자료 판단 1개 + 근거 있는 제안 1개 | 간단한 자료와 충분한 답칸 |

평가의 목표·문항·채점 기준 연결은 [평가 품질 검토](../knowledge/assessment-quality.md)로 점검합니다. 마지막 문항에서 드러난 오개념에 따라 다시 볼 장면을 교사 해설에 적습니다.

## 13. 제작 순서와 단계별 결과물

| 단계 | 하는 일 | 확인 가능한 결과물 |
|---|---|---|
| 1. 설계 확정 | 6종 수업 목표·장면·문항·원자료 정리 | 이 계획 + 학년별 대본 + 출처표 |
| 2. 대표 수업 제작 | 3–4학년 한글날을 첫 화면부터 평가까지 연결 | 클릭해 끝까지 진행하는 1개 완성 수업 |
| 3. 표현 확립 | 실제 삽화, 글자 조합, 전환·정답 공개 적용 | 대표 수업의 시각·조작 기준 |
| 4. 6종으로 확장 | 저·고학년 한글날, 개천절 3종 제작 | 모든 학년·주제 조합의 독립된 수업 |
| 5. 교실 준비 | QR 학생 화면, 영상 대안, 학습지·정답지 | 학생 접속과 인쇄물까지 연결 |
| 6. 최종 검수 | 내용·작동·투사·모바일·인쇄·수업 시간 확인 | 아래 인수 기준을 통과한 수업 패키지 |

**대표 수업을 끝까지 먼저 만드는 이유:** 6종의 첫 화면만 만들어 놓는 대신, 한 수업에서 교사의 전체 흐름과 활동·평가의 연결을 확인한 뒤 같은 품질을 확장하기 위함입니다.

## 14. 완성 판정 기준

### 내용과 수업

- [ ] 6개 수업 모두 학습목표·발문·활동·평가가 서로 연결된다.
- [ ] 학년 전환 시 글자 수뿐 아니라 질문·활동·평가 방식이 달라진다.
- [ ] 각 수업의 단계별 시간이 40분이며, 영상과 기기 없는 대체 경로도 가능하다.
- [ ] 한글 관련 연도·자모 수·문자/언어 구분, 신화/역사 표현을 검수했다.
- [ ] 골든벨과 학습지의 모든 답·해설·인정 기준을 확인했다.

### 교사와 학생의 사용

- [ ] 첫 화면에서 주제·학년을 골라 수업을 시작할 수 있다.
- [ ] 이전·다음·목차·전체 화면·정답 공개가 모든 수업에서 작동한다.
- [ ] 활동을 다시 시작해도 이전 답이나 타이머가 잘못 남지 않는다.
- [ ] QR로 주제·학년·활동이 정확히 열리며 스마트폰에서 직접 확인했다.
- [ ] 학생 기기·인터넷이 없어도 같은 목표를 향해 수업을 이어 갈 수 있다.
- [ ] 검토된 영상이 재생되거나 명확한 대체 경로를 보여 준다.

### 이미지·모션·출력

- [ ] 모든 이미지가 실제 자산으로 로드되며 깨진 파일·임시 그림이 없다.
- [ ] 그림의 국기·문자·손·인물·시대 표현을 눈으로 확인했다.
- [ ] 16:9 교실 화면, 노트북, 스마트폰에서 글이 잘리지 않는다.
- [ ] 수업 글은 발표 화면에서 충분히 크며 교실 뒤에서 확인했다.
- [ ] 키보드·터치로 활동 가능하며 색만으로 정답을 구분하지 않는다.
- [ ] 모션 줄이기·음소거가 작동한다.
- [ ] 학생용 인쇄물에 교사 정답이 섞이지 않고 A4 흑백 출력도 읽힌다.
