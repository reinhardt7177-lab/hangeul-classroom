# 한글날 수업: 탐색과 근거 설명을 강화하는 설계

확인일: 2026-09-26. 검토 대상은 `content/hangeul-data.js`의 초등 1~2 / 3~4 / 5~6학년용 3종 수업이다. 제작 담당과 범위를 맞춘 뒤 **저학년 q2 전이형·중학년 q4 오개념 보기·04/06/07 교사 노트의 탐색과 피드백**을 데이터에 반영했다. 교사 안내의 저학년 정답표도 동기화했다. 학습지 문항은 유지했고 PDF 담당에게 영향 범위를 전달했다. 아래 고학년 문항 변경은 후속 제안으로 남아 있다.

## 참고하는 것과 주장하지 않는 것

미국 전체가 따르는 **단일한 공식 수업 순서가 있는 것은 아니다.** 미국 교육부는 교육과정·기준이 주와 지역 중심으로 정해진다고 설명한다. 따라서 ‘미국 표준 수업을 그대로 따랐다’고 표시하지 않는다. [미국 교육부 FAQ](https://www.ed.gov/about/contact-us/faqs/Elementary%20and%20Secondary%20Education)

이번 수업은 아래 세 자료의 일부 원칙을 한글날 계기교육에 적용한다. 자료가 이 앱의 효과나 ‘최고 수준’을 직접 입증하는 것은 아니다. 학급에서 학생의 설명과 오답을 보고 계속 고친다.

## IES 근거 수준을 섞지 않기

| 이 수업과 관련한 권고 | 해당 2007 안내서의 표시 | 설계 판단 |
|---|---|---|
| 핵심 내용을 다시 꺼내는 퀴즈, 깊이 있는 설명 질문 | Strong evidence | ‘정답 클릭’ 뒤 까닭을 듣고, 도움 없이 먼저 생각하게 한다. |
| 시간 간격 두기, 완성된 풀이와 문제 해결 교대, 그림과 말 설명, 구체와 추상 연결 | Moderate evidence | 시범을 따라 하는 데서 끝내지 않고 다른 예에 적용하게 한다. |
| 새 주제 전 사전 질문, 퀴즈로 더 배울 부분 판단 | Minimal evidence | 사전 질문은 관심·생각 확인에 사용하며 그 자체를 강한 효과로 홍보하지 않는다. |

‘Minimal’은 효과가 없다는 뜻으로 사용하지 않는다. 이 표는 안내서가 당시 부여한 근거 수준을 구분한 것이며, 최신 모든 연구를 새로 종합한 결과는 아니다. [IES 권고·증거 수준 원문](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)

## 40분·10장면을 유지하며 바꿀 사고 과정

**관찰 → 예상 → 직접 탐색 → 설명 → 적용 → 이유를 듣고 수정**을 반복한다. 수업의 역사적 사실은 자료로 정확히 알려 주되, 학생이 직접 확인할 수 있는 글자 조합과 안내문의 효과는 먼저 살펴보게 한다. 역사 연대를 추측해서 발견하도록 만들지 않는다.

아래 대응은 **이 프로젝트의 설계 판단**이다. 특정 기관이 아래 10장면이나 시간을 승인했다는 뜻이 아니다.

| 장면·시간 | 학생이 실제로 해야 할 생각 | 교사의 운영 변화 | 참고 연결 |
|---|---|---|---|
| 01 관찰 3분 | 그림·표기에서 본 것과 생각을 구분 | “어디를 보았나요?” 후 “무엇을 예상하나요?” | 5E 관심·사전 생각 |
| 02 목표 1분 | 끝나면 설명할 것을 알기 | “날짜를 안다”와 “뜻을 전한다”를 분리해 목표 제시 | UDL 목표 명료화 |
| 03 이야기 6분 | 불편한 상황을 예상하고 자료로 목적 확인 | 질문→잠깐 생각→근거 설명. 사실·요약·상상 삽화 표시 | 그림·말 설명, 근거 읽기 |
| 04 원리 6분 | 예상→낱자 조작 또는 표기 비교→변화 설명 | 정답 시범을 바로 보여 주지 않고 짧은 탐색 시간 확보 | 5E 탐색·설명 |
| 05 영상 4분 | 내 예상과 실제 관찰 비교 | 관찰 질문 하나를 먼저 제시하고 본 근거를 말하게 함 | 여러 표상 연결 |
| 06 적용 8분 | 시범의 원리를 새 글·상황에 사용 | 짧은 생각 시범→학생의 다른 예→짝이 읽고 검토 | 시범·연습 교대, 적용 |
| 07 확인 3분 | 도움 없이 먼저 답하고 이유 설명 | 힌트는 시도 후 선택. 오답은 근거를 보고 한 번 수정 | 회상·행동 피드백 |
| 08 정리 2분 | 연결되는 개념을 자기 말로 정리 | 핵심 문장을 보여 주기 전 한 가지 먼저 말하게 함 | 회상·설명 |
| 09 평가 6분 | 관찰·조합·판단·적용을 다른 방식으로 표현 | 4/5/6문항 유지, 이유 문항을 점수와 별도로 확인 | 평가·여러 응답 방식 |
| 10 전이 1분 | 다시 확인할 개념과 실천 정하기 | “어느 부분을 다시 보면 좋을까?”를 선택 | 자기 점검 |

03의 역사 설명이 04의 탐색보다 앞에 있으므로 **엄격한 5E 순서 그대로라고 부르지 않는다.** 04 내부에서 탐색→학생 설명→교사 정리를 만들고 06에서 다른 상황에 적용하는 방식이다.

## 문제의 질을 높이는 최소 변경안

현재 문항 수와 `id`, 스키마를 유지한다. 아래 중 **저학년 q2와 중학년 q4는 반영 완료**, 나머지 문항의 변경은 검토 제안이다. 정답 위치가 바뀌면 앱과 교사 자료를 반드시 함께 갱신한다.

### 1~2학년: 4문항 유지

| 문항 | 현재 판단 | 개선안 |
|---|---|---|
| q1 글자로 마음 전하기 | 목표에 맞음. 현재 텍스트 보기만 읽으면 ‘관찰형’ 구현은 아님 | 인사·쪽지·말하기의 동등한 그림을 제공하고 “무엇을 보고 골랐니?” 구술 추가. 그림 미구현이면 ‘상황 선택’으로 정확히 부른다. |
| q2 ㄴ+ㅏ→나 | 같은 시범의 반복이라 적용 확인이 약함 | **‘나’에서 ㅏ를 ㅓ로 바꾸면?** 보기 ‘나 / 너 / 다’, 답 index 1. 학생이 바뀐 부분도 가리킴. |
| q3 날짜 OX | 기초 목표 확인으로 유지 가능 | 답 공개 전 도움 없이 선택, 틀리면 날짜 그림을 보고 다시 말하기. |
| q4 마음과 까닭 | 구두·그림 표현이 목표와 맞음 | ‘좋은 말인가’뿐 아니라 누구에게 어떤 뜻인지 확인. 예시와 문장이 달라도 인정. |

q2 개선 후 해설 예: “ㄴ은 그대로이고 ㅏ가 ㅓ로 바뀌어 ‘너’가 돼요.” 힌트 예: “바뀐 낱자 하나를 찾아 손으로 짚어 보세요.”

### 3~4학년: 5문항 유지

| 문항 | 현재 판단 | 개선안 |
|---|---|---|
| q1 날짜·뜻 OX | 하나의 문장에 날짜와 의미가 함께 있어 틀린 지점 진단이 어려움 | 정답은 유지하되 이유 질문을 “날짜와 기념하는 뜻을 하나씩 말하기”로 분리. |
| q2 창제·반포 | 사건 구분에 맞음 | 보기만 읽기보다 연도·사건 카드를 먼저 떠올리게 한 뒤 선택. |
| q3 한 조합 | 조합 관찰에 맞음 | ‘한’의 어느 위치가 근거인지 짚기. 네 보기는 이 문항에 필요한 선택이며 전 문항 표준이 아님. |
| q4 창제 목적 | ‘어렵게/배운 사람만’은 너무 명백하게 나빠 보이는 오답 | 보기 개선: **① 글씨 모양을 더 화려하게 꾸미려고 / ② 백성이 쉽게 배우고 뜻을 전하도록 / ③ 같은 내용을 더 빨리 베껴 쓰도록.** 답 index 1 유지. |
| q5 안내문의 도움 | 적용·설명이 목표와 맞음 | 내 수정 문장이나 남긴 정보 하나를 근거로 답하게 하기. |

q4 오답은 사실인 설명으로 가르치지 않는다. 해설은 “모양이나 속도 자체보다, 글을 배우고 뜻을 전하는 데 겪는 어려움을 돕는 목적이 중심이에요”로 정리한다.

### 5~6학년: 6문항 유지

| 문항 | 현재 판단 | 개선안 |
|---|---|---|
| q1 문자·언어 | 정의 선택으로만 맞힐 수 있음 | 사례 전이형: **‘안녕’을 ‘annyeong’으로 적으면 무엇이 달라질까?** ① 쓰는 문자가 달라진다 / ② 한국어가 영어로 바뀐다 / ③ 인사말 뜻이 반대로 바뀐다. 답 index 0. |
| q2 언어가 먼저 존재 OX | 핵심 오개념 확인에 맞음 | X 이후 정확한 문장 한 줄로 고치기. |
| q3 창제·반포·날짜 단정 | 사실 정확성 확인에 맞음 | 근거가 확인된 범위와 현재 기념일을 구별하도록 유지. |
| q4 자료가 지지하는 주장 | 자료→추론의 연결이 있음 | 자료 원문과 수업용 요약을 구분하여 표시하고, 뒷받침하지 않는 보기를 하나 설명하게 함. |
| q5 안내문 재작성 | 적용에 맞지만 수업에서 같은 문장을 그대로 고침 | 06과 다른 예로 전이: **‘금일 13:00 도서관 집결, 필기구 지참’.** 답 예: ‘오늘 오후 1시에 도서관으로 모이세요. 필기구를 가져오세요.’ |
| q6 수정 이유·목적 | 근거 설명에 적합하나 세 요구가 길 수 있음 | ‘바꾼 표현→독자에게 주는 도움→창제 목적’의 세 작은 말틀을 제공. |

고학년 q5를 바꾸면 뒤 문항 q6의 ‘안내문’이 새 예를 가리키게 해설을 맞춘다. 새로운 예에서 정보 보존을 확인할 수 있어야 적용 평가가 된다. 원자료에서 특정 문장 수정의 효과까지 직접 입증했다고 주장하지 않는다.

## 피드백은 정답 다음 행동까지

공통 흐름: **먼저 답하기 → 이유 말하기 → 근거 확인 → 고쳐 보기.** 힌트 사용은 벌점이 아니다. 최초 답과 도움 뒤의 답은 교사가 구분해 관찰한다.

| 반응 | 피드백 예 | 확인할 다음 행동 |
|---|---|---|
| ㄴ+ㅓ를 ‘나’로 읽음 | “옆 낱자가 처음 것과 어떻게 달라졌나요?” | 바뀐 모음을 짚고 다시 읽기 |
| 1446년을 창제로 연결 | “새로 만든 사건과 널리 알린 사건을 각각 찾아 봅시다.” | 두 사건 카드를 바르게 연결 |
| 로마자를 영어로 단정 | “소리 내어 읽는 말은 같나요? 적는 모양은 같나요?” | 언어와 문자를 각각 답하기 |
| 쉬운 안내문에서 장소를 뺌 | “이 글만 읽고 어디로 갈지 알 수 있나요?” | 누락 정보를 찾아 수정 |

선택형 정답률만으로 설명 능력·실생활 적용을 모두 판단하지 않는다. 열린 답의 말·그림·타이핑은 같은 목표를 드러내는 대안이다. 쓰기 속도나 기기 보유 여부를 학습 성취로 혼동하지 않는다. 이는 CAST의 응답 방식·표현 지원을 이 수업에 적용한 판단이다. [CAST 3.0](https://udlguidelines.cast.org/)

## 차시 이후의 짧은 다시 보기

40분 안의 여러 확인은 **같은 수업 안의 회상**이다. 장기 간격 학습을 모두 구현한 것이 아니다. 교사가 가능하면 약 1주 뒤 다른 예로 2분 확인하고, 몇 주 뒤 학급 안내문을 쓰는 시간에 다시 적용한다. 구체적인 간격은 학급 상황에 맞춘 설계이며 ‘최적의 간격’으로 확정하지 않는다. IES 원문은 주·월 단위 지연 후 핵심 내용 재검토를 권한다. [IES 간격 학습 권고](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)

## 반영 전 확인

- [ ] 화면에서 학생의 첫 생각을 듣는 시간이 실제로 있다.
- [ ] 교사의 설명과 학생의 직접 탐색을 구별했다.
- [ ] 그림은 답의 근거를 담고 있으며 단순 장식에 머물지 않는다.
- [ ] 보기의 길이·색·표정으로 정답을 눈치채게 하지 않는다.
- [ ] 같은 시범 복사가 아닌 다른 예에서의 적용을 적어도 한 번 본다.
