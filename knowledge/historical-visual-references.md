> 이 문서는 조사·설계 자료이다. 아래 외부 사진은 아직 내려받거나 수업에 삽입하지 않았다.

## 1. 이미지 사용 방향

이미지를 풍성하게 쓰되, 학생이 **사진으로 확인한 것 / 자료를 바탕으로 상상한 것 / 신화 속 이야기**를 구분하게 한다.

| 화면의 이미지 유형 | 역할 | 학생 화면에 붙일 표시 |
|---|---|---|
| 기존 클레이 시안 5종 | 랜딩 화면의 국경일 안내·분위기 형성 | 국경일 상징 그림 |
| 실제 유물·문헌 사진 | 형태, 재료, 옛 글자, 제작 시기 관찰 | 실물 자료 · 유물명 · 제작 시대 · 소장처 |
| 사료에 근거한 사실적 재현 | 당시 사람의 문제·행동·생활을 이해 | 자료를 바탕으로 상상한 장면 |
| 단군 신화 그림 | 전승의 줄거리·의미를 이해 | 단군 신화를 표현한 상상 그림 |
| 현대적 개념도·한글 조합 화면 | 글자의 원리나 오늘의 실천을 설명 | 원리 설명 그림 / 오늘의 생활 |

기존 `public/assets/hangul.png`의 세종 얼굴·의복·배경은 시각 콘셉트용 창작이다. 실제 세종 초상이나 15세기 복식·궁궐의 정확한 복원처럼 소개하지 않는다. `gaecheon.png`도 단군의 실재 모습을 복원한 자료가 아니다.

### 제작자가 특히 구분할 것

- **1443 창제 / 1446 해례본 간행·반포 / 1459 『월인석보』 / 1568 중간본 / 1946 영인본**은 서로 다른 사건 또는 물건의 제작 시점이다.
- 현대인이 읽는 ‘나랏말싸미…’ 번역·전사 화면과 해례본 실물 지면을 한 자료처럼 합치지 않는다.
- 실물에 없는 읽기 쉬운 현대 한글을 고문헌 사진 안에 덧써서 원문인 것처럼 보이게 하지 않는다. 읽기 도움은 옆 패널에 둔다.
- 현존 박물관 물건이 조선시대라는 사실만으로 세종 재위 때 사용되었다고 말하지 않는다.
- 복식은 **장면의 시기 → 행사/집무 구분 → 착용 신분 → 자료의 제작 연대** 순서로 확인한다. 확인되지 않은 소매 폭, 옷깃 재단, 용의 발톱, 신하 흉배, 갓 모양을 구체 사실로 단정하지 않는다.
- 현재 경복궁 사진은 유적 답사·장소 연결에 쓰고, 15세기 재현은 검증된 범위의 부분 공간과 소품으로 구성한다.

## 4. 이미지를 활용한 활동·4지선다 설계

아래는 이 조사에서 도출한 **수업 설계 제안**이다. 역사 자료가 직접 제안하는 활동이라는 뜻은 아니다.

| 방식 | 1–2학년 | 3–4학년 | 5–6학년 | 필요한 이미지 |
|---|---|---|---|---|
| 이미지 4지선다: 장면 읽기 | 한글을 읽고 도움을 받은 장면 고르기 | 글자가 필요한 상황과 창제 목적 연결 | 같은 상황에서 정보 접근을 개선한 방법과 근거 고르기 | 같은 인물·장소·화풍의 4장. 정답만 밝고 크게 그리지 않기 |
| 실물 찾기 | 책·관모·그림 중 교사가 말한 물건 찾기 | 유물 확대 부분과 전체 연결 | 제작 연대·재료 카드까지 맞추기 | 실제 사진 전체 1장 + 확대 보기. 변형 허용 여부 확인 |
| 지면 비교 | 옛 책에서 글자가 있는 곳 찾기 | 해례본 지면과 현대 설명문 구별 | 해례본·언해본·현대 번역·현대 글꼴 중 자료 설명과 맞는 것을 선택 | 출처가 분명한 4개 지면. 지면 글자를 AI가 만들어 쓰지 않기 |
| 시간 탐정 | 옛날/오늘 물건 구분 | 1446 책과 오늘의 앱 구분 | 영친왕 곤룡포·1772 임진자·현재 경복궁을 세종 시대 현물과 구별 | 시대를 검증한 사진 + 학생이 열 수 있는 정보 카드 |
| 순서 놓기 | 단군 신화 3–4장 순서 배치 | 원인·행동·결과 연결 | 이야기 장면과 후대 기록 과정을 두 줄 시간선에 구분 | 같은 인물 설정의 장면 연작. 신화 표시 항상 유지 |
| 사실과 표현 구분 | 사진과 상상 그림 구분 | 실물 자료/신화 그림/재현 장면 분류 | 자료가 증명하는 것과 증명하지 못하는 것을 설명 | 실물 2장 + 재현 1장 + 신화 1장 |
| 시각 근거 골든벨 | 그림을 고른 뒤 한마디 이유 말하기 | 근거 부분을 터치하고 답 선택 | 4개 주장 중 자료가 뒷받침하는 주장 선택 | 응답 후 근거 영역 확대·출처 표시 |
| 화면 속 오류 찾기 | 오늘 물건이 끼어 있는 부분 찾기 | 옛 책 지면에 현대 글자 혼입 찾기 | 잘못 붙은 시대·제작법·소장처 설명 고치기 | ‘오류 찾기용 창작 그림’ 표시. 오류를 정답 해설에서 회수 |

4지선다는 시각적 단서가 정답을 알려주지 않게 네 보기를 비슷한 크기·화풍·복잡도로 맞춘다. 정답은 선택 직후 **왜 맞는지, 어떤 부분이 근거인지** 이미지 확대·짧은 해설로 확인한다. 학습지에서도 같은 이미지 번호와 출처를 유지한다.

## 6. 공식 사진 사용 안내와 다음 확인 항목

[국립고궁박물관 소장품 사진 안내](https://gogung.go.kr/gogung/main/contents.do?menuNo=800163)는 박물관 제공 소장품 사진을 공공누리 제1유형으로 이용할 수 있다고 안내한다. 소장처와 사진 출처를 밝히고, 박물관이 이 교육 앱을 후원하는 것처럼 표시하지 않는다. 원하는 소장품 또는 적절한 고해상도 이미지가 없을 때의 신청 절차도 안내한다.

본 조사에서는 H08·H13·G03의 개별 페이지에 표시된 제1유형과 H02 게시물의 제4유형을 확인했다. 그 밖의 사진은 **링크와 고증 근거만 확보한 상태**이다. 실제 제작에서는 선택한 사진 원본·다운로드 경로·개별 사용조건을 기록하고, 조건이 맞지 않는 사진은 공식 페이지 연결 또는 독자 제작 설명도로 처리한다.

추가 조사 우선순위는 ① 장면별 연도 고정, ② 15세기 복식의 추가 사료, ③ 소품의 실제 제작 연대, ④ 채택할 문헌의 정확한 권차·판본·지면, ⑤ 각 사진의 이용조건이다. 이미지를 많이 만드는 단계에서도 이 다섯 항목을 확인한 장면부터 제작한다.
