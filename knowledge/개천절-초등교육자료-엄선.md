# 개천절 초등 계기교육 자료 엄선 기록

조사일: 2026-09-27. 이 문서는 교사가 바로 수업에 쓸 자료만 남긴 선정 기록이다. **공식성, 초등 적합성, 사실·전승의 구분, 관찰·활동 가능성**을 기준으로 삼았다. 출처의 문장과 이미지를 그대로 복제하지 않고, 사실 확인·교사용 링크·학생 탐구 발문의 근거로 사용한다.

## 보조 자료

- [국사편찬위원회: 청동기 시대의 비밀을 간직한 고인돌](https://contents.history.go.kr/mobile/eh/view.do?levelId=eh_r0010_0010): 실제 유적에서 무엇을 관찰하고 무엇을 추정하는지 보여 준다. 분량이 길어 전문을 수업에 넣기보다 고인돌 사진 관찰 발문만 차용한다. 이 글의 인원·인구 추정치를 확정 사실로 문제화하지 않는다.
- [행정안전부 어린이 국가상징: 태극기](https://www.mois.go.kr/chd/sub/a05/birth/screen.do): 개천절에 국기를 다는 생활 연결 자료다. 한 차시가 단군 이야기와 역사 탐구로 과밀해지면 선택 활동으로 둔다.
- [국립중앙박물관 교육플랫폼: 요령식 동검 감상자료](https://modu.museum.go.kr/explore/paper/20382): 교사가 자료를 열어 실물의 아랫부분·잘록한 허리·분리된 손잡이를 함께 살필 수 있다. 이 페이지의 활동지에는 **출처표시·비상업·변경금지** 이용 조건이 명시되어 있으므로 앱에 재가공해 넣지 않고 원문 링크로 안내한다.

## 이미지·영상 제작에 바로 적용할 기준

1. 이야기 영상은 **전승을 시각화한 장면**으로 제한하고, 정확한 고대 복식·건축·얼굴을 알아냈다는 인상을 주지 않는다. 한국의 화강암 산세, 소나무, 곰과 범 등 이야기의 필수 요소만 선별한다.
2. 유물 장면은 생성한 ‘그럴듯한 동검’을 실물처럼 제시하지 않는다. 실제 소장품은 박물관 원문으로 열거나, 별도 제작 시 명확히 교육용 도해로 분리한다.
3. 중국식 궁궐·기와문·용좌·황제관·한푸·선협·한자 장식은 사용하지 않는다. 그렇다고 고조선의 역사적 생활상을 후대 조선 한복과 궁궐로 대체하지도 않는다.
4. 날짜, 사료의 작성 시기, 유물의 증거 범위는 영상 자막보다 **교사의 다음 장면 발문과 노트**에서 확인한다. 화면의 글씨는 짧고 크며 실제 사진·상상 그림의 차이를 오도하지 않는다.

## 선정에서 제외한 방식

- 출처와 재이용 조건이 불분명한 블로그 PPT·활동지, 영상 속 역사 표현을 검증할 수 없는 짧은 애니메이션을 그대로 수업에 삽입하지 않는다.
- ‘단군의 모습’, ‘고조선 왕궁’, ‘정확한 국경 지도’, ‘기원전 2333년 10월 3일 현장’ 같은 장면을 실증된 역사 자료처럼 만들지 않는다.
- 초등 저학년에게 기년 계산과 8조법의 형벌 조항을 주된 학습 목표로 삼지 않는다. 고학년에게도 개천절 한 차시의 핵심은 **기념의 의미·자료의 성격·홍익인간**이다.

자료 링크의 접근성과 이용 조건은 배포 시 다시 확인한다. 기관 자료의 사진·활동지를 앱에 직접 저장하거나 변형할 때는 각 항목의 이용 조건을 별도로 검토한다.
