# 한글날·개천절 학년군별 수업 설계

**대상: 초등 1~2 / 3~4 / 5~6학년, 국경일별 10장면·40분씩 총 6종.** 이 문서는 제작을 위한 교수·학습 설계다. 실제 앱과 영상 재생을 검수한 결과는 아니다. 기존 `content/lessons.json`은 **3~4학년 9화면 기초데이터**이며, 최종 10장면 구조로 통합·재편성할 예정이다. 세 학년군 전체의 콘텐츠를 이미 구현한 것으로 보지 않는다.

일시적인 화려함보다 학생이 보아야 할 순서가 분명한 화면을 만든다. 학년군별로 글의 길이만 바꾸지 않고 **생각해야 할 문제, 활동 방법, 평가 기준**을 달리한다. 현재 자료는 계기교육용 설계이며 특정 교육과정 성취기준 코드에 직접 대응시켰다고 주장하지 않는다.

## 1. 학년군별 설계 기준

| 기준 | 1~2학년 | 3~4학년 | 5~6학년 |
|---|---|---|---|
| 중심 질문 | 무엇을 기억하는 날일까? | 왜 기념하며 내 생활과 어떻게 이어질까? | 어떤 근거로 설명하며 어떻게 판단할까? |
| 화면 글 | 핵심 문장 1~2개, 큰 그림 | 핵심 문장 2~3개, 비교 카드 | 주장·자료·질문을 구분한 짧은 읽기 |
| 교사 역할 | 소리 내어 읽어 주기, 몸짓 시범 | 개념 구분, 짝 대화 촉진 | 근거 확인, 해석과 사실 구분 안내 |
| 활동 | 고르기·잇기·그리기·말하기 | 분류·순서·조합·생활 적용 | 근거 비교·수정 설명·설계·토론 |
| 평가 | 날짜·뜻을 그림이나 말로 표현 | 개념을 구분하고 이유 말하기 | 근거와 한계를 포함해 설명하기 |
| 디지털 참여 | 교사 화면 중심, 선택적으로 한 기기 공동 사용 | 2인 1기기 또는 공책 병행 | 개인 또는 모둠 기기, 근거를 덧붙인 응답 |

공통 원칙: 골든벨은 전원 참여이며 탈락을 없앤다. QR 참여가 되지 않아도 같은 사고 과정을 종이·말·손짓으로 할 수 있다. 이름·학교·연락처 입력이나 학생 계정 가입이 학습의 전제가 되지 않도록 설계한다.

## 2. 한글날 1~2학년 — 글자로 마음을 전해요

### 학습목표

1. 한글날이 10월 9일이며 한글의 소중함을 기억하는 날임을 말이나 그림으로 나타낸다.
2. 한글로 짧은 마음의 말을 쓰거나 골라서 친구에게 전한다.

**핵심 설명 문장:** “세종은 사람들이 쉽게 배우고 마음을 전할 수 있는 글자를 만들었어요. 10월 9일 한글날에는 한글의 소중함을 기억해요.”

이 수업에서는 **1443·1446년을 암기시키지 않는다.** 필요한 경우 교사가 “먼 옛날 세종이 만들고, 사람들에게 널리 알려 주었어요”라고 설명한다. 숫자 28·24도 필수 평가에서 제외한다.

### 화면과 수업 흐름

| 화면 | 시간 | 학생이 할 일 | 교사의 설명·조작 |
|---|---:|---|---|
| 1. 내 이름이 반짝! | 3분 | 이름표·책·간판 그림에서 글자를 찾는다. | 글자 없는 그림과 글자 있는 그림을 차례로 보여 준다. |
| 2. 오늘의 미션 | 1분 | 오늘 기억할 날짜와 마음을 듣는다. | 짧게 읽어 준다. |
| 3. 세종의 선물 | 6분 | 등장인물의 마음을 고른다. | 사람들이 뜻을 전하도록 만든 글자라는 이야기를 읽는다. |
| 4. 글자 블록 놀이 | 6분 | 낱자를 눌러 ‘나’, ‘너’를 만들거나 따라 그린다. | ㄴ+ㅏ, ㄴ+ㅓ의 조합을 차례로 실행한다. |
| 5. 한글 모양 탐험 | 4분 | 영상·시연에서 모양을 찾는다. | 사전 확인한 약 2분 영상 + 대화 2분. |
| 6. 마음 쪽지 | 8분 | 말을 고르거나 쓰고 그림으로 꾸민다. | 그림·말·카드 선택을 허용한다. |
| 7. 그림으로 잠깐 확인 | 3분 | 장면 속 글자를 짚고 어떤 마음을 전하는지 말한다. | 관찰한 부분과 뜻을 듣는다. |
| 8. 핵심 정리 | 2분 | 날짜와 한글의 쓰임을 말한다. | 큰 글자·그림으로 정리한다. |
| 9. 모두의 골든벨 또는 학습지 | 6분 | 그림·OX 문제에 답한다. | 정답과 까닭을 순서대로 공개한다. |
| 10. 오늘의 한마디 | 1분 | 친구에게 마음의 말을 건넨다. | 생활 속 실천으로 연결한다. |

**학생 활동:** 큰 낱자 카드 조합 → 마음 쪽지 한 장. 쓰기의 정확성보다 뜻을 전한 경험을 먼저 본다.

**교사 발문 예:** “글자가 우리에게 무엇을 알려 주나요?” / “친구가 들으면 기분 좋은 말은 무엇일까요?”

### 평가 예시

- **OX:** “한글날은 10월 9일이에요.” → O.
- **객관식:** “한글을 사용한 모습은?” ① 글자로 친구에게 편지를 써요. ② 공을 차요. → ①. 그림과 함께 제시한다.
- **이유 설명:** “쪽지에 ‘고마워’라고 쓴 까닭을 말해 볼까요?” → 고마움을 표현하려는 뜻을 말·그림·몸짓으로 표현하면 인정한다.

**학습지:** 날짜 점선 따라 쓰기 1문항, 한글을 만나는 곳 그림 고르기 1문항, 마음 쪽지 꾸미기 1칸. 쓰기 어려운 학생은 구술로 대체한다.

**확인 기준:** 날짜·뜻을 도움받아 말할 수 있는지, 상대에게 전할 내용을 골랐는지 관찰한다. 연도·자모 수를 모른다는 이유로 미도달 처리하지 않는다.

## 3. 한글날 3~4학년 — 만든 마음, 모아 쓰는 원리

### 학습목표

1. 한글날의 의미를 설명하고 1443년 창제와 1446년 반포를 구분한다.
2. 기본 자음과 모음의 조합을 체험하고, 다른 사람이 이해하기 쉬운 문장을 만든다.

**핵심 설명 문장:** “세종은 1443년에 훈민정음을 만들고 1446년에 널리 알렸어요. 처음에는 28자였고, 지금의 기본 자모는 자음 14자와 모음 10자를 합한 24자예요.”

### 화면과 수업 흐름

| 화면 | 시간 | 학생이 할 일 | 교사의 설명·조작 |
|---|---:|---|---|
| 1. 글자가 없다면? | 3분 | 오늘 만난 글자를 말한다. | 생활 장면으로 문자의 쓰임을 묻는다. |
| 2. 오늘의 미션 | 1분 | 구분할 개념 두 가지를 듣는다. | 목표를 짧게 제시한다. |
| 3. 세종의 마음과 연표 | 6분 | 1443·1446 사건을 연결한다. | 우리말은 이미 있었음을 설명하고 창제·반포를 구분한다. |
| 4. 글자 실험실 | 6분 | ㅎ+ㅏ+ㄴ을 ‘한’으로 조합한다. | 28자와 현대 기본 자모 24자를 구분한다. |
| 5. 한글 탐험 영상 | 4분 | 모양과 원리를 한 가지 관찰한다. | 약 2분 구간 + 대화 2분. |
| 6. 다정한 말 공방 | 8분 | 쉽고 다정한 문장을 짝과 만든다. | “받는 친구가 바로 이해할 수 있을까?” |
| 7. 중간 확인 | 3분 | 낱자를 바꾸어 결과를 비교하거나 OX에 답한다. | 필요할 때 그림 4지선다를 선택한다. |
| 8. 핵심 정리 | 2분 | 창제·반포를 설명한다. | 연표를 다시 보여 준다. |
| 9. 골든벨 또는 학습지 | 6분 | 5문제에 답하고 해설을 듣는다. | 오답도 다시 답할 수 있게 한다. |
| 10. 배움 챙기기 | 1분 | 실천 하나를 말한다. | 다음 생활 장면으로 연결한다. |

**학생 활동:** 글자 조합 실험 + 다정한 말 한 문장. 학생이 임의로 선택한 낱자가 의미 없는 음절을 만들어도 조합 원리 관찰과 의미 있는 말 만들기를 구분해서 안내한다.

### 평가 예시

- **OX:** “한글은 1446년에 처음 만들어졌다.” → X. 1443년 창제, 1446년 반포.
- **객관식:** “처음 훈민정음 / 현대 기본 자모의 수는?” ① 24 / 28 ② 28 / 24 ③ 28 / 28 → ②.
- **이유 설명:** “누구나 이해하기 쉬운 안내문이 세종의 마음과 이어지는 까닭은?” → 여러 사람이 내용을 알고 자기 뜻을 전하도록 돕기 때문이라는 설명을 인정한다.

**학습지:** 날짜, 연도·사건 연결, 훈민정음의 뜻, 기본 자모 수, 쉬운 안내문 또는 다정한 문장 만들기. 상세 6문항과 5문제 골든벨은 `content/lessons.json`에 있다.

**확인 기준:** 창제·반포를 구분하고, ‘24자’를 전체 음절 수가 아닌 기본 자모 수로 설명하며, 창제 목적을 생활과 연결하는지 살핀다.

## 4. 한글날 5~6학년 — 누구나 이해할 수 있는 글

### 학습목표

1. 한글과 한국어, 창제와 반포를 구분하고 자료에 근거해 한글의 창제 목적을 설명한다.
2. 읽는 사람의 상황을 고려하여 안내문을 고치고, 바꾼 이유를 근거와 함께 설명한다.

**핵심 설명 문장:** “한국어는 말, 한글은 그 말을 적는 문자예요. 세종은 글로 뜻을 전하기 어려웠던 사람들을 위해 새 문자를 만들었어요. 좋은 글은 독자가 필요한 정보를 이해하고 행동할 수 있게 도와요.”

외래어가 섞인 문장도 한글로 적을 수 있음을 설명한다. 한글날을 ‘외래어를 절대로 쓰지 않는 날’로 단순화하지 않는다. 다른 문자·언어와 우열을 겨루기보다 창제 목적과 문자 체계의 특징을 살펴본다.

### 화면과 수업 흐름

| 화면 | 시간 | 학생이 할 일 | 교사의 설명·조작 |
|---|---:|---|---|
| 1. 한글과 한국어는 같을까? | 3분 | ‘안녕 / annyeong’에서 말과 표기를 생각한다. | 같은 말도 다른 문자로 적을 수 있음을 보인다. |
| 2. 오늘의 미션 | 1분 | 구분·개선 과제를 확인한다. | 사실과 적용의 목표를 보여 준다. |
| 3. 자료와 연표 | 6분 | 창제 목적, 1443·1446, 28·24를 확인한다. | 출처와 풀이를 구별해 표시한다. |
| 4. 문자·언어 탐구 | 6분 | 그림 속 발화·표기를 분류한다. | 한글과 한국어의 차이를 확인한다. |
| 5. 영상 비평 관찰 | 4분 | 설명에 필요한 개념을 찾는다. | 약 2분 영상 + 확인 질문 2분. |
| 6. 쉬운 글 편집실 | 8분 | 독자를 정하고 안내문을 고쳐 이유를 적는다. | 문장 길이·낱말·정보 순서를 점검한다. |
| 7. 시각 자료 비교 | 3분 | 고치기 전·후 안내판에서 달라진 부분을 표시한다. | 변화가 독자에게 도움이 되는 이유를 묻는다. |
| 8. 핵심 정리 | 2분 | 문자·언어와 창제 목적을 설명한다. | 단정·오개념을 바로잡는다. |
| 9. 근거 골든벨 또는 학습지 | 6분 | 선택 문항과 이유 문항을 해결한다. | 정답과 근거를 따로 확인한다. |
| 10. 나의 편집 원칙 | 1분 | “나는 글을 쓸 때 ___를 확인하겠다.” | 생활 속 정보 접근과 연결한다. |

**학생 활동 예:** 수업용 창작 문장 “익일 우천 시 야외활동을 실내활동으로 대체하며 우산을 지참한다.”를 “내일 비가 오면 실내에서 활동해요. 우산을 가져오세요.”로 고친다. 이것은 실재 학교 공지의 인용이 아니라 **수업용 예시**로 표시한다. 학생들은 이해하기 쉬워진 이유를 설명한다.

### 평가 예시

- **OX:** “한글이 만들어지기 전에는 한국어도 없었다.” → X. 말과 그것을 적는 문자는 구분한다.
- **객관식:** “한글과 한국어를 바르게 설명한 것은?” ① 같은 뜻이다. ② 한글은 문자이고 한국어는 언어이다. ③ 한글은 옛날에만 쓴 말이다. → ②.
- **이유 설명:** “내가 안내문에서 바꾼 두 부분과 그 이유를 설명하고 세종의 창제 목적과 연결하세요.” → 독자의 어려움, 구체적인 수정, 이해·소통과의 연결을 확인한다.

**학습지:** 개념 구분 2문항, 연표·자모 확인 2문항, 안내문 수정 1문항, 수정 이유 1문항. **성공 기준:** 정확한 개념 / 독자 고려 / 수정의 타당한 이유를 각각 확인한다. 글을 길게 쓰는 능력만 평가하지 않는다.

## 5. 개천절 1~2학년 — 함께 좋은 일을 해요

### 학습목표

1. 개천절이 10월 3일이며 고조선의 시작을 기억하는 날임을 말한다.
2. 단군 이야기가 옛날부터 전해 오는 이야기임을 알고, 다른 사람을 돕는 행동을 고른다.

**핵심 설명 문장:** “10월 3일은 개천절이에요. 고조선의 시작을 기억해요. 단군 이야기는 옛날부터 전해 오는 건국 이야기예요. 홍익인간은 여러 사람에게 이로운 세상을 바라는 뜻이에요.”

기원전 연대는 암기시키지 않는다. ‘환웅이 하늘에서 내려왔다’는 장면에 **전해 오는 이야기** 표시를 계속 둔다. 이야기를 사실이라고 믿는지 평가하지 않는다.

### 화면과 수업 흐름

| 화면 | 시간 | 학생이 할 일 | 교사의 설명·조작 |
|---|---:|---|---|
| 1. 하늘이 열린 날 | 3분 | 하늘·마을 그림에서 생각을 말한다. | 개천절 날짜를 함께 읽는다. |
| 2. 오늘의 미션 | 1분 | 날짜와 도움의 마음을 배울 것을 안다. | 한 문장으로 읽어 준다. |

| 4. 이야기 길 잇기 | 6분 | 그림 3장을 순서대로 놓고 설명한다. | ‘전해 오는 이야기’ 표시를 유지한다. |

**학생 활동:** 이야기 그림 순서 잇기 + 도움의 꽃 한 장. ‘곰이 실제로 사람으로 변할 수 있을까?’라는 논쟁을 길게 진행하지 않고, 신비로운 옛이야기라는 성격을 알려 준다.

## 8. 풍성한 이미지로 배우는 다양한 활동

이미지는 도입 장식에 그치지 않고 **관찰·비교·순서·조작·창작·토론**에 사용한다. 4지선다는 필요한 장면에서 선택할 수 있는 예시 한 가지다. 모든 수업이나 평가를 네 그림 고르기로 통일하지 않는다. 화면에 그림이 많더라도 한 번에 해야 할 일은 하나로 유지한다. 역사 장면의 의복·건물·도구는 고증 검토를 거친다. 확인할 수 없는 장면은 ‘교육용 상상 삽화’, 단군 신화 장면은 ‘전해 오는 건국 이야기’로 표시한다.

### 6종 수업의 대표 시각 활동

아래는 **제작할 활동의 설계 예**다. 이미지 속 핵심 글자·날짜·지시는 이미지 생성에 맡기지 않고 앱에서 정확한 글자로 합성한다. 주제와 학년군마다 대표 활동을 달리해 반복적인 문제풀이 화면이 되지 않게 한다.

| 수업 | 대표 방식 | 학생이 하는 일·관찰할 배움 |
|---|---|---|
| 한글 1~2 | 장면 탐색과 마음 쪽지 창작 | 생활 그림에서 글자를 찾고, 글자·그림을 조합한 쪽지로 뜻을 전한다. |
| 한글 3~4 | 낱자 조작과 변화 관찰 | 낱자 블록을 모으고 하나를 바꿔 글자가 어떻게 달라지는지 말한다. |
| 한글 5~6 | 전후 비교와 안내문 재설계 | 같은 안내판의 수정 전·후를 비교하고, 독자에게 필요한 정보를 정확히 전달하도록 고친다. |
| 개천 1~2 | 그림 이야기 순서와 구술 | 환웅·웅녀·단군 그림의 흐름을 잇고 전해 오는 이야기로 들려준다. |
| 개천 3~4 | 장면 분류와 생활 적용 | 신화 삽화·실물 자료의 성격을 구분하고, 현대 교실 그림에 필요한 도움을 제안한다. |
| 개천 5~6 | 자료·주장 연결과 토론 | 실제 자료의 출처·내용을 확인해 주장과 연결한 뒤, 확인할 수 없는 범위를 설명하고 공동체 규칙을 토론한다. |

**선택형 예시 하나:** 한글 3~4학년의 중간 확인에서 “ㅎ·ㅏ·ㄴ을 모아 쓴 글자는?”을 묻고 ‘하 / 나 / 한 / 난’의 조합 그림 네 장을 제시할 수 있다. 정답은 ‘한’이며, 학생은 선택 근거가 된 낱자를 짚어 설명한다. 네 보기의 구도·크기·밝기를 비슷하게 만들고 정답만 빛나거나 크게 그리지 않는다. 이 문항은 낱자 조작·말하기 활동을 대신하는 기본 형식이 아니라 필요할 때 사용하는 짧은 확인 방법이다.

선택형을 사용할 때에도 정답을 기억했는지보다 어떤 부분을 보았는지 듣는다. 보기에 두 개의 합리적 정답이 생기면 학생을 오답 처리하지 않고 질문·그림을 수정한다. 저학년에게 여러 그림을 동시에 보여 줄 때에는 교사가 보기 내용을 순서대로 읽어 주고 충분히 관찰할 시간을 준다.

### 다양한 시각 활동의 역할

| 방식 | 학생의 사고 | 적용 예 |
|---|---|---|
| 확대 관찰 | 보이는 근거 찾기 | 책·낱자·생활 안내판에서 단서 짚기 |
| 그림 4지선다 | 비교하여 선택 | 같은 상황의 다른 행동·같은 낱자의 다른 조합 |
| 전후 전환 | 변화와 원인 설명 | 어려운 안내판→쉬운 안내판, 흩어진 낱자→모아쓴 글자 |
| 순서 잇기 | 시간·관계 이해 | 창제→반포, 환웅·웅녀·단군의 이야기 흐름 |
| 그림 분류 | 자료의 성격 구분 | 신화 삽화·실물 자료·현대 실천 장면 |
| 잘못된 설명 고치기 | 오개념 수정 | 같은 그림에 붙은 두 설명 중 부정확한 표현 고치기 |
| 부분 가리기·열기 | 예상과 재검토 | 그림 일부를 보고 예상한 뒤 전체를 확인해 수정 |
| 나만의 그림·한 문장 | 생활 적용 | 마음 쪽지·홍익인간 실천 카드 만들기 |

**고증이 필요한 그림을 오답 찾기 게임용으로 일부러 왜곡하지 않는다.** 예를 들어 조선의 의복에 현대 물건을 끼워 넣고 그것만 찾게 하면 잘못된 모습이 기억될 수 있다. 비교 과제는 검증된 요소로 만들고 오답의 이유는 행동·정보·조합·근거의 차이에서 나오게 한다. 의도적인 오류 그림이 교육적으로 필요할 때에는 오류 표시와 즉시 교정을 포함한 별도 설계를 한다.

## 9. 영상 선정과 학년별 적합도 검수

현재 확보한 영상은 **후보 자료**다. 실제 YouTube 링크가 교육기관 또는 제작자 소개 페이지에 있는 것은 확인했다. 영상 전체를 재생하여 길이·세부 표현·광고·자막·임베드 허용 여부를 확인하지 못했으므로 아래 학년별 적합도는 **제작 전 검토 의견**이다.

| 영상 | 출처 확인 | 1~2학년 활용 검토 | 3~4학년 활용 검토 | 5~6학년 활용 검토 | 남은 확인 |
|---|---|---|---|---|---|
| [박물관 속 한글탐험](https://www.youtube.com/watch?v=8H7o9kgH3hE) | 국립한글박물관 제작. [충청북도유아교육진흥원 안내](https://www.cbiedu.go.kr/home/sub.php?menukey=335&mod=view&no=5722&scode=99999999) | 소개상 어린이용 애니메이션. 짧은 모양 관찰 구간 후보 | 조합 원리 관찰 후보. 단순한 부분은 요약 | 개념을 확인·비평하는 짧은 관찰로 제한 | 전체 길이, 적절한 2~3분 구간, 자막 가독성, 현재 재생·임베드 여부 |
| [[계기교육] 하늘이 열린 날, 개천절](https://www.youtube.com/watch?v=0h0I_DfiKJY) | [몽당분필 제작자 안내](https://www.teacherville.co.kr/MDBFTV/contents/20637.edu) | 이름·사건 수가 과하지 않은 구간 후보. 교사 중간 설명 필요 | 날짜·기념 뜻 확인 후보 | 신화와 사실을 나타내는 표현을 검토하는 자료 후보 | 전체 길이, 연령별 어휘, 신화 표시, 현재 재생·임베드 여부 |

화면의 ‘5분’ 등은 **시청과 대화에 배정한 수업 시간**이며 영상의 전체 길이가 아니다. 미검증 타임코드나 재생 시간을 사실처럼 표시하지 않는다. 더 적합한 공식 영상이 확보되면 링크·구간·선정 이유를 함께 갱신한다.

**영상이 안 열릴 때:** 한글날은 교사의 자음·모음 조합 시연으로, 개천절은 직접 만든 이야기 카드와 날짜·뜻 확인으로 대체한다. 영상에만 정답의 근거를 두지 않아 수업을 그대로 이어갈 수 있다.

## 10. QR·기기·접근성 대체 설계

| 상황 | 학생이 참여하는 방식 | 교사의 진행 |
|---|---|---|
| QR 촬영이 안 됨 | 화면의 짧은 주소 직접 입력 | QR 아래에 목적·주소·종이 참여 안내를 함께 표시 |
| 학생 기기가 없음 | 2인 1기기 또는 답 카드·공책 | 기기를 가진 학생과 같은 문제·생각할 시간을 제공 |
| 네트워크가 끊김 | 손으로 OX, 번호 카드, 모둠 종이 | 답을 일괄 공개하고 말로 이유를 나눔 |
| 읽기가 어려움 | 교사 읽어 주기·아이콘·음성 답변 | 제한 시간 경쟁을 줄이고 뜻을 확인 |
| 쓰기·조작이 어려움 | 구술·짝의 기록·선택 카드 | 글씨와 클릭 정확성을 지식 평가와 분리 |
| 영상 청취가 어려움 | 검수한 자막·교사의 대체 설명 | 중요한 학습 내용은 화면 텍스트·그림으로도 제공 |
| 움직임에 민감함 | 정지된 그림과 단계별 나타내기 | 모션 줄이기 설정을 제공하고 번쩍임·지속 반복을 피함 |

QR에는 단순히 ‘참여하기’만 쓰지 않고 **무엇을 하는 링크인지** 표시한다. 예: ‘한글 중간 확인 2문제’, ‘홍익인간 실천 한 문장’. 라이브 집계가 구현되지 않았다면 교사가 학생 답을 실시간으로 받고 있다는 표현을 쓰지 않는다.
