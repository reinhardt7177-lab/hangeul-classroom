# 개천절 생성 이미지 제작 기록

제작 방식: 내장 `imagegen` 도구. 기존 여섯 이미지에 한국 산 도입·현대 교실·현대 자료 탐구 이미지 세 장을 더해 원본을 `site/dist/assets/`로 복사하여 앱에 연결했다. 이미지 속 고대 장면은 사료 사진이나 복원이 아니라 **교육용 상상·해석 그림**이다. 한국의 화강암 산세·소나무를 중심으로 구성했고 중국 궁궐·복식·용·무협·도교 장식·한자 글자는 배제했다. 고대 인물의 미확인 얼굴·복식을 정면으로 확정해 그리지 않았다.

모든 출력을 화면으로 확인했다. 생성한 박물관 동검 장면은 실물 형태가 부정확해 **채택하지 않았다**. `gaecheon-dolmen.png`와 `gaecheon-community.png`는 실제 유물을 찍은 사진처럼 보일 수 있어 교사 노트와 출처 모달에서 **교육용 상상 재구성**임을 설명한다. 슬라이드 위에 긴 설명 문구를 얹지 않는다. 실제 유물은 박물관 원문 링크로 확인한다. 역사 표현의 근거는 [사실과 전승 검증](개천절-사실과-전승-검증.md)에 연결했다.
