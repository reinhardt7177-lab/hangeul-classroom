# 개천절 수업의 역사 표현 기준

이 문서는 개천절 앱의 문장, 문제, 삽화에 적용한 사실 검증 기준이다. **기념의 의미**와 **실증된 고대 사건**을 구분한다.

| 수업에서 사용할 표현 | 근거와 한계 |
|---|---|
| 개천절은 10월 3일인 대한민국 국경일이다. | [행정안전부 국경일 안내](https://www.mois.go.kr/chd/sub/a05/celebrationDay/screen.do), [국가법령정보센터 국경일에 관한 법률](https://www.law.go.kr/법령/국경일에관한법률). 다섯 국경일을 랜딩에 배치했다. 제헌절은 2008년 공휴일에서 빠졌다가 「공휴일에 관한 법률」 개정(2026년 시행)으로 다시 공휴일이 되었다([정책브리핑](https://www.korea.kr/news/policyNewsView.do?newsId=148959009)). 국경일(「국경일에 관한 법률」)과 공휴일(「공휴일에 관한 법률」)은 서로 다른 법으로 정한다. |
| 개천절은 하늘이 열렸다는 전승과 고조선의 시작을 기린다. | [한국민족문화대백과 개천절](https://encykorea.aks.ac.kr/Article/E0001734). ‘개천’의 엄밀한 전승상 의미는 환웅의 하강과 연결된다. 단군이 **양력 10월 3일** 나라를 세운 것으로 확증되었다고 말하지 않는다. |
| 환웅, 신단수, 곰과 범, 웅녀, 단군왕검 이야기는 전승으로 읽는다. | [국사편찬위원회 우리역사넷, 단군왕검, 아사달에 나라를 세우다(초등)](https://contents.history.go.kr/mobile/eh/view.do?code=eh_age_10&levelId=eh_n0010_0010), [우리 역사 속 최초의 국가, 고조선(초등)](https://contents.history.go.kr/mobile/eh/view.do?code=ganada&levelId=eh_r0005_0010), [『삼국유사』 원문·해설](https://contents.history.go.kr/front/hm/view.do?levelId=hm_001_0010). 『삼국유사』에 기록된 이야기의 존재와 모든 장면의 실증은 다르다. 초등용 글의 ‘기원전 2333년’, ‘곰 부족’ 같은 문장은 “~라고 전해요”, “~로 해석하기도 해요”로 바꿔 말한다. |
| 10월 3일은 나라의 시작을 **기념하는** 날짜이고, 기원전 2333년은 후대가 계산한 연도다. | [한국민족문화대백과 개천절](https://encykorea.aks.ac.kr/Article/E0001734): 1909년 대종교가 음력 10월 3일을 경축일로 삼았고 상해 임시정부도 기념했으며, 1949년 음·양력 환산이 불가능하다는 이유 등으로 「국경일에 관한 법률」에서 양력 10월 3일로 정했다. 같은 항목의 ‘서기전 2333년 음력 10월 3일 건국’, ‘상원 갑자년(서기전 2457년)’은 대종교 기년이므로 사실로 옮기지 않는다. 『삼국유사』는 ‘요 즉위 50년 경인년’이라 적었고 일연이 연대가 맞지 않는다는 주를 달았다. 기원전 2333년은 『동국통감』(1485)이 단군 원년을 요 25년 무진년으로 본 것을 서기로 옮긴 연도이며([한국민족문화대백과 단군조선](https://encykorea.aks.ac.kr/Contents/Item/E0013554): “『동국통감』의 무진년을 따라 서기전 2333년으로 이해”), 역사적 사실이라기보다 후대의 관념적 산물로 본다([우리역사넷 『주제로 본 한국사』 단군 신화를 이해하는 몇 가지 논점들](https://contents.history.go.kr/mobile/ht/view.do?levelId=ht_001_0020_0020)). |
| 고조선과 청동기 문화는 유물 등으로 탐구한다. | [우리역사넷, 비파형 동검](https://contents.history.go.kr/mobile/kc/view.do?levelId=kc_r000300), [국립중앙박물관 비파형 동검](https://www.museum.go.kr/MUSEUM/contents/M0201030400.do?relicId=29833&schM=view&showHallId=760). 비파형 동검·탁자식 고인돌의 출토 분포는 문화권을 짐작하게 하지만 특정 인물·대화·정확한 건국일의 직접 증거가 아니다. 고인돌은 고창(447기)·화순처럼 한반도 남부에도 밀집하므로([국가유산청 고창·화순·강화 고인돌 유적](https://www.heritage.go.kr/heri/html/HtmlPage.do?pg=%2Funesco%2FHeritage%2FHeritage_07.jsp&pageNo=5_2_2_0)) 고인돌이 있는 곳을 모두 고조선이라고 말하지 않는다. |
| 홍익인간은 사람을 널리 이롭게 한다는 전승의 뜻이다. | [『삼국유사』 원문·해설](https://contents.history.go.kr/front/hm/view.do?levelId=hm_001_0010): 환인이 환웅을 내려보낸 까닭으로 나온다(단군의 건국 목표로 말하는 영상 풀이와 구분). 현재 교실의 실천은 상대의 의견과 존엄을 존중하며 함께 돕는 행동으로 연결한다. |

## 시각 고증의 경계

앱의 `gaecheon-dawn.png`, `gaecheon-tree.png`, `gaecheon-bear-tiger.png`, `gaecheon-community.png`, `gaecheon-dolmen.png`, `gaecheon-classroom.png`는 **교육용 생성 삽화**다. 특정 유적의 발굴 사진, 단군·환웅의 실물 복식 복원, 기원전 2333년의 기록 사진으로 사용하지 않는다. `gaecheon-community.png`의 집(반지하 움집)·옷·밭·마을 배치는 청동기 생활을 생각하게 하는 **해석적 재구성**이고, 한 장소에서 함께 발견되었다는 주장이 아니다. `gaecheon-dolmen.png`도 특정 고인돌 유적의 사진이 아니라 탁자식 고인돌을 상상하여 그린 이미지다. 이미지에는 한국의 화강암 산세·소나무·토착 동물을 사용했다. 중국 궁궐·용좌·한푸·청 왕조 장식·무협 연출·도교적 복장·한자 장식을 배제했다. 인물 얼굴과 고대 복식의 특정 형태를 확정적으로 묘사하지 않기 위해 이야기 장면은 자연과 동물 중심으로 만들었다.

추가 이미지 `gaecheon-summit-dawn.png`와 표지로 쓰던 `gaecheon-dawn.png`·새벽 8초 영상은 황산식 산수(절벽 소나무·바위 봉우리·구름바다)로 읽혀 2026-09-28부터 쓰지 않는다. 원본은 `drafts/replaced/2026-09-28/`에 보관했다. 표지는 직접 만든 1분 도입 영상과 `gaecheon-tree.png`다([시각 고증 재검토](개천절-이미지-프롬프트.md)). `gaecheon-community.png`는 청동기 시대 근거가 약한 닭과 옥수수처럼 보이는 걸이를 지운 수정본이다. `gaecheon-source-study.png`는 **현대 학생이 자료를 살펴보는 장면**, `gaecheon-helping-today.png`는 **현대 교실의 협력 장면**이다. 실물 동검과 닮지 않은 생성 박물관 장면은 채택하지 않았다. 실제 비파형 동검을 관찰할 때는 [국립중앙박물관 소장품 설명](https://www.museum.go.kr/MUSEUM/contents/M0201030400.do?relicId=29833&schM=view&showHallId=760)으로 연결한다. 두 Kling 영상은 기존 생성 이미지에서 출발한 상징적 도입과 전승 시각화이며 실증된 고대 장면을 촬영한 기록이 아니다. 완성 영상의 고증·음악·비용은 [영상 제작 기록](../docs/개천절/영상-제작기록.md)에 남겼다.

## 학년별 평가 구분

- 1–2학년: 날짜와 뜻, 전해지는 이야기의 순서, 서로 돕는 행동을 말한다.
- 3–4학년: 전승·사실·교육용 상상 그림을 구분하고 홍익인간을 적용한다.
- 5–6학년: 문헌과 유물의 증거 범위를 설명하고 정확한 건국일 단정을 비판한다.

모든 정답은 교사 화면에서 ‘다음’ 뒤에 이유와 함께 공개한다. 그림 선택 4지선다는 여러 평가 방식 중 하나이며, 태블릿에는 순서 배열·자료 분류·행동 선택·자기 문장 쓰기도 넣었다.
