# 개천절 수업의 역사 표현 기준

이 문서는 개천절 앱의 문장, 문제, 삽화에 적용한 사실 검증 기준이다. **기념의 의미**와 **실증된 고대 사건**을 구분한다.

| 수업에서 사용할 표현 | 근거와 한계 |
|---|---|
| 개천절은 10월 3일인 대한민국 국경일이다. | [행정안전부 국경일 안내](https://www.mois.go.kr/chd/sub/a05/celebrationDay/screen.do). 다섯 국경일을 랜딩에 배치했다. 제헌절을 모두가 쉬는 날이라고 설명하지 않는다. |
| 개천절은 하늘이 열렸다는 전승과 고조선의 시작을 기린다. | [한국민족문화대백과 개천절](https://encykorea.aks.ac.kr/Article/E0001734). ‘개천’의 엄밀한 전승상 의미는 환웅의 하강과 연결된다. 단군이 **양력 10월 3일** 나라를 세운 것으로 확증되었다고 말하지 않는다. |
| 환웅, 신단수, 곰과 범, 웅녀, 단군왕검 이야기는 전승으로 읽는다. | [국사편찬위원회 우리역사넷, 단군 신화](https://contents.history.go.kr/mobile/eh/view.do?code=eh_age_10&levelId=eh_n0010_0010), [단군과 고조선](https://contents.history.go.kr/mobile/eh/view.do?code=ganada&levelId=eh_r0005_0010). 『삼국유사』에 기록된 이야기의 존재와 모든 장면의 실증은 다르다. |
| 고조선과 청동기 문화는 유물 등으로 탐구한다. | [우리역사넷, 비파형 동검](https://contents.history.go.kr/mobile/kc/view.do?levelId=kc_r000300). 비파형 동검·고인돌의 출토 분포는 문화권을 짐작하게 하지만 특정 인물·대화·정확한 건국일의 직접 증거가 아니다. |
| 홍익인간은 사람을 널리 이롭게 한다는 전승의 뜻이다. | [우리역사넷, 단군 신화](https://contents.history.go.kr/mobile/eh/view.do?code=eh_age_10&levelId=eh_n0010_0010). 현재 교실의 실천은 상대의 의견과 존엄을 존중하며 함께 돕는 행동으로 연결한다. |

## 시각 고증의 경계

앱의 `gaecheon-dawn.png`, `gaecheon-tree.png`, `gaecheon-bear-tiger.png`, `gaecheon-community.png`, `gaecheon-dolmen.png`, `gaecheon-classroom.png`는 **교육용 생성 삽화**다. 특정 유적의 발굴 사진, 단군·환웅의 실물 복식 복원, 기원전 2333년의 기록 사진으로 사용하지 않는다. `gaecheon-community.png`의 집·옷·고인돌 배치는 청동기 생활을 생각하게 하는 **해석적 재구성**이고, 한 장소에서 함께 발견되었다는 주장이 아니다. `gaecheon-dolmen.png`도 특정 고인돌 유적의 사진이 아니라 탁자식 고인돌을 상상하여 그린 이미지다. 이미지에는 한국의 화강암 산세·소나무·토착 동물을 사용했다. 중국 궁궐·용좌·한푸·청 왕조 장식·무협 연출·도교적 복장·한자 장식을 배제했다. 인물 얼굴과 고대 복식의 특정 형태를 확정적으로 묘사하지 않기 위해 이야기 장면은 자연과 동물 중심으로 만들었다.

## 학년별 평가 구분

- 1–2학년: 날짜와 뜻, 전해지는 이야기의 순서, 서로 돕는 행동을 말한다.
- 3–4학년: 전승·사실·교육용 상상 그림을 구분하고 홍익인간을 적용한다.
- 5–6학년: 문헌과 유물의 증거 범위를 설명하고 정확한 건국일 단정을 비판한다.

모든 정답은 교사 화면에서 ‘다음’ 뒤에 이유와 함께 공개한다. 그림 선택 4지선다는 여러 평가 방식 중 하나이며, 태블릿에는 순서 배열·자료 분류·행동 선택·자기 문장 쓰기도 넣었다.
